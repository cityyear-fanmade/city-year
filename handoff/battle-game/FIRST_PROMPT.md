# 시작 프롬프트 (새 세션에 붙여 넣기)

```
이 저장소는 도시의 한 해 전투를 따로 떼어 만드는 전투 연출 게임이야. 먼저 CLAUDE.md와 docs/를 읽어 줘.

만들고 싶은 것
- 한 판의 흐름: ① 카드 선택 화면(루이나식: 내 속도 주사위와 카드 몇 장을 고른다, 상대의 계획도 일부 보인다) → ② 합 연출(림버스식: 서로의 카드가 맞부딪힌다) → ③ 에고 컷인(조건을 채우면 큰 연출 한 번) → ④ 결과.
- 규칙은 src/engine.js(도시의 한 해 엔진)를 그대로 써. 화면은 엔진의 전투 기록(이벤트)만 받아서 재생해.
- 도트 전투 무대는 proto/char-test.tpl.html의 "전투 화면"을 시작점으로 써(위: 주사위 판정, 아래: 도트 무대). 도트 몸·머리 시트와 합성 방식은 그대로 쓴다.

해 줬으면 하는 첫 작업(한 번에 하나만)
1. 엔진이 전투를 시뮬할 때 이벤트 목록을 내보내는지 확인하고, 없으면 최소한으로 추가하는 계획을 말해 줘(코드는 아직 고치지 마).
2. 그 이벤트 목록의 예시(한 라운드 분량)를 보여 줘.
3. 내가 확인하면 "이벤트 재생기" 시험을 proto에서 만든다.

하지 말 것
- 원작(루이나·림버스)의 대사·사건 문장·이미지를 옮기지 마. 연출 문법만 따라 해.
- 이미지는 네가 만들지 말고 필요하면 GPT용 프롬프트를 써서 나에게 요청해.
- 한꺼번에 여러 화면을 만들지 마.
```
