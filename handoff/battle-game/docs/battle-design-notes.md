# 전투 설계 메모 (출발점)

## 흐름
1. **선택 화면**: 이번 라운드에 쓸 카드를 고른다. 도시의 한 해 엔진에는 이미 "라운드마다 행동 N개"와 속도 순서가 있다(`resolveRound(C, playerPlan, enemyPlan)`).
2. **합**: 선공·후공 순서로 카드가 맞붙는다. 명중 1d100 대 회피/방어 1d100의 판정 칸을 연출로 키운다(위쪽 판정 상자는 유지).
3. **에고**: 조건(정신력·카드 등)이 맞으면 컷인과 함께 큰 한 방. 시험판의 도트 연출(돌진·섬광·히트스톱)을 확장한다.
4. **결과**: 피해·상태 정리.

## 연출 부품(시험판에서 이미 된 것)
- 도트 몸 20칸 + 머리 38칸(단발·숏컷), 머리색·눈색 교체
- 대기 반복, 공격·회피·피격·쓰러짐 프레임 재생
- 베기 이펙트, 타격 섬광, 피해 숫자, 좌우 배치(주인공 오른쪽)

## 더 필요한 것
- 이펙트 도트 시트(베기, 타격, 에고 발동), 히트스톱, 화면 흔들림
- 에고 컷인용 일러스트(상반신 컷 1장 + 배경 효과). 이미지는 GPT 프롬프트로 요청한다.
- 엔진 이벤트 목록(없으면 최소로 추가)

## 주의
- 상대 297종을 모두 연출하지 않는다. 보스급만 도트·컷인을 붙이고 나머지는 이름 카드 + 색.
- 규칙(밸런스)은 도시의 한 해와 같게 유지한다.
