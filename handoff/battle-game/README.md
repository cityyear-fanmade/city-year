# 전투 게임 (가칭) — 새 저장소 시작 묶음

도시의 한 해와 따로 가는 **전투 중심 게임**을 시작하기 위한 인계 묶음이다. 이 폴더를 새 저장소에 그대로 옮긴 뒤 `copy-from-city-year.sh`로 필요한 부분을 가져온다.

## 한 줄 설명
"라이브러리 오브 루이나식 카드 선택 → 림버스 컴퍼니식 에고 연출이 들어간 전투 화면". 규칙은 도시의 한 해 전투 엔진을 그대로 쓰고, 화면(연출)을 새로 만든다.

## 폴더 안 파일
- `CLAUDE.md` 새 저장소의 작업지침(첫 파일로 둔다)
- `FIRST_PROMPT.md` 새 세션에 처음 붙여 넣는 시작 프롬프트
- `copy-from-city-year.sh` 도시의 한 해 저장소에서 가져올 파일 목록(엔진·데이터·도트 시트·시험판 도구)
- `docs/` 설계 메모(아래)
- 이 인계 묶음은 도시의 한 해 저장소 `v8-dev` 브랜치 기준

## 새 저장소를 만드는 순서
1. 새 저장소를 만든다(비공개 권장, 이름은 정한 뒤).
2. 이 폴더의 파일을 새 저장소 루트로 옮긴다(`CLAUDE.md`, `FIRST_PROMPT.md`, `docs/`, `copy-from-city-year.sh`).
3. 도시의 한 해 저장소를 옆에 받아 둔 뒤 `bash copy-from-city-year.sh <도시의한해 경로>`를 실행한다.
4. 새 Claude 세션을 새 저장소에서 열고 `FIRST_PROMPT.md`를 붙여 넣는다.
