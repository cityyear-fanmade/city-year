# 거미집 30턴 설계서 (3턴 = 1해 · 내력 이어짐)

상태: 설계 확인 대기. 코드·원고는 아직 바꾸지 않았다.
이전 안(20턴·5턴=1해·후일담 3년 별도 화면)을 대체한다.

## 1. 확정한 것 (사용자 결정)

| 항목 | 내용 |
|---|---|
| 길이 | 본편 30턴, 3턴 = 1해, 10년 |
| 시작 | 루트마다 다르다. 제자 루트: 입단 뒤 2년차부터 초대(신입). 스승 루트: 제자 제안을 거절한 뒤 간부급이 되면 초대(년차 가변). 아래 2절 참고 |
| 결말 뒤 | 별도 후일담 화면 없음. 결과가 "내력"으로 저장되고 일반 진행이 이어받는다 |
| 내력의 수명 | 결말 이후 1막 끝(55년차)과 2막(55년차 이후)까지 판이 끝날 때까지 남는다. 사건 시점은 결말 연도 기준 상대값으로 잡는다 |
| 스승 루트 결말 | 가담 / 변형 / 탈출(레테를 데리고 나감) / 제거(레테를 없앰) 4갈래 |
| 제자 루트 결말 | 힘이 없다. 프로젝트 초기 재료로 끝난다. 탈출·제거는 고를 수 없다 |
| 제자 18턴 대부 직접 등장 | 삭제. 언더보스가 인장 명령서를 전달 |
| 제자 루트 길이 | 21턴(7해). 스승 루트와 길이가 다르다 |

## 2. 시간표

### 루트별 입성 시기 (현재 코드 기준)

| | 제자 루트 | 스승 루트 |
|---|---|---|
| 조건 | 손가락 조기 입단(`fingerEarly`) 또는 소지 표식 + 입단 뒤 `inviteYear`(2)해 이후 | 제자 제안을 거절한 뒤 간부급: 엄지 언더보스(`fi≥2`) · 검지 `fi≥1` · 중지 `fi≥3` · 약지 증거 반지 · 소지 네 별 |
| 플레이어 | 막 들어온 신입, 17~20세 | 간부급. **25~34세에 제안이 열려야 한다**(= 9~18년차, 나이 = 16 + 년차) |
| 시작 연도 | 2~4년차(보류하면 2년 뒤 다시 묻는다) | 9~18년차(25~34세) 안에서 간부급이 된 해 이후. 18년차(34세)를 넘기면 제안은 닫힌다 |
| 길이 | 21턴 = 7해 | 30턴 = 10해 |
| 결말 연도 | 시작 + 7 (대략 9~11년차) | 시작 + 10 (19~28년차, 플레이어 35~44세) |
| 상대 결말 뒤 남은 해 | 40년 이상 | 27~36년 + 2막 |

- 지금 코드는 제안 조건에 `G.year + 9 > lastYear(G)`가 있다(8해 + 여유 1). 30턴이면 `ceil(총턴 / 3) + 1`로 바꾼다.
- 스승 제안의 상한은 18년차(34세)로 확정한다. 결말은 19~28년차(35~44세)이고, 내력이 1막 후반 27~36년과 2막까지 이어진다.
- 나이 차: 제자(상대)는 열아홉에서 시작해 해마다 오른다. 스승은 25~34세에 시작하므로 차이는 6~15세로 시작부터 끝까지 같다. 연애 선택지의 나이 차 상한은 15세이고, 창의 상한 34세는 제자 19세 + 15에서 나온다.
- 스승 원고에는 플레이어의 구체 나이를 쓰지 않는다(25~34세 안에서 판마다 다르다).
- 위험: 간부급(엄지 언더보스 등)이 34세 안에 안 되면 스승 제안이 아예 열리지 않는다. 몇 %의 판이 창 안에서 간부급이 되는지 시뮬로 재 본 뒤, 모자라면 창 안 승급 가속이나 조건 완화를 정한다(미정).
- 연애 선택지는 제자가 성인으로서 충분히 자란 뒤(해 5 이후, 제자 23세 이후)에만 열고, 천천히 쌓이는 연정으로만 다룬다. 수위는 일반 이용 범위로 두고 성별을 드러내는 표현은 쓰지 않는다.
- 제자 루트의 플레이어는 신입이므로 "해 n"만 쓰고 구체 나이는 피한다(입단 나이가 판마다 17~20세).

## 2-1. 스승 자리 제안: 한 단계 위로 올리는 이유

스승 제안의 서열 조건을 한 단계 낮춘다(엄지 카포, 중지 작은형님). 제안을 받아들이면 그 자리에서 바로 위 서열로 올려 주고, 원고의 호칭(`web.role`)은 그대로 둔다. 거절하면 승급은 없다.

| 손가락 | 제안 조건 | 받아들이면 | 이유 (제안문의 핵심) |
|---|---|---|---|
| 엄지 | 카포 | 언더보스 | 대부: "자리를 줘서 네가 되는 게 아니다. 네게 이미 있는 걸 자리가 따라가는 거다." |
| 중지 | 작은형님 | 큰형님 | 큰형님: "네가 앉을 자리가 아니라, 네가 이미 하고 있던 일의 이름이다." |
| 검지 | 대행자·전령 | (최상위, 승급 없음) | 찢긴 지령 옆에 붙은 쪽지: 읽히지 않는 줄을 읽으려 하지 않고 수행해 온 사람이 이 일에 맞는다 |
| 약지 | 마에스트로(증거 반지) | (최상위, 승급 없음) | 붉은 줄 옆에 적힌 이름: 틀린 곳을 가장 먼저 알아본 눈이 필요하다 |
| 소지 | 네 별을 모두 이음 | (서열 없음) | 이은 사람이 아니면 잡을 수 없는 남은 가닥 하나. 그 가닥은 사람을 세우는 일로만 끝까지 당겨진다 |

- 구현: `webStart`에서 `route === 'master'`이고 `canFingerUp`이면 `fingerStep`을 한 번 호출하고 칩에 "스승의 자리 · 언더보스" 식으로 알린다. 서열이 이미 최상위이면 호출하지 않는다.
- 제안문(`data/web.json` 스승 초대)은 위 이유가 보이게 고친다. 제안 조건(`webCadre`)은 엄지 `fi≥1`, 중지 `fi≥2`로 낮춘다.
- 25세 전에 조건을 채운 판은 25세(9년차)에 제안이 뜬다.

## 3. 내력 (`ch.web`, 판 저장에 포함)

```
ch.web = {
  route: 'master' | 'disciple',
  proj:  'join' | 'alter' | 'escape' | 'remove'         // 스승
       | 'obey' | 'resign' | 'trace',                   // 제자
  rel:   'bond' | 'apart' | 'knot' | 'left' | 'cut',    // 이어진 실 / 각자의 길 / 같은 매듭 / 남겨진 자리 / 끊어낸 실
  rete:  'done' | 'with' | 'gone' | 'removed',          // 레테: 완성 / 곁에 있음 / 사라짐 / 제거됨
  hidden: true|false,                                   // 변형: 숨긴 기록이 아직 드러나지 않았는가
  endYear: <결말을 맞은 년차>
}
```

- 관계 결과(`rel`)는 인연 키(신뢰·의존·존경·집착·공범·연정)가 결말 시점에 가장 높은 쪽과 연정 여부로 정한다.
- 사건 조건에 `web:탈출`, `web:rel>=bond` 같은 항목을 추가한다.

## 4. 영향 단계

| 단계 | 시기 | 내용 | 이번 범위 |
|---|---|---|---|
| 1 | 결말 연도 + 1~3 | 결과별 연례 사건: 탈출=추적, 제거=조직 보복, 변형=숨긴 기록이 드러남, 가담=완성된 프로젝트의 결과 | 포함 |
| 2 | 이후 | 레테를 데리고 탈출하면 인연 캐릭터로 등록되어 2막까지 동행. 연정이 있으면 후반 인연 이야기 | 포함 |
| 3 | 결말 + 10·20해, 그리고 55년차 이후(2막) | 장기 내력 사건 2~3개, 엔딩 문구·칭호가 (프로젝트 × 관계)로 달라짐 | 포함 |
| 4 | 무한 모드 100해쯤 | "형상 이상" 사건에 레테·제자·스승의 형상이 섞임. 사무소 직원 시스템과 같이 설계 | 나중 |

## 5. 제자 루트

- 길이: 21턴(7해). 3턴=1해. 30턴으로 늘리지 않는다. 결말은 신입이 거미집에 들어간 지 7년 뒤(대략 9~11년차)라서, 내력이 40년 넘게 남는다.
- 18턴 대부 직접 등장은 없애고, 언더보스가 대부의 인장 명령서를 전달한다.
- 끝: 프로젝트 초기 재료로 쓰인다. 질문을 하는 대신 행동 선택지로 고른다(기존 규칙 유지).

## 6. 구현 목록

1. `config.js`: `web.turnsPerYear` 3, 보상 배율, 결말 코드 목록(`complete/apart/accomplice/left/revolt` → 위 4+3으로 교체).
2. `tools/web-validate.mjs`: 길이 30(제자 20), 해 구조, 결말 코드, 레테 이름 시작 턴.
3. `engine.js`: 결말 효과(서열·소속·추적 플래그), `ch.web` 저장, `web:` 조건, 연례 사건 풀.
4. `data/events.json`(또는 `data/web.json`): 내력 연례 사건, 장기 사건, 엔딩 문구와 칭호.
5. 원고: 엄지 스승 30턴 → 엄지 제자 20턴 → 읽기용 문서 재생성(`node tools/web-readable.mjs`).
6. 인계 문서(`gpt-handoff.md`, `story-bible.md`)를 30턴·3턴=1해·결말 4갈래로 갱신.
7. 시험판(`npm run build -- --finger`) 다시 올리기.

## 7. 미정

| 항목 | 질문 |
|---|---|
| 제자 루트 끝 | 초기 재료가 되면 판이 끝나는가(게임오버), 아니면 재료가 되어도 일반 진행이 이어지는가 |
| 스승 창(9~18년차) 안 간부급 도달률 | 측정함(아래). 엄지 언더보스 29%, 중지 큰형님 10%로 모자라서 서열 조건 완화가 필요하다 |

### 간부급 도달 연도 측정 (무작위 선택 자동 진행, 조기 입단 판, 표본 약 40~50판/손가락)

| 손가락 · 서열 | 도달 | 중앙값(년차 / 나이) | 9년차 전 | 9~18년차 | 19년차 이후 |
|---|---|---|---|---|---|
| 엄지 카포 | 40/42 | 11 / 27세 | 12 | 27 | 1 |
| 엄지 언더보스(현재 조건) | 32/42 | 21 / 37세 | 0 | 12 | 20 |
| 중지 작은형님 | 49/50 | 18 / 34세 | 0 | 37 | 12 |
| 중지 큰형님(현재 조건) | 47/50 | 26 / 42세 | 0 | 5 | 42 |
| 검지 대행자·전령(현재 조건) | 35/43 | 13 / 29세 | 0 | 31 | 4 |

- 약지·소지는 아직 측정하지 않았다.
- 무작위 선택 기준이라 실제 플레이는 더 빠를 수 있다.
| 내력 연례 사건 간격 | 결말 연도 기준으로 해마다 하나씩 넣을지, 몇 해 건너뛸지 |
| 제거의 대가 | 조직 보복의 강도(소속 상실까지 갈지) |
| 공방 거리 지연 | 10해 동안 쌓이는 기회를 거미집 직후에 몰아서 줄지, 몇 개만 줄지 |
| 나머지 손가락(보냐텔리·약지·중지·검지·소지) | 같은 30턴 틀을 쓰되 GPT 원료 문서로 받을 때 해별 뼈대를 함께 보낸다 |
