# 시지프 상호작용 확장안 (2026-11-18, 검수 대기)

목표: 사냥·옷 제작 같은 반복 루프를 빼고, **그 해(턴)와 소속에 맞는** 사건·선택 80편 안팎을 둔다. 무작위로 섞지 않고 시기 창(턴 범위)과 소속 조건으로 정해 둔다.
한 판에서 보게 되는 양은 약 35~45편(방문한 층과 소속에 따라), 전체 풀은 80편이라 다시 해도 새로운 사건이 나온다.

## 구조
- **시기 창**: 초반(1~9턴) · 중반(10~24) · 후반(25~39) · 말기(40~51). 사건마다 창이 정해져 있어 해에 맞는 것만 나온다.
- **층 사건(42편)**: 구역을 골라 나갔을 때, 지금 시기에 맞고 아직 안 본 그 층 사건이 가장 먼저 걸린다(확률 55%, 나머지는 평소 사냥).
- **소속 사건(24편)**: 소속이 정해진 뒤 정해진 턴(대략 8턴 간격)에 소속별로 하루 한 편.
- **공통 사건(14편)**: 손님 사연 10 + 시즌 방송 4. 시기 창에 맞게 한 번씩.
- **주문 제작 의뢰(템플릿 12종)**: 3~4턴에 한 번 손님이 특정 색·무늬를 요청. 맞춰 지으면 값 +보너스와 신뢰.
- **사냥 대상 고르기(구역마다 2종 × 5구역)**: 사냥을 나가면 안전한 대상과 위험한 대상 중 고른다(위험하면 보상도 큼).

## 정할 것
1. 층 사건 확률 55%와 한 판당 보게 되는 양(35~45편)이 적당한지
2. 소속 사건 24편의 방향(위 소제목) 확인
3. 주문 제작 보너스 폭(값 +30%, 신뢰 +1 정도로 시작해도 되는지)
4. 먼저 만들 것: 층 사건 42편 중 층 하나를 시험으로 만들어 느낌을 볼지(추천), 한꺼번에 80편을 쓸지
