# 나중에 할 일 (5차 이후)

- 스탯 창: 수치를 출처(기본·출신·성장·소속)별로 나눠 보여 주기 (지금은 합계 + 장비 몫만)
- 히든 직업(머리의 발톱·조율자) 실제 플레이: 시작 신분, 전용 카드·패시브, 집행 의뢰 사건, 진행 방식
- 협회·날개·손가락 최고점 칭호도 특색처럼 직접 입력할지 결정

## 5차 예정
- (4차에 반영함) 장비 효과 기호화
- 검지 대행자급(승률 70% 안팎) 히든 보스 2명 추가 (전용 패시브·전리품 포함)

- 기믹 보스 후보: 피아니스트(뒤틀림), 샤덴프로이데(환상체로 추정, 분류 확인 후 결정)
- 혈귀·유물 적성자 밸런스 시뮬 점검, 전체 난이도 상향 검토 (시뮬 완주율 약 90%)

## 업데이트 흐름 (2026-10-12 결정)
1. 이 저장소에서 수정 → `npm run -s check`
2. 테스트판: `npm run -s build -- --expires <ISO>` → Claude Artifact로 플레이테스트 링크 선공개
3. 테스트 피드백 반영·수정
4. 완성본: `npm run -s pages`로 루트 index.html 갱신, 처음 화면 버전 올림(src/ui.js vTitle) → main에 푸시 → 1~2분 뒤 https://cityyear-fanmade.github.io/city-year/ 반영

## 5차: 일반 적 15종 추가 + 무한런 (2026-10-12 v5.0에 반영함)
- 초반: 골목 쥐 패거리, 무허가 해결사, 녹슨 의수 강도, 고장 난 배달 기계, 골목 소매치기
- 중반: 밤의 청소부, 배신한 사무소 해결사, 날개 처리반, 중지 막내들, 뒤틀린 짐꾼
- 후반: 협회 감찰관, 현상금 사냥꾼, 특이점 시험체, 약지의 "작품", 피아니스트(라오루, 후반 표에서 낮은 확률 · 기믹 전투)
- 기본 엔딩 연차 45년 → 55년. 목표 플레이 시간: 히든 제외 엔딩까지 약 45분 (적 성장 재조정 필요)
  - 승급 필요량: 연차 비율(55/45)만큼 늘림
  - 히든 보스 후반 보정: 25년차부터 해마다 체력 +2, 3년마다 공격력 +1 (40년차 체력 +30 · 공격력 +5, 55년차 +60 · +10). 기존 보정에 더함
- 무한런: 55년 엔딩 뒤 "계속 살아간다" 선택. 위협 등급 도시 괴담 → 도시 전설 → 도시 질병 → 도시 악몽 → 도시의 별 → 불순물. 불순물 통과 시 진엔딩. 엔딩 문구 확장(산 햇수, 도달 등급, 쓰러뜨린 상대). 시간 기준은 55년 엔딩에만 적용.
