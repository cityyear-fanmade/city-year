# 해금 출생 · 머리의 발톱 / 조율자 기본 설계안 (2026-10-30)

해금 출생 틀(`design-unlock-origin.md`, route 엔진)에 **머리의 발톱**과 **조율자**를 올리는 설계. 이미 있는 히든 직업 둘을 이야기가 있는 줄기로 바꾼다. 7-2절 사용자 제안(\"다른 존재와의 싸움\", 휘말려서 외곽으로 가고, 도시와 적대하게 된다)을 뼈대로 쓴다.

> 상태: 기본 설계 제안. 구현 전에 아래 "정할 것"의 답이 필요하다.

## 1. 지금 구조 (확인한 것)
| 항목 | 머리의 발톱 | 조율자 |
|---|---|---|
| 출생 굴림 | 1 | 100 |
| 해금 | 금기 선택 1회 + 다른 히든 보스 격파 + 13년차 이후에 나오는 **발톱 · 바랄**을 이긴다 | 금기 2회 등 같은 조건에서 나오는 **조율자 · 제나**를 이긴다 |
| 직업 | 머리 소속, 공방 3등급, 전용 책장 12장(덱 고정) | 같음 |
| 시작 | 레벨 12, HP +60, 공격 +10, 회피 +5, 속도 +6 | 레벨 12, HP +80, 공격 +9, 회피 +7, 속도 +3, 판정 +8 |
| 전용 무기 | 발톱 (공+5 속+3 적중마다 2d2) | 요정 (공+5 회피+4 피해+2) |
| 패시브 | 질주: 3라운드마다 빛 +1 | 봉인: 4라운드마다 상대 공격 카드 1장 취소. 권한을 고를 때마다 주기 −1(최소 2) |

문제는 해금과 같다. 직업을 얻은 뒤의 이야기가 없고, 일반 연례 사건·공방 거리·일반 조우를 그대로 쓴다.

## 2. 방향
- 둘 다 **머리의 직속**이다. 발톱은 명령을 몸으로 집행하는 쪽, 조율자는 균형을 맞추는 쪽이다. 도시의 가장 높은 곳에서 시작해 도시에서 멀어지는 이야기다.
- 해금 출생 공통 규칙: 시작 레벨 12(조율자·발톱 예외), 공방 거리 없음, 일반 조우 없음, 전용 책장 12장 고정(새 카드 대신 돈), 2차 강화되는 전용 무기.
- 1막은 **머리의 의뢰를 집행**하는 이야기, 2막은 **의뢰가 도시 밖으로 이어져 휘말리는** 이야기다. 도시와 적대하게 되는 것은 2막의 전환점이다.
- 마지막 상대는 **외곽에서 온 존재**(이름과 정체 미정, 맥거핀으로 남긴다). 발톱·조율자 줄기가 서로 상대의 추적자가 된다.

## 3. 공통 뼈대
| 단계 | 연차 | 내용 |
|---|---|---|
| 출발 | 1 | 머리의 부름. 레벨 12로 시작, 전용 무기를 받는다 |
| 의뢰 | 1~55 | 해마다 **머리의 보급 / 집행(조율) 의뢰**를 고른다(까마귀팀의 처분 의뢰 흐름 재사용). 의뢰 대상은 단계별 목록(전용 몹과 금기자들) |
| 균열 | 40~55 | 의뢰의 흔적이 도시 안이 아닌 곳으로 이어진다. 외곽에서 온 무언가가 금기의 흔적을 알아본다 |
| 휘말림 | 56~60 | 의뢰를 수행하던 사서는 외곽으로 끌려 나간다. 머리는 이유를 말하지 않는다 |
| 적대 | 60~70 | 도시 쪽 추적자가 붙는다(발톱은 조율자 제나, 조율자는 발톱 바랄). 차원 유랑 장면 몇 개 |
| 결전 | 73 | 외곽에서 온 존재와 마지막 싸움. 엔딩은 두 갈래 |

## 4. 머리의 발톱 (집행하는 쪽)
- **분위기**: 빠르고 망설이지 않는다. 말이 적다. 명령서를 읽고 바로 움직인다.
- **의뢰 흐름**: 집행 의뢰는 대상 이름과 구역만 적혀 있다. 준비물(속도 위주 3개)을 고르고 2년 뒤 대상과 만난다. 대상은 금기를 어긴 해결사, 도망친 집행자, 머리가 지운 이름 순으로 올라간다.
- **무기 성장**: 발톱이 의뢰 3·6·9번째마다 1단계씩 강화된다(최대 3단계). 세 단계에서 이름이 바뀐다.
- **1막 줄기(안)**: 첫 집행 → 동료 발톱의 실종 → 실종한 동료의 마지막 집행서를 쫓음 → 도시 가장자리에서 외곽의 흔적을 봄.
- **2막**: 머리의 이유 없는 명령으로 외곽에 나간다. 돌아갈 길이 끊긴다. 조율자 제나가 \"데려오라\"는 명령을 받고 추격한다.
- **엔딩(안)**: 명령을 따라 도시로 돌아가는 길을 만든다 / 명령을 내려놓고 외곽에 남는다.

## 5. 조율자 (바로잡는 쪽)
- **분위기**: 차분하고 판정이 정확하다. 균형을 맞추는 일을 한다. 말투는 정중하다.
- **조율 의뢰**: 금기를 어긴 대상에게 **봉인 / 서약** 중 하나를 건다. 봉인은 HP를 깎고 방어를 얻고, 서약은 정신력을 깎고 공격을 얻는다. 고를 때마다 봉인 패시브의 주기가 짧아진다.
- **다른 금기자**: 같은 금기를 어긴 사람을 만난다. 구한다 / 넘긴다 / 지나친다. 선택이 쌓여 결말이 갈린다.
- **무기 성장**: 요정이 의뢰 3·6·9번째마다 1단계씩 강화된다.
- **1막 줄기(안)**: 조율 통지서 → 서류 심사(정직·거짓·침묵) → 다른 금기자 → 조율 제안 → 균열의 보고(조율한 금기의 근원이 도시 밖).
- **2막**: 조율의 대상이 도시가 아닌 존재가 된다. 머리가 조율자를 도시에서 떼어 낸다. 발톱 바랄이 \"회수하라\"는 명령을 받고 추격한다.
- **엔딩(안)**: 균형의 한쪽을 도시에 남긴다 / 균형을 조율하는 쪽에서 내려온다.

## 6. 해금 조건 (안)
- **기존 해금 유지**: 발톱·조율자를 이긴 기록(`cityYearUnlocks`의 `claw`/`arbiter`)이 있으면 해금 출생도 열린다. 이미 직업을 해금한 사용자는 바로 쓸 수 있다.
- **출생 선택 화면**: 해금 출생 목록에 둘을 올린다. 기존 출생 굴림 숫자(1, 100)로 고르는 직업 시작도 그대로 유지한다. 직업과 출생을 합칠지는 나중에 정한다.

## 7. 구현 순서
1. `unlockOrigins`에 두 출생을 넣고 `routes.claw` / `routes.arbiter`를 만든다(공방 거리 없음, 일반 조우 끔, 시작 레벨 12).
2. 1막: 의뢰 흐름(hunt)과 대상 목록, 줄기 임무 5개씩.
3. 무기 성장 단계(발톱·요정)와 전용 책장.
4. 2막: 휘말림, 추격자(제나·바랄), 외곽에서 온 존재전, 엔딩 2종씩.
5. 시뮬(완주 40~60% 목표)과 테섭 확인.

## 8. 정할 것
1. 직업과 출생을 **따로 두는지**(굴림으로 고르는 직업도 유지) 합치는지.
2. 마지막 상대인 **외곽에서 온 존재**의 이름과 어디까지 보여 줄지(맥거핀으로 둘지).
3. 2막에서 도시와 적대하는 연출 수위(차원 유랑 장면의 수).
4. 엔딩 4종(발톱 2, 조율자 2)이 맞는지.
5. 원작 인물 사용: 제나·바랄은 사용자 지시로 쓰는 예외이고, 외곽에서 온 존재는 원작 이름을 쓰지 않는다.
6. 두 줄기가 서로 추격자가 되는 구도(발톱 줄기에서 제나, 조율자 줄기에서 바랄)가 맞는지.

## 9. 구현 현황 (2026-10-30)
- **해금 출생과 합쳤다(확정)**: 발톱과 조율자는 이제 해금 출생으로만 고른다(굴림 1·100으로 직업을 고르는 선택은 없앴다). 기존 해금 기록(`cityYearUnlocks`의 `claw`/`arbiter`)은 그대로 이어져 이미 해금한 사용자는 바로 쓴다. 굴림 번호 히든 출생(예: 90)은 그대로이고 별개다.
- **구현됨**: 해마다 머리의 보급 또는 집행(조율) 의뢰(대상 8명, 준비물 5종), 1막 줄기 4편(발톱: 동료의 실종 / 마지막 집행서 / 가장자리의 흔적 / 집행의 밤, 조율자: 조율 통지서 / 서류 심사 / 다른 금기자 / 균열의 보고), 의뢰 사이의 조용한 사건, 2막 줄기 7편(머리의 이유 없는 명령 → 휘말림 → 차원 유랑 → 도시의 추격자(발톱 줄기는 제나, 조율자 줄기는 바랄) → 두 번째 길 → 외곽에서 온 존재 → 73년차 마지막 선택), 전용 무기 2단계 강화(발톱·요정), 엔딩 4종(`clawreturn` · `clawstay` · `arbkeep` · `arbdown`), 새 적 2종(외곽의 사냥꾼, 외곽에서 온 존재).
- **자동 전투 결과(30판)**: 발톱 완주 67%, 조율자 73%.
- **아직 안 한 것**: 1막 중반(약 38~55년차) 사이를 채우는 줄기, 차원 유랑 장면 추가, 의뢰 대상 목록 확대(지금 8명), 전용 BGM, 수치 정밀 조정.
