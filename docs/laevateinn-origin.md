# 레바테인 전용 출생 설계 (별도 브랜치 `laev-origin-dev`, 2026-11-17)

> 본섭·테섭(`v8-dev`)에는 넣지 않는다. 이 브랜치에서만 만들고, 사용자가 올리라고 할 때 합친다.

## 배경
- 원작 레바테인을 쥐었던 인물은 마티아스. 중지 소속이었고, 자신의 큰누님·큰형님을 죽이고 유적에서 레바테인을 훔쳐 나락으로 떨어졌다.
- 게임에는 이미 히든 보스 '중지의 큰형님 마티아스'(`matthias`), '배신자 마티아스'(`pil_matthias`), '줄 그어진 마티아스'(`matthias2`)가 있다. 새 출생은 마티아스 본인이 아니라 **같은 길을 간 다른 사람**으로 두어 겹치지 않게 한다.
- 레바테인은 이미 잊힌 유물 '레바테인 봉인'(`laev`)으로 있다: 공+4 · 적중마다 붉은 화염 1 · 화염을 건 횟수 20/45/80에 1단계·2단계·해방.
- 검색으로 확인된 원작 특징: 전투 시작에 화상을 거는 것, 상대의 화상+출혈 합계가 높을수록 기본 공격 피해가 오르는 것. 세부 스킬 목록은 확인하지 못했다(원작 스킬은 따라 쓰지 않는다).

## 안 (확정 대기)
| 항목 | 내용 |
|---|---|
| 출생 이름 | 「나락의 도둑」(후보: 「유적을 턴 동생」) |
| 시작 장비 | 레바테인 봉인 |
| 능력치 | 공격 +2 · 최대 HP +4 · 회피 −1 |
| 전용 카드 | 9장, 화염·출혈 중심. 상대의 화상+출혈이 높을수록 피해 상승 |
| 봉인 시너지 | 카드로 거는 붉은 화염도 해방 횟수에 센다 |
| 중지의 시선 | 1년차부터 중지 쪽 추격자가 가끔 찾아온다(약한 추격자 위주) |
| 약점 | 해방 후 자신에게도 화상 · 중지 쪽 진로·보상 닫힘 |
| 마티아스 연결 | 마티아스 보스를 만나면 "나보다 먼저 같은 검을 쥐었던 사람" 취지의 새 대사 한 줄 |

## 결정할 것
1. 출생 이름  2. 중지 추격 포함 여부  3. 마티아스 연결 대사 포함 여부

## 작업 순서
1. 전용 카드 9장의 한국어 효과 초안 → 사용자 확인
2. 데이터(`hiddenOrigins`, 카드) 추가 → `npm run -s check`
3. 봉인 해방 속도·승률 시뮬 → 다른 숨은 출생과 균형 비교
4. 이 브랜치 전용 시험판으로 확인 → 사용자가 확인한 뒤에만 `v8-dev`에 합친다
