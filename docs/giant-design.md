# 거인(해금 직업) 설계 초안 (2026-11-16, 사용자 방향 + 제안 · 확인 대기)

## 1. 사용자 방향 (확정)
- 거인은 **N사 시지프 백화점을 관리하는 존재**다. 기존 카드 전투와 **전혀 다른 방식**으로 한다(2026-11-11).
- 진행 방식은 **페이퍼 플리즈 같은 느낌**: 도트로 그려진 백화점 내부에서 **빨간 위험 표시가 뜨면 그것을 해결**하는 식이다.
- 전투는 아직 정하지 않았다. 무한 모드는 없을 수도 있고, 둔다면 "거인 활동 중 백화점이 붕괴한 이후부터 활성화" 같은 안이 있다.
- 열려 있는 질문: ① 아바타 상태로 전투할 수 있게 할지 ② 거인 아바타를 여러 종류로 만들지.

## 2. 제안 구조 (권장)
**1막 = 관리(전투 없음), 붕괴 이후 = 아바타로 밖에서 기존 방식.**

| 구간 | 하는 일 | 시스템 |
|---|---|---|
| 1막(약 40~55턴) | 백화점 도트 화면에서 위험 표시를 해결한다 | 새 시스템(관리) · 전투 없음 |
| 붕괴 | 해결하지 못한 위험이 쌓여 백화점이 무너진다 | 사건 연쇄(시지프 4단계와 같은 틀) |
| 2막~ | 거인이 **아바타**를 밖으로 내보내 도시를 돌아다닌다 | 기존 카드 전투 · 무한 모드 활성 |

### 2-1. 관리 화면 (페이퍼 플리즈식)
- 한 턴(=하루)마다 층별 도트 화면에 **빨간 위험 표시** 1~3개가 뜬다(예: 정신이 무너져 가는 고객, 황금송진 도난, 르누아르·르루주 충돌, 간수 호출 요청, 재고 정리 승인 요구).
- 표시를 눌러 **조사**(시간·인력 소모) 후 **처리**를 고른다. 처리 수단은 자원이 정해져 있다: 점원(인력), 안, 통조림 품질, 간수 호출권, 안내방송.
- 처리의 결과는 **고객 만족 · 정신 안정 · 붕괴 게이지 · 세력 호감**에 ±로 반영된다. 하루가 끝날 때 못 푼 표시는 붕괴 게이지를 올린다.
- 압박은 자원 부족과 표시 수에서 오고, 실시간 제한 시간은 두지 않는다(턴제, 모바일 조작 우선).
- 장면은 도트 이미지(층 배경, 마네킹·고객·점원 스프라이트, 위험 표시)다. **이미지는 사용자에게 요청**한다. 이미지가 없는 동안은 사각형 칩과 글자로 동작하게 만든다.

### 2-2. 붕괴와 무한 모드
- 붕괴 게이지가 차거나 정해진 턴에 이르면 백화점이 무너진다(시지프의 붕괴와 같은 현상을 위쪽에서 본 이야기).
- 붕괴 후 거인은 백화점을 잃고 **아바타를 밖에 둔다**. 이때부터 기존 게임 방식(나이 진행 · 일반 사건 · 카드 전투)으로 진행하고 **무한 모드를 연다**. 이 방식이면 새로 만들 것은 관리 화면 하나뿐이고, 전투·무한 모드·성장은 기존 것을 쓴다.
- 무한 모드를 아예 두지 않는 대안: 붕괴로 끝나는 짧은 직업(약 50턴)으로 하고 기록과 칭호만 남긴다. 제작량은 줄지만 재도전 동기가 약하다.

### 2-3. 아바타 전투 (2026-11-16 개정: 침입자 전투 추가)
- 관리는 전투 없이 위험 해결로 진행하되, **순환을 망치려는 침입자는 직접 상대하는 전투로 들어갈 수 있다**(사용자 아이디어, 5번 참고). 이 전투는 기존 카드 전투를 쓰고, 한 판에 몇 번만 나오는 특별 사건이다.
- 아바타는 거인이 백화점 밖에서 쓰는 몸이라서, 전투 때의 능력은 관리 중의 선택이 정한다(아래).

### 2-4. 아바타 종류
- **여러 종류를 둔다. 권장은 세력별 4종**(르누아르 · 르루주 · 르카키 · 르네앙). 관리 중에 어느 세력을 많이 도왔는지(세력 호감)가 아바타 종류를 정한다. 시지프의 "옷을 만든 성향에 따라 소속이 정해지는" 판정과 같은 방식이라 구현을 재사용할 수 있다.
- 종류마다 전용 카드 책장(8~10장), 전투 규칙 한 가지(예: 르누아르 = 보존·충전, 르루주 = 출혈·충전, 르카키 = 유행, 르네앙 = 허무)를 가진다.
- 아바타가 쓰러지면 **다른 종류의 아바타로 이어 가는** 목숨 시스템은 선택 사항이다(2막이 길어지는 것을 막지만 판의 맛이 달라진다).

## 3. 제작 단계(제안)
1. 설계 확정(이 문서의 질문들).
2. 관리 화면 엔진·데이터(위험 표시 약 20종, 자원, 붕괴 게이지) — 이미지 없이 칩으로 동작.
3. 붕괴 사건과 아바타 전환(세력 판정, 책장 지급, 무한 모드 열기).
4. 도트 이미지 요청과 연결(층 배경 · 스프라이트 · 위험 표시), 시험·번역.

## 4. 확인이 필요한 것
1. 구조: **1막 관리 → 붕괴 → 아바타로 밖에서 기존 방식(무한 모드 포함)** 으로 가도 되는지.
2. 관리 화면은 **턴제 + 자원** 방식으로(실시간 제한 시간 없음) 가도 되는지.
3. 아바타 종류를 **세력별 4종**으로 할지, 다른 기준(예: 위험을 해결한 방식별)으로 할지.
4. 아바타가 쓰러졌을 때 다른 종류로 이어 가는 목숨 시스템을 둘지.
5. 해금 조건(시지프 백화점을 어떻게 겪어야 거인이 열리는지)은 아직 정하지 않았다.

## 5. 화면 구성과 침입자 전투 (2026-11-16, 사용자 참고 이미지: 페이퍼 플리즈)
화면은 한 장에 세 영역을 둔다(모바일은 탭으로 나눈다).

```
┌───────────────────────────┬─────────────────────┐
│ 왼쪽: 백화점 안에서 일어나는 │ 오른쪽 위: 조작 패널  │
│ 일(층 도트 화면·고객·점원·   │ (조사 / 승인 / 거부 /  │
│ 위험 표시)                  │ 호출 / 정리 등 버튼)   │
│                           ├─────────────────────┤
│                           │ 오른쪽 아래: 관리 안내문│
│                           │ (오늘의 규칙, 허용·금지)│
└───────────────────────────┴─────────────────────┘
```
- **관리 안내문**이 규칙집이다. 하루마다 규칙이 바뀌거나 늘어난다(예: 오늘은 토파즈 등급 고객은 지하 2층 출입 금지, 통조림 품질 B 미만은 반출 불가).
- **위험 표시 = 규칙 위반의 의심.** 눌러서 조사하면 고객의 상태·소지품·등급·행동이 보이고, 안내문과 비교해 어긋난 곳을 찾는다(페이퍼 플리즈식 대조). 대응은 승인·거부·간수 호출·정리(재고 정리 신청) 중에서 고른다.
- 잘못 판단하면 고객 만족·정신 안정이 깎이거나 붕괴 게이지가 오른다. 제대로 판단해도 자원(점원 인력·안·호출권)이 든다.

### 5-1. 순환을 망치려는 침입자 (직접 조지는 전투)
- 안내문의 규칙 가운데 **"정해진 결말"과 "순환"을 어기려는 자**는 위반자와 다르다. 이들은 조사로 정체가 드러나면 **전투로 돌입**한다(실패하면 규칙 위반 누적, 이기면 붕괴 게이지 감소와 보상).
- 침입자 후보(이름과 구조만, 문장은 새로 쓴다): 밖에서 온 이방인, 재고 정리를 거스르려는 고객, 황금송진을 훔쳐 가려는 자, 허기에 휘둘리는 붉은 신의 줄기. 시지프 직업으로 플레이한 판의 "이방인"을 침입자로 쓰는 연결도 가능하다(선택).
- 전투는 기존 카드 전투를 쓴다. 거인은 **아바타를 불러내 싸운다**(아바타 종류 = 4번 참고). 침입자 전투는 한 판에 3~5번만 나오게 해서 관리 화면의 주인공 감각을 해치지 않는다.
- 이 전투는 위 2-3의 "붕괴 이후에만 전투"를 **바꾼다**: 1막에서도 침입자 전투가 나온다(관리 화면 중간에 전투로 전환 → 끝나면 관리 화면으로 복귀).

### 5-2. 제작 영향
- 새로 만들 것: 3분할 화면, 규칙집·대조 시스템(규칙 20~30개, 위반 유형), 침입자 전투 연결.
- 기존 전투·카드·무한 모드는 그대로 쓴다.
- 확인이 필요한 것: ① 3분할 화면의 이미지(도트 스프라이트·층 배경)는 사용자에게 요청한다. ② 규칙집이 어려워져 모바일에서 읽기 힘들 수 있어, 규칙은 하루 최대 5개로 제한하고 안내문 아래 요약 줄을 둔다.
