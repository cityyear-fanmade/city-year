# 해금 출생 · 까마귀팀 설계안 (초안 · 2026-10-29)

상태: 설계 제안. 거미집은 보류하고 이 작업을 먼저 한다. 테섭(v8-dev)에서만 구현한다.
관련: `docs/design-hidden-unlock.md`(신탁대행자·도서관 지정사서), `docs/design-rh-route.md`(R사 부화장 루트).

## 1. 지금 구조 (확인한 것)
- 숨은 출생 7종(`birth.json.hiddenOrigins`)은 출신 굴림이 그 번호에 걸리거나 "아무것도 없는 출발" 운명(`blankFate`)에서만 나온다. 해금 개념이 없다.
- 해금 저장소 `cityYearUnlocks`(히든 직업 claw/arbiter가 쓴다)와 보스 승리 시 해금 훅(`ui.js` `r.unlock`)이 이미 있다.
- `newChar(직업, 출신굴림)`의 두 번째 인자로 출신을 고정하는 길이 이미 있다(오늘의 시드가 쓴다).
- 까마귀팀은 R사 부화장 루트에서 **추격대 보스(rh2)** 로만 나온다. 카드 `rv_0`~`rv_9` 10장과 패시브 '까마귀의 눈'(`CFG.raven`)은 만들어져 있지만 플레이어가 쓸 길이 없다.

## 2. 해금 출생 (제안)
| 항목 | 내용 |
|---|---|
| 해금 키 | `origin:<출신 번호>`를 `cityYearUnlocks`에 저장 (직업 해금과 같은 저장소) |
| 해금 조건 | **무한 모드 전, 2막 끝까지 간다**(2막 엔딩 화면에 닿으면 인정, 사망하면 불인정). 그 판이 ① 특정 출생으로 시작했거나 ② 특정 아이템을 들고 있으면 해금. 우연히 굴려서 시작한 판이어도 된다 |
| 출생 화면 | 히든 직업 패널 옆에 **'해금된 출생'** 패널. 목록에서 하나를 고르면 출신이 그것으로 고정된다 |
| 다시 태어난다 | 출신은 고정. 재능·결점·무기·성장기·타고난 것만 다시 굴린다. 출신 전용 선택(팀 고르기 등)은 그대로 둔다 |
| 안 되는 곳 | 오늘의 시드(출신 지정일), 도전 모드. 기록은 일반 판과 같이 쌓는다 |
| 난이도 | 숨은 출생은 원래 강한 쪽이라, 선택 시작에도 별도 불이익은 두지 않는다. 대신 해금 조건을 엔딩으로 잡아 문턱을 둔다 |

구현은 `newChar`에 출신 고정 인자를 쓰고, 출생 화면에 `UI.origin`을 추가하는 정도다. 엔진 규칙 변경은 없다.

## 3. 해금 조건안 (확정 방향: 2막 끝까지 + 특정 출생 또는 특정 아이템)
공통: 2막 엔딩 화면에 닿은 판만 센다. 판정 위치는 '무한 모드로 들어가기' 직전(`infinite()` 호출 전)이다.

| 해금되는 출생 | ① 이 출생으로 2막 끝까지 | ② 이 아이템을 들고 2막 끝까지 (제안) |
|---|---|---|
| 보냐텔리 가문 | 해당 | 보냐텔리 가문 전용 장비 |
| 동부 출신 외곽 생존자 | 해당 | 외곽에서 얻는 전용 장비 |
| E.G.O 적성자 | 해당 | E.G.O 무기 최종 단계 |
| 부화장에서 태어난 자 | 해당 | — |
| **까마귀팀 복제체**(신규) | **부화장 출생으로 2막 끝까지** (부화장 선택과 함께 열린다) | 까마귀팀 카드 `rv_*` 6장 이상을 덱에 가진 채 (다른 길로 얻었을 때) |
| 홍원의 자제 | 해당 | 홍원 소장품(`hw_*` 장비) |
| 별에 선택받은 자 | 해당 | 별 관련 유물 |
| 대호수로 나간 자 | 해당 | 대호수 작살 |
| 신탁대행자(신규) | — | **신의 단말기(헤르메스)** |
| 도서관 지정사서(신규) | 도서관의 손님 출신 | — |

- 아이템 쪽은 '그 아이템을 얻는 길이 이미 있는 것'만 둔다. 없는 출생은 ①만 쓴다.
- 까마귀팀은 내부적으로 부화장 출생 + 팀 고정이다. 출생 목록에는 별도 항목으로 보인다.
- 같은 판에서 ①②가 겹치면 한 번만 센다. 이미 해금된 출생은 다시 알리지 않는다.

## 4. 까마귀팀 출생
- **이름**: 부화장 출신의 다른 팀. 출신 이름 "까마귀팀 복제체"(가칭).
- **루트**: 부화장 출생과 같은 R사 루트를 쓴다(13연전 → 탈출 → R사 날개 → 탈주 → 추격 → 조율자 → 숙청 집행관). 달라지는 것은 팀뿐이다.
- **팀 보정**: 토끼 속도+3, 순록 회피+3, 코뿔소 HP+10에 맞춰 까마귀는 **명중+4**(정찰·무전 계열과 맞춤)로 잡는다.
- **전용 카드**: `rv_0`~`rv_9`를 책장으로. 시작 덱은 기존 부화장처럼 고정 8장(rv 4종 + 기본 카드).
- **전용 무기**: 까마귀 부리 단검(가칭) — 출혈 중심. 출혈 카드가 많아 기존 흑운회·밤의 송곳과 겹치므로, 수치는 같은 구간으로 맞춘다.
- **패시브 '까마귀의 눈'**: 이미 있는 `CFG.raven`을 그대로 쓴다(적중마다 버프 1개 제거, 6장 명중+10, 8장 주사위당 +1, 10장 방어·회피 봉쇄).
- **추격대**: 내 팀이 까마귀이면 추격에서 까마귀팀 대장이 빠지고 토끼·순록·코뿔소 대장이 온다(기존 규칙 '내 팀 제외' 그대로).
- **숫자 번호**: 부화장(30)과 별개 번호를 받는다. 새 번호는 `blankFate` 풀에 넣지 않는다(해금으로만 나온다).

## 5. 구현 순서
1. 출생 화면 '해금된 출생' 패널 + 출신 고정 시작 (기존 출생 7종 먼저, 해금 키만 연결)
2. 해금 훅: 2막 엔딩 화면(무한 모드 진입 직전)에서 출생·소지품을 보고 `origin:*` 저장
3. 까마귀팀 복제체: `birth.json`, 팀 보정, 카드 책장, 무기, 추격 제외 처리
4. 신탁대행자·도서관 지정사서는 별도 설계서 순서대로 뒤에 붙인다
5. `check` + Playwright: 선택 시작, 다시 태어난다(출신 고정), 해금 전 잠금 표시

## 6. 정할 것
1. ②번 열의 아이템 후보가 맞는지(특히 별·보냐텔리·외곽)
2. 선택 시작을 보통 난이도 이상에서만 열지(해금은 난이도 상관없이 인정할지 포함)
3. 까마귀 전용 무기 이름과 수치 방향(출혈 / 명중 중심)
4. 해금 화면(기록실)에 출생 목록을 어떻게 보여줄지 — 히든 직업 패널 아래 같은 모양이면 충분하다고 본다

## 7. 까마귀팀 출생 스토리 (개정 · 2026-10-29)
**방향 전환**: 까마귀팀 출생은 부화장 13연전 루트를 그대로 쓰지 않고, **'처분' 루트**로 간다. 부화장 출생이 2막 끝까지 간 사람이 여는 해금 출생이라는 점은 그대로다.

| 항목 | 내용 |
|---|---|
| 정체 | R사 최상위 부대 까마귀팀의 대원. 다른 팀이 임무에 실패하거나 복제 시스템에 문제가 생겼을 때 **처분 판정**을 받은 대상을 정리한다 |
| 모티브 | 제4무리 사령관(검은 검신에 금색·주황색 장식의 세이버, 뒷골목 출신)을 모티브로 한 **사령관 계승** 서사. 이름·대사는 원문을 쓰지 않고 이 게임용으로 새로 쓴다 |
| 전용 무기 | 검은 세이버(가칭). 충전을 모아 한 번에 베는 **참수/처형형**, 암전(시야를 가려 방어를 무력화) 계열 카드와 묶는다. 기존 `rv_*` 10장을 책장으로 쓴다 |
| 공방 거리 | 없음(R사 보급과 처분 의뢰만). 부화장·홍원 루트와 같은 방식 |
| 만나는 적 | **무한 모드 전까지 일반 조우 없음.** 전용 몹 보스와 기존 히든 보스만 만난다 |

### 진행 틀
| 시기 | 내용 |
|---|---|
| 출생 | 까마귀팀 대원으로 배치. 전용 카드·검은 세이버 지급 |
| 1막 | 해마다 **처분 의뢰 한 건**: 대상 소개 → 선택(처분한다 / 보류한다) → 고정전. 대상은 기존 보스를 재사용한다(제3무리 추격조장, 제4무리 토끼·순록·코뿔소 팀 대장, 탈주한 복제체 등) |
| 1막 후반 | 처분 의뢰의 이유가 점점 이상해진다(실패한 팀이 아니라 '지나치게 자란 복제체'가 대상이 된다). 보류를 고른 횟수가 이후 갈래를 정한다 |
| 전환 | 사령관의 자리가 비고, 까마귀팀 대원이 그 자리를 맡을 후보가 된다 |
| 2막 | 사령관 계승전: 숙청 집행관 · 조율자 등 기존 히든 보스와의 고정전. 처분 명령을 내린 쪽을 마지막에 만난다 |
| 엔딩 | 사령관 계승(검은 세이버를 든다) / 처분 명령 거부 두 갈래 (무한 모드 문구도 갈래별) |

### 규칙 메모
- **처분 선택**은 정신력과 엔딩 갈래에만 영향을 준다. 전투 수치는 건드리지 않는다.
- 고정전 대상은 새로 만들지 않고 기존 보스·`rh*` 적을 재사용해서 분량을 줄인다. 전용 몹 보스는 사령관 계승전용 1~2종만 새로 만든다.
- 이름 확인이 필요하다: '보냐텔리아' 님의 처분이라는 표현은 원문 표기를 확인한 뒤에 쓴다(게임 안의 '보냐텔리 가문' 출생과 같은 인물인지도 포함).

## 8. 구현 메모 (2026-10-29)
- **굴림 번호 히든 출생(7종)과 해금 출생은 별개다.** 해금 출생은 `birth.json.unlockOrigins`(새 목록)에만 둔다. 지금은 비어 있어서 화면에 아무것도 나오지 않는다.
- 항목 형식: `{key, n, t, e, cond:{origin:'출생 이름'} 또는 {item:'아이템 id'}, ...출신 데이터(fx, deck, gear 등)}`
- 해금: 무한 모드 전 2막 끝까지 간 판이 `cond`를 만족하면 `cityYearUnlocks`에 `origin:<key>` 저장, 2막 끝 화면에 '출생 해금' 알림.
- 선택: 출생 화면 '해금된 출생' 패널. 고르면 출생 고정, 다시 태어나면 나머지만 새로 굴린다. 오늘의 시드에서는 숨긴다.
- 앞의 3절 표에서 굴림 번호 히든 출생이 해금 대상으로 적힌 행은 무효다. 해금 대상은 까마귀팀, 신탁대행자, 도서관 지정사서 같은 신규 출생뿐이다.

## 9. 해금 출생은 이야기 줄기에 따라 1막·2막·공방 거리를 바꾼다 (요청 · 2026-10-29)
해금 출생마다 자기 이야기 줄기를 갖고, 그 줄기에 맞춰 판의 틀이 달라진다.

현재 구조(확인함): R사 부화장·홍원 루트는 `engine.js`의 공방 거리 판정(`shopDue` ... `!(ch.rb&&!ch.rb.out)`)에서 루트 조건으로 공방 거리를 건너뛰고, 전용 사건 풀을 쓴다. 이 방식을 해금 출생에도 쓸 수 있게 일반화한다.

### 출생 데이터에 둘 항목 (`unlockOrigins[*].route`)
| 항목 | 뜻 |
|---|---|
| `shop` | `false`면 공방 거리 없음. 대신 `shopAlt`로 그 출생 전용 상점/보급 사건을 둘 수 있다 |
| `act1` | 1막 연례 사건 풀을 이 목록으로 바꾼다(일반 풀 대체 또는 일부 섞기) |
| `act2` | 2막 연례 사건·위협 등급 진행을 이 목록으로 바꾼다 |
| `fixed` | 고정전 순서(연도, 적 id). 만나는 적은 이 목록 + 히든 보스만 |
| `end` | 엔딩 갈래와 무한 모드 문구 |

### 출생별 방향
| 출생 | 공방 거리 | 1막 | 2막 |
|---|---|---|---|
| 까마귀팀 복제체 | 없음(R사 보급·처분 의뢰) | 해마다 처분 의뢰 1건 | 사령관 계승전 |
| 신탁대행자 | 없음 또는 신탁 중계소로 대체 | 신탁 수행(기존 신탁 사건 확장) | 헤르메스의 주인과의 대결 |
| 도서관 지정사서 | 없음(도서관 안) | 손님 맞이 | 환상체전(책이 요동친다) |
| 조율자 | 없음 | 봉인·집행 의뢰 | 다른 존재와의 싸움 |

### 구현 순서
1. 엔진에 `route` 해석을 넣는다(공방 거리 건너뛰기, 사건 풀 교체, 고정전 목록). 기존 R사·홍원 루트는 그대로 둔다.
2. 출생 하나(까마귀팀)로 끝까지 시험한다.
3. 나머지 출생은 같은 틀에 데이터만 더한다.

## 10. 구현 현황 (2026-10-29)
- **route 엔진**: `engine.js`의 `routeOf/routeStep/routeFight/routeFree`. 출생 데이터의 `route` 이름으로 `birth.json.routes`를 읽는다. 공방 거리 생략(`shop:false`), 연례 사건 풀 교체(`yearly.act1/act2`), 고정전(`fixed:[{y,enemy,label}]`)·2막 등급전(`grade:[등급별 적]`) 교체, 줄기가 있으면 일반 조우를 끈다(`noFight:false`로 되돌림). 무한 모드에 들어가면 일반 규칙으로 돌아온다.
- **처분 의뢰(`hunt`)**: 해마다 'R사 보급 / 처분 의뢰' 선택 → 처분 의뢰를 고르면 같은 해 안에 준비물 고르기(최대 3개, 해를 쓰지 않는 단계) → `gap`년(기본 2년) 뒤 처분 대상 사건과 전투. 준비물의 `fx`는 수색을 시작할 때 적용된다.
- **시작 보너스(`start:{lv,fx}`)**: 해금 출생과 히든 직업에 레벨과 능력치를 얹어 시작한다. 해금 출생 기본은 레벨 8, 조율자·발톱은 레벨 12와 큰 능력치.
- **까마귀팀 복제체**: `unlockOrigins`에 초안으로 들어 있다(조건: 부화장 출생으로 2막 끝). 1막 동안 처분 대상은 4명뿐이라 뒤의 해는 연례 사건으로 채워지는 상태이므로 대상·사건을 더 써야 한다.

## 11. 임무는 한 줄기씩 이어서 (개정 · 2026-10-29)
임무를 연차 순으로 섞지 않고, 이야기 줄기(`arc`)마다 순서대로 이어서 낸다. 줄기가 열려 있는 동안에는 다른 줄기의 임무도, 새 처분 의뢰도 나오지 않는다(사이 해는 연례 사건으로 채운다). 임무는 앞 임무(`after`)와 간격(`gap`)으로 이어진다.

| 줄기 | 순서 | 비고 |
|---|---|---|
| 홍원 가주 승계 (12년차~) | 심사를 지켜본다 → R사의 후보 관련 의뢰 → 후보 곁의 임무(전투) → 가주 승계 마무리 작업(**무기 1차 강화**) → 반란 세력 제압(전투) → 즉위 | 처음 고른 후보(가환/설보차)가 끝까지 이어진다 |
| 날개 (26년차~) | 날개 직원 호송 → 날개 내부 감사 → 환상체 제압 의뢰(**무기 2차 강화**) | |
| R사 내부 (34년차~) | 실패한 팀의 사후 정리 → 복제체 회수 현장 입회 | |

### 해금 출생의 시작 조건 (정리)
- 레벨 8 시작 + 능력치 보너스
- 전용 책장(카드팩, 덱 고정)
- **처음부터 키운 전용 무기**: 명장급으로 시작하고, 임무 이정표에서 두 번 강화되어 히든급이 된다(`CFG.routeWeapon.<줄기>.lv`, 임무 선택지의 `routeWpn`)

## 12. 까마귀팀 2막: 사령관 계승 (구현 · 2026-10-29)
2막(56~73년차)은 한 줄기(`cmd`)의 임무 6개가 위협 등급 간격(3년)으로 이어지고, 일반 등급 전투 대신 이 임무의 전투를 치른다.

| 연차 | 임무 | 상대 |
|---|---|---|
| 58 | 사령관의 부름 | R사 숙청 집행관 |
| 61 | 뒤틀린 복제체 | 뒤틀린 얀 |
| 64 | 두 번째 뒤틀림 | 뒤틀린 쥰 |
| 67 | 사령관의 서고 | (전투 없음 · 기록을 끝까지 읽으면 `crow_truth` 기록) |
| 70 | 발톱이 선 자리 | 발톱 · 바랄 |
| 73 | 처분 명령을 내린 쪽 | 조율자 · 제나 (자리를 잇는다 `crow_succeed` / 명령을 거부한다 `crow_refuse`) |

- 상대 능력치는 줄기의 `trial`(상대 id별 HP 배율, 공격 가감)로 낮춘다. 자동 전투 시뮬 150판 기준 1막~2막 완주 약 50%.
- 엔딩 갈래(`crow_succeed/crow_refuse/crow_truth`)는 기록만 해 두었고, 엔딩 문구와 무한 모드 문구는 아직 없다.
