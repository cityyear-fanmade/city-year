# 해금 출생 · 까마귀팀 설계안 (초안 · 2026-10-29)

상태: 설계 제안. 거미집은 보류하고 이 작업을 먼저 한다. 테섭(v8-dev)에서만 구현한다.
관련: `docs/design-hidden-unlock.md`(신탁대행자·도서관 지정사서), `docs/design-rh-route.md`(R사 부화장 루트).

## 1. 지금 구조 (확인한 것)
- 숨은 출생 7종(`birth.json.hiddenOrigins`)은 출신 굴림이 그 번호에 걸리거나 "아무것도 없는 출발" 운명(`blankFate`)에서만 나온다. 해금 개념이 없다.
- 해금 저장소 `cityYearUnlocks`(히든 직업 claw/arbiter가 쓴다)와 보스 승리 시 해금 훅(`ui.js` `r.unlock`)이 이미 있다.
- `newChar(직업, 출신굴림)`의 두 번째 인자로 출신을 고정하는 길이 이미 있다(오늘의 시드가 쓴다).
- 까마귀팀은 R사 부화장 루트에서 **추격대 보스(rh2)** 로만 나온다. 카드 `rv_0`~`rv_9` 10장과 패시브 '까마귀의 눈'(`CFG.raven`)은 만들어져 있지만 플레이어가 쓸 길이 없다.

## 2. 해금 출생 (제안)
| 항목 | 내용 |
|---|---|
| 해금 키 | `origin:<출신 번호>`를 `cityYearUnlocks`에 저장 (직업 해금과 같은 저장소) |
| 해금 조건 | **무한 모드 전, 2막 끝까지 간다**(2막 엔딩 화면에 닿으면 인정, 사망하면 불인정). 그 판이 ① 특정 출생으로 시작했거나 ② 특정 아이템을 들고 있으면 해금. 우연히 굴려서 시작한 판이어도 된다 |
| 출생 화면 | 히든 직업 패널 옆에 **'해금된 출생'** 패널. 목록에서 하나를 고르면 출신이 그것으로 고정된다 |
| 다시 태어난다 | 출신은 고정. 재능·결점·무기·성장기·타고난 것만 다시 굴린다. 출신 전용 선택(팀 고르기 등)은 그대로 둔다 |
| 안 되는 곳 | 오늘의 시드(출신 지정일), 도전 모드. 기록은 일반 판과 같이 쌓는다 |
| 난이도 | 숨은 출생은 원래 강한 쪽이라, 선택 시작에도 별도 불이익은 두지 않는다. 대신 해금 조건을 엔딩으로 잡아 문턱을 둔다 |

구현은 `newChar`에 출신 고정 인자를 쓰고, 출생 화면에 `UI.origin`을 추가하는 정도다. 엔진 규칙 변경은 없다.

## 3. 해금 조건안 (확정 방향: 2막 끝까지 + 특정 출생 또는 특정 아이템)
공통: 2막 엔딩 화면에 닿은 판만 센다. 판정 위치는 '무한 모드로 들어가기' 직전(`infinite()` 호출 전)이다.

| 해금되는 출생 | ① 이 출생으로 2막 끝까지 | ② 이 아이템을 들고 2막 끝까지 (제안) |
|---|---|---|
| 보냐텔리 가문 | 해당 | 보냐텔리 가문 전용 장비 |
| 동부 출신 외곽 생존자 | 해당 | 외곽에서 얻는 전용 장비 |
| E.G.O 적성자 | 해당 | E.G.O 무기 최종 단계 |
| 부화장에서 태어난 자 | 해당 | — |
| **까마귀팀 복제체**(신규) | **부화장 출생으로 2막 끝까지** (부화장 선택과 함께 열린다) | 까마귀팀 카드 `rv_*` 6장 이상을 덱에 가진 채 (다른 길로 얻었을 때) |
| 홍원의 자제 | 해당 | 홍원 소장품(`hw_*` 장비) |
| 별에 선택받은 자 | 해당 | 별 관련 유물 |
| 대호수로 나간 자 | 해당 | 대호수 작살 |
| 신탁대행자(신규) | — | **신의 단말기(헤르메스)** |
| 도서관 지정사서(신규) | 도서관의 손님 출신 | — |

- 아이템 쪽은 '그 아이템을 얻는 길이 이미 있는 것'만 둔다. 없는 출생은 ①만 쓴다.
- 까마귀팀은 내부적으로 부화장 출생 + 팀 고정이다. 출생 목록에는 별도 항목으로 보인다.
- 같은 판에서 ①②가 겹치면 한 번만 센다. 이미 해금된 출생은 다시 알리지 않는다.

## 4. 까마귀팀 출생
- **이름**: 부화장 출신의 다른 팀. 출신 이름 "까마귀팀 복제체"(가칭).
- **루트**: 부화장 출생과 같은 R사 루트를 쓴다(13연전 → 탈출 → R사 날개 → 탈주 → 추격 → 조율자 → 숙청 집행관). 달라지는 것은 팀뿐이다.
- **팀 보정**: 토끼 속도+3, 순록 회피+3, 코뿔소 HP+10에 맞춰 까마귀는 **명중+4**(정찰·무전 계열과 맞춤)로 잡는다.
- **전용 카드**: `rv_0`~`rv_9`를 책장으로. 시작 덱은 기존 부화장처럼 고정 8장(rv 4종 + 기본 카드).
- **전용 무기**: 까마귀 부리 단검(가칭) — 출혈 중심. 출혈 카드가 많아 기존 흑운회·밤의 송곳과 겹치므로, 수치는 같은 구간으로 맞춘다.
- **패시브 '까마귀의 눈'**: 이미 있는 `CFG.raven`을 그대로 쓴다(적중마다 버프 1개 제거, 6장 명중+10, 8장 주사위당 +1, 10장 방어·회피 봉쇄).
- **추격대**: 내 팀이 까마귀이면 추격에서 까마귀팀 대장이 빠지고 토끼·순록·코뿔소 대장이 온다(기존 규칙 '내 팀 제외' 그대로).
- **숫자 번호**: 부화장(30)과 별개 번호를 받는다. 새 번호는 `blankFate` 풀에 넣지 않는다(해금으로만 나온다).

## 5. 구현 순서
1. 출생 화면 '해금된 출생' 패널 + 출신 고정 시작 (기존 출생 7종 먼저, 해금 키만 연결)
2. 해금 훅: 2막 엔딩 화면(무한 모드 진입 직전)에서 출생·소지품을 보고 `origin:*` 저장
3. 까마귀팀 복제체: `birth.json`, 팀 보정, 카드 책장, 무기, 추격 제외 처리
4. 신탁대행자·도서관 지정사서는 별도 설계서 순서대로 뒤에 붙인다
5. `check` + Playwright: 선택 시작, 다시 태어난다(출신 고정), 해금 전 잠금 표시

## 6. 정할 것
1. ②번 열의 아이템 후보가 맞는지(특히 별·보냐텔리·외곽)
2. 선택 시작을 보통 난이도 이상에서만 열지(해금은 난이도 상관없이 인정할지 포함)
3. 까마귀 전용 무기 이름과 수치 방향(출혈 / 명중 중심)
4. 해금 화면(기록실)에 출생 목록을 어떻게 보여줄지 — 히든 직업 패널 아래 같은 모양이면 충분하다고 본다
