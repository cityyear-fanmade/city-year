# 시지프 번역 준비 (2026-11-18, 번역은 아직 하지 않음)

순서(작업 방침): 한국어 확정 → 제미나이로 번역 → 내가 훑어 고침 → 일본어 화면에서 적용 확인.
제미나이는 무료 한도 안에서만 쓰고, 호출 전에 횟수를 먼저 알려 확인받는다. 키는 환경 변수로만 쓴다.

| 언어 | 데이터 문장 | 화면 문구(코드) | 호출 횟수 |
|---|---|---|---|
| 일본어 | 1456 | 1740 | 15 + 18 = 33 |
| 영어 | 1456 | 1740 | 15 + 18 = 33 |

- 이 숫자에는 시지프 말고 기존 게임의 미번역 문장도 포함돼 있을 수 있다. 시지프만 따로 세려면 시지프 데이터만 뽑는 필터를 추가한다.

## 번역 전에 확정해야 할 것
1. 한국어 문구 확정: `docs/sisyphus-text-review-3.md`와 설명 문구 줄이기(`docs/sisyphus-text-trim-list.md`) 결정이 끝나야 한다. 문구를 고치면 번역이 다시 필요하다.
2. 고유명사 영어·일본어 표기. 아래 목록에서 **공식 표기가 있는 것은 알려 주셔야** 한다. 모르는 이름은 임의로 번역하지 않는다.
