# G사 병기 출신 해금 출생 기본 설계안 (2026-10-31)

해금 출생 틀(`design-unlock-origin.md`, route 엔진)에 **G사 병기 출신**을 올리는 기본 설계. `design-hidden-unlock.md` 4절에서 "날개 직원 집안의 위쪽, 숨겨진 비밀이 있는 설정으로 더 고민"으로 남아 있던 항목이다.

> 상태: 기본 설계 제안. 구현 전에 아래 "정할 것"의 답이 필요하다. **G사의 원작 설정은 이 문서에서 확인되지 않았다.** 게임 안의 확정 사실은 "날개 소속 6곳 중 하나"뿐이라, 이름과 설정은 확인 후 쓴다(`CLAUDE.md`: 세계관 고증이 불확실한 이름은 확인 요청). 그 전까지는 일반 명칭("G사의 병기")만 쓴다.

## 1. 한 줄 요약
G사 날개가 단 한 번의 결전을 위해 만든 병기로 태어난 사람의 이야기. 처음에는 자신이 병기인 줄 모르고 날개 직원으로 산다. 중반에 비밀이 드러나고, 2막에서 결전의 날이 온다.

## 2. 숨겨진 비밀
- 출생 화면에는 "G사 병기 출신"이라고 쓰지 않는다. 이름은 **"G사 날개 직원 집안의 아이"** 정도로만 보이고, 비밀은 1막 중반 사건에서 드러난다. (해금한 사용자는 출생 목록에서 알고 고르므로 이름은 고를 수 있게 둔다. 본문에서만 비밀이다.)
- 비밀의 내용: 자신이 결전을 위해 설계된 병기이며, 몸 안에 개방 장치가 있다. 인간의 모습으로 태어났지만 인간이 아닌 것이 인간의 자리를 채우는 일은 머리의 금기에 닿는다. 그래서 G사는 이 사실을 숨겨 왔다(머리는 아무 말도 하지 않는다).
- 이 비밀은 **맥거핀이 아니다.** 사서·발톱과 달리 이 줄기에서는 진실이 밝혀진다.

## 3. 해금 조건 (안)
- **안 A (추천)**: G사 날개 소속으로 2막 끝(무한 모드 진입)까지 간다. 소속 조건은 새 해금 조건 종류(`cond.aff`)로 만든다.
- 안 B: 특이점 응용 의수(공방 3등급)를 장착한 채 2막 끝까지 간다. 아이템 조건은 기존 `cond.item`으로 바로 된다.
- 둘 중 하나만 둔다. 이미 날개를 고른 판이 해금으로 이어지게 하려면 A가 자연스럽다.

## 4. 시작 상태
| 항목 | 값 |
|---|---|
| 소속 | G사 날개 (병기 개체 · 일반 직원처럼 보인다) |
| 레벨 | 8 (해금 출생 공통) |
| 능력치 | HP +30 · 공격 +5 · 회피 +3 · 속도 +2 · 판정 +2 (몸이 병기라 판정은 낮다) |
| 시작 무기 | **G사 병기 · 시제**(내장 병기, 맨손으로 보인다). 이정표에서 두 번 강화 |
| 전용 책장 | 10장(덱 고정 · 새 카드 대신 돈) |
| 공방 거리 | 없음(G사의 보급 창구가 대신한다) |
| 일반 조우 | 끈다 |

### 병기의 패시브: 결전 개방
- 전투 중 **적중할 때마다 게이지가 쌓이고**(최대 10), 가득 차면 다음 공격 카드의 피해가 **두 배**가 된다(한 전투에 한 번). 이후 게이지는 다시 쌓인다.
- 1막에는 개방이 불완전하다(피해 ×1.5). 비밀을 안 뒤부터 ×2가 된다.
- 구현은 기존 충전(`charge`)·마무리(`finish`) 장치를 참고해 새 패시브(`gw`)로 만든다.

## 5. 줄기 (안)
| 단계 | 연차 | 내용 |
|---|---|---|
| 출발 | 1 | G사 날개 직원 집안의 아이. 어릴 때부터 몸이 튼튼하다는 말을 듣는다 |
| 보급 / 시험 | 1~35 | 해마다 **G사의 보급 / 시험 가동**을 고른다. 시험 가동은 사내 시험으로 처리되는 전투다(대상은 목록) |
| 단서 | 25~40 | 설계도의 일부, 지워진 번호, 몸의 이음매가 사건으로 나온다. 선택으로 단서를 모은다 |
| 자각 | 40~50 | 비밀이 밝혀진다. **받아들인다 / 거부한다**를 고른다(플래그 `gw_accept` / `gw_refuse`) |
| 1막 끝 | 50~55 | 날개에서 G사의 결전 준비가 시작된다. 병기는 결전 날을 알게 된다 |
| 2막 | 56~73 | 결전 준비 → 다른 날개·협회의 개입 → 결전 |
| 결전 | 73 | 결전의 상대(미정)와의 전투. 엔딩 2종 |

- **엔딩(안)**: 결전을 치른 병기 / 결전을 거부한 병기(몸의 장치를 스스로 닫는 선택).
- 받아들이면 병기가 더 강하게 개방된다(결전 개방 ×2, 정신력 상한 감소). 거부하면 개방이 약해지는 대신 정신력이 안정되고 결전의 상대가 달라진다.

## 6. 전용 무기: G사 병기 · 시제
| 단계 | 이름 | 효과(안) |
|---|---|---|
| 0 | G사 병기 · 시제 | 공+6 속+2 · 2d4 · 적중마다 결전 게이지 +1 |
| 1 | G사 병기 · 개방기 | 공+9 속+3 · 2d5 · 라운드마다 첫 적중 피해 +8 |
| 2 | G사 병기 · 결전형 | 공+13 속+4 · 2d6 · 상대 HP 30% 이하면 피해 +8 · 결전 게이지 +2 |

## 7. 구현 순서
1. `unlockOrigins`에 출생(`gweapon`)과 `cond.aff` 해금 조건을 넣고, `routes.gweapon`(공방 거리 없음, 일반 조우 끔)을 만든다.
2. 시험 가동 의뢰(대상 8곳), 단서 사건 5개, 자각 선택.
3. 결전 개방 패시브(`gw`)와 전용 무기 2단계 강화.
4. 2막 임무와 결전, 엔딩 2종.
5. 시뮬(완주 40~60% 목표)과 테섭 확인.

## 8. 정할 것
1. **G사의 원작 설정**: 알려 주실 설정(이름, 특징, 결전병기의 정체, 결전의 상대)이 있는지. 없으면 위 일반 명칭으로 간다.
2. **해금 조건**: 안 A(G사 날개 소속 2막 끝)와 안 B(특이점 응용 의수) 중 어느 쪽.
3. **비밀의 수위**: 중반에 확실하게 밝힐지(위 안), 끝까지 일부만 암시할지.
4. **결전의 상대**: 다른 날개(예: R사 날개)와의 결전으로 할지, 협회·머리 쪽(발톱·조율자 줄기와 겹치지 않게)으로 할지.
5. **엔딩 2종**과 결전 개방 패시브(게이지 방식)가 맞는지.
6. 머리의 금기(인간성 경계)와 병기의 존재를 연결하는 방식(위 2절)이 맞는지. 발톱·조율자 줄기의 서술 기준(머리는 말하지 않는다)과 충돌하지 않게 둔다.
