# 시지프 백화점 설정 정리 (2026-11-18, 현재 구현 기준)

> 이 문서는 게임 데이터(`data/birth.json`의 `sisyphus`, `src/config.js`의 `CFG.sis`)에 **실제로 들어 있는 것**만 정리한다. 미구현·초안은 맨 아래에 따로 적는다.
> 오마주 원칙: 이름·용어는 쓰고, 원작 대사·사건 문장은 옮기지 않는다.

## 1. 한 줄 요약
금기를 어긴 N사 날개 출신이 법정에서 형을 받고 "시지프 백화점"에 들어간다. 사냥 → 옷 제작 → 판매를 반복하며 소속(르카키·르누아르·르루주)이 갈리고, 52년차에 백화점이 무너지면 탈출한다. 1막(백화점 안)까지만 구현.

## 2. 진입 (N사 날개 → 시지프)
1. **금지된 것** — 소문: 경험은 통조림에 담기고, 담기지 않은 경험은 규칙 밖이다. 선택: 가짜 경험 통조림을 판다 / 금지된 영상을 감상한다(금기 위반, 되돌릴 수 없음). 출신이 "평범한 둥지 시민", "둥지 노동자"일 때 4년차 갈림길에 나온다.
2. **붙잡힘** — 같은 색 옷의 사람들이 서류를 들고 온다.
3. **재판** — 방청석 없는 재판정, 판결문의 마지막 줄은 한 단어 "시지프".
4. **시즌 안내** — 눈을 뜨면 매장. 방송: "지금 시즌은 @!$$!"(잡음). 낯선 손님이 가위를 들고 시비 → 첫 전투(손님을 쓰러뜨리면 몸이 실이 되고 가죽 조각이 남는다, 가위 손잡이에 6층 고객센터 접수 번호표).
5. 이후 "백화점을 둘러본다"로 규칙 3가지를 알아간다(장소 이름만 보이고, 고르면 질문과 설명이 나온다).

## 3. 공간 (6개 구역)
| 층 | 이름 | 분위기 | 주요 적(예) |
|---|---|---|---|
| f1 | 1층 매장 | 옷걸이 사이로 유행이 한 바퀴 돈다 | 장갑·지갑·마네킹(약) |
| b1 | 지하 1층 푸드코트 | 정육 걸이 너머 국자 소리 | 수셰프, 마네킹(약) |
| b2 | 지하 2층 방적장·염색실 | 베틀 소리와 염료 냄새 | 바늘 날실/씨실/바늘왕 |
| b3 | 지하 3층 가죽실·수선실 | 마네킹들만 돌아다닌다 | 마네킹, 컨트롤러 |
| f4 | 4층 가구관·신발관 | 가구가 된 고객들이 값을 외친다 | 외다리, 도로시아, 소파 |
| f5 | 5~6층 | 식탁은 길고 계단은 하나뿐 | 식사하는 자, 쓰러진 자, 간수 |
- 구역 마지막 상대(보스)는 20% 확률로 나온다.
- **샘터**: 쓰러지면 깨어나는 곳(체력 50%, 안 20% 손실). 문턱 안으로 아무도 들어오지 못한다.
- **6층 고객센터**: 붕괴 때 문의를 받는다(최고 등급이어야 올라감).

## 4. 핵심 순환
- **하루(day1)**: 사냥 구역 고르기 / 쉰다 / 재단대에서 보낸다 / 벽을 뜯는다(황금송진, 성향 −2, 경비 20%).
- **사냥** → 재료(가죽 조각·무명실·무명·황금가죽·염료·가공 재료·정육 소다·황금송진·모직·비단·무두질 가죽·은실·황금실).
- **재단대**: 형태 6종(셔츠·정장 재킷·외투·휘감은 천 상의·드레스·황금가죽 망토) × 색 8종(회색·검은색·붉은색·흰색·남색·카키색·암적색·금색) × 무늬 6종(민무늬·줄무늬·띠·격자·물방울·박음선) × 장식(겹누빔·손톱 섞음·눈알 먹임·이음 보강). 남성형/여성형 마네킹.
- **손질(등급)**: 기본 완성 → 고급 완성 → 걸작 → 런웨이(옷깃·소매·몸판·안감 4부위, 재료를 넣을수록 성공 확률↑ 최대 80%, 실패하면 그 단계에서 끝).
- **판매(day2)**: 손님에게 "밀어붙인다 / 천천히 설명한다". 손님 취향(색·무늬 배율)이 소속마다 다르다.
- **거래**: 층마다 상대(수셰프·팔레트·네이키드·아네트 등), 안(눈알)이나 재료로 맞바꾼다.
- **고객 등급**: 토파즈 → 에메랄드(8) → 금(24) → 루비(48) → 다이아몬드(80). 올라갈수록 몸이 강해진다(체력·공격·회피·속도).
- **단골 맞춤**: 취향에 맞춰 판 옷 3벌마다 1단계(최대 3단계), 소속 전투 규칙이 강해진다.

## 5. 시간과 규칙
- **턴**: 약 52턴(백화점 붕괴 52년차). 10턴에 소속이 정해진다(옷의 성향 합이 +3 이상이면 르루주, −3 이하이면 르누아르, 옷을 2벌 미만 만들었으면 르카키).
- **재고 정리**: 16턴·30턴에 걸린다. 방송이 멈추고 모두의 기억이 지워지며 시간이 10턴 되돌아간다. 당신만 기억한다.
- **순응도(0~10)**: 낮으면(2 이하) 간수가 올 수 있다(30%), 높으면 점원이 값을 더 쳐 준다.
- **알아야 할 규칙 8개**: 등급에 맞는 층만 열림 / 좋은 옷을 계속 내놓아야 함 / 벽을 건드리지 말 것 / 쓰러지면 샘터 / 6층 고객센터 / 간수 / 재고 정리 / 옷을 팔수록 점원이 믿음.

## 6. 소속 3개
| 소속 | 성향 | 전투 규칙 | 보상 |
|---|---|---|---|
| **르카키** | 유행·중립. 아침 방송으로 유행이 정해지고 입는 것도 바뀜 | 그 라운드의 유행 키워드 +2 | 카키 전용 카드 |
| **르누아르** | 검은 코트·정돈 | 라운드마다 보호막 2, 규율을 지키면 보호막·충전·다음 공격 피해 증가, 어기면 반동 4 | 르누아르의 책장(진동·보존, 카드 8장+2) |
| **르루주** | 붉은 옷·맥동 | 라운드마다 최대 체력 일부를 내고 공격 피해 증가(붉은 신이 곁에 있으면 비용 절반) | 르루주의 책장(출혈·충전, 카드 8장+2) |
- 소속이 정해지는 순간 몸이 **백화점의 뒤틀림** 형태가 되고, 백화점 밖으로 나가도 유지된다.

## 7. 붉은 신 (르루주 중심)
- 2층 공사장에서 태어나는 눈 하나·입 하나의 붉은 것. 이름을 정해 주면 따라온다(미생).
- 말을 배운다(단어 → 문장 → 질문 "밖은 어떤 곳이야?"). 허기가 쌓이면 **성장기**를 거쳐 **뷔페**(보스)가 된다. 먹이 주기는 없다.
- 르누아르는 미리 제거하지 않으면 뷔페와 싸우고, 일찍 만나면 갓 태어난 존재와 싸운다. 르카키는 붉은 신을 만나지 않는다.
- 결말 분기: 함께 나오기 / 뷔페가 남음 / 쓰러뜨림 / 패배.

## 8. 간수와 운명 이탈 (신부)
- **간수**: 규칙을 어긴 고객 앞에 선다. 검은 로브, 등의 못 끝에서 푸른 불꽃. 말이 없다. 사냥에서 쓰러지면 샘터에서 깨어나지만, 1막 최종전(52년차 간수전·신부전)에서는 쓰러지면 영구 사망한다.
- **운명 이탈**: "브랜드 매니저"를 죽이려 하면(죽이면 안 되는 인물) 간수가 나타나 쓰러뜨리고 시간이 3칸 되돌아간다. 기억은 남는다. 칭호 "운명을 이탈한 자".
- **신부**(르루주 전용): 간수가 쓰러지면 로브 속에서 흰 베일이 풀린다. 간수는 처음부터 신부의 한 모습이었다(검은 신의 자리에 앉아 규칙을 지켜 온 존재). 쓰러뜨리면 베일 안은 비어 있고 층이 기운다.

## 9. 붕괴와 탈출 (1막 끝, 52년차)
1. **붕괴의 징조** — 방송이 끊기고 다시 켜지지 않는다. 층이 짧아진다.
2. **6층 고객센터** — 문이 처음으로 열려 있다. "밖으로 나가는 방법을 묻는다" / "그냥 올려다본다". 카키는 계단이 주저앉아 6층에 닿지 못한다.
3. **통로** — 한 사람이 지날 폭.
4. **결말 4종**: 카키(가진 것 그대로 나옴) / 붉은 것과 함께 / 뷔페가 남음(씹는 소리) / 혼자 나옴. 칭호: "백화점에서 나온 자", "접수 번호를 받은 자".

## 10. 층 사건 42편
층마다 7편(초반·중반·후반·말기 창), 구역을 골라 나갔을 때 사냥 전에 붙는다(확률 55%, 하루 한 편까지). 선택지는 순응도·안·염료·재료·체력에 영향. 층별 사건 제목:
- **1층**: 안내판 앞의 줄 / 시즌 방송의 오타 / 진열 위치 바꾸기 / 반품 손님 / 도난 의심 / 마네킹과 눈이 마주침 / 신입 점원 교육
- **지하 1층**: 수셰프의 시식 / 정육 소다 쿠폰 / 빈 접시의 줄 / 주방 보조 구함 / 식권 위조 / 불 꺼진 조리대 / 뒷문의 냄새
- **지하 2층**: 팔레트의 줄 / 네이키드의 흥정 / 손톱자국이 난 벽 / 염료통 사고 / 색 지정 의뢰 / 물든 손님 / 염색실 폐쇄
- **지하 3층**: 가위 소리 / 긁어내는 자의 장부 / 무두질 일감 / 수선 대기표 / 쓰러진 마네킹 / 가죽 냄새 속의 목소리 / 재단 도구 분실
- **4층**: 등이 굽은 조명 / 값을 외치는 소파 / 신발 한 짝 / 낮잠 손님 / 전시 침대 / 가구가 된 고객 / 신발 맞춤
- **5~6층**: 난간의 손님 / 멈춘 에스컬레이터 / 위층 안내 방송 / 고객센터 소문 / 계단 아래의 틈 / 등급 확인 심사 / 방송실 앞의 줄

## 11. 화면·그림
- 소속별 테마 색(르루주 붉은색·르누아르 검정/은색·르카키 황금빛) + 층 안내판, 방송 자막, 순응도·허기·맞춤 게이지.
- GPT 배경: PC 3색(좌우 장식), 모바일 2색(위아래, 카키 모바일은 아직 없음). 본문 영역은 단색 바탕.
- 옷 이미지: 마네킹이 옷을 입은 형태(`sis_w_*`)를 색 입히기. 남성형 5벌 변환.
- PWA/홈 화면 설치 지원(시지프와는 별개).
