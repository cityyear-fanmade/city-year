# 제보 정리 (v11.1.0 설문, 2026-11-11) — 결정 사항

## 버그
- 검은 가면 해금 조건이 기록실에 보이지 않음: (1) 기록실 조건 문구 목록에 검은 가면이 빠져 있었음 (2) 해금 판정이 "출생 조건 없이 보스 처치만 있는 출생"을 처리하지 않아 해금이 되지도 않았음. → v8-dev에서 수정(조건 문구 상시 표시, 처치 즉시 해금, 이미 처치 기록이 있으면 해금).

| # | 항목 | 결정 |
|---|---|---|
| 1 | 디버프류 최대 상한 | 올려서 사용감을 높이되 침잠 등 너무 올리면 사기인 것은 확인하고 조정 |
| 2 | 보스 드랍 다양성 | 보스뿐 아니라 쓸모없이 겹치는 기존 히든 보스 드랍도 포함. 보조 장비 드랍 추가 |
| 3 | 조율자·발톱 | 발톱을 너프하지 않고 둘 다 최상위권으로. 그중 최최최상위가 바랄·제나 |
| 4 | 날개 반복 개발 | 채택(경험치 1짜리 일반 특이점 개발 반복, 금기 개발 강제 제거) |
| 5 | 중복 적(환상체/불순물)·일반 이벤트 중복 제거 | 채택(일반 이벤트는 1막 것만 외곽 연출용으로 남김) |
| 6 | 유저가 되는 불순물 | "첫 엔딩 플레이를 본딴 더 강한 고정 특수 보스". **지금부터 저장**(이전 기록은 해당 없음) |
| 7 | 흡혈·반격·보호막·선공 | 흡혈 다소 너프. 반격 강화 최소 3배~최대 5배. 보호막·선공의 권리 버프 |
| 8 | 하드 불순물 체력 1억 이상 | 1000살(984년) 기준 하드 체력을 어디까지 올릴지 논의 필요 |
| 9 | 스탯 설명 추가 | 채택 |

## 측정(현재 불순물 체력)
| 연차 | 보통 | 하드 |
|---|---|---|
| 100 | 11,000 | 22,000 |
| 300 | 450,000 | 900,000 |
| 500 | 9,000,000 | 18,000,000 |
| 984 | 99,999,999(상한) | 99,999,999(상한) |
- 984년 기준으로 보통·하드 모두 이미 상한 99,999,999에 닿아 있다. 하드가 1억 이상이 되려면 **상한 자체를 풀고** 하드의 증가 곡선을 새로 정해야 한다.
