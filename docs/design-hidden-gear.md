# 최고 등급 공방과 히든 장비 개성 (준비 단계, 2026-10-22)

사용자 아이디어를 정리한 것이다. 아직 구현하지 않았고, 구현 전에 아래 "정해야 할 것"을 확정한다.

## 확정 (2026-10-22, 사용자 결정)
- 지금의 3등급 '명장 공방'은 **장인 공방**으로 이름을 바꾸고, 그 위에 최고 등급 **명장의 공방**(4등급)을 새로 둔다.
- 명장의 공방: 해결사 1급 이상(또는 진로 최고 직위)만 이용. 물건은 스탯만 쓸 만하게(발톱 장비보다 살짝 아래), **특수 효과 없음**. → 구현됨(테섭): 명장의 무기 공+12·회피+7 4800안 / 방어구 HP+22·회피+3 4200안 / 의수 공+7·회피+4 4500안. 이름·수치는 임시.
- 나머지 히든 장비는 전부 **전용 키워드 추가 또는 기믹**을 갖는다. → 미구현(아래 개성 목록 확정 후).

## 1. 최고 등급 공방 (가칭, 위 확정이 우선)
- 지금 공방 거리는 1 뒷골목 · 2 협력 · 3 명장 공방이다. 3 위에 **전용 최상위 공방 하나**를 둔다. 접근 등급은 손가락의 대부처럼 진로 최고 직위(또는 1급)로 건다.
- 이름은 세계관 고증이 불확실하므로 확정 전에 사용자에게 확인한다.
- 판매 물건은 **명장 이상급**: 히든 장비와 같은 스탯대로 팔고, 개성(기믹·키워드)은 히든 장비마다 따로 둔다.
- 대호수 출생은 공방 대신 '항구'를 쓰므로 이 공방은 열지 않는다.

## 2. 히든 장비의 두 갈래
| 종류 | 설명 | 개성 |
|---|---|---|
| 일반 히든 | 히든 보스 전리품·유물. 스탯은 한 기준표를 따른다 | 장비마다 기믹 하나 또는 키워드 하나 |
| 연계 히든 | 두 히든(또는 히든 + 최상위 공방 재료)을 잇는 상위 장비 | 일반 히든의 개성에 연계 효과가 붙는다 (더 세게) |

- 스탯은 일반 히든과 같은 기준표에 두고, 차이는 개성과 연계 보너스로만 둔다. 숫자 인플레를 막는다.
- 미리 준비: 장비 데이터에 `unique`(개성 id) 칸과 `link`(연계 대상 id) 칸을 비워 둔다. 지금은 아무 동작도 하지 않고, 개성 목록이 정해지면 채운다.

## 3. 개성 후보 (기믹 또는 키워드)
- 키워드형: 기존 키워드(출혈·파열·호흡·화상·불꽃·손톱·작살 등)를 장비에 붙인다. 카드 없이 장비만으로 스택을 주는 방식.
- 기믹형: 전투 중 한 번 발동, 라운드 N마다 발동, 체력 일정 이하에서 발동, 연속 명중 보너스 등 패시브 규칙.
- 연계형: 두 장비를 함께 착용하면 켜지는 연계 규칙(세트 효과).

## 4. 정해야 할 것
1. 최상위 공방의 이름과 접근 조건 (1급 해결사인가, 손가락 대부·협회 최고 직급 같은 진로 최고 직위인가).
2. 개성 방향 (키워드형 위주인지, 기믹형 위주인지, 둘 다인지).
3. 연계 히든은 구매인가 합성인가 (공방 작업대의 재료 규칙과 맞출지).
4. 처음 준비할 히든 장비 후보 (지금 있는 전리품 중 어느 것부터).
