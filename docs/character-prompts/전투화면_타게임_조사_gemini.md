# 타 게임의 전투 화면 캐릭터 배치 조사 (Gemini 초안 · 2026-11-08, 확인 필요)

모바일 환경(430px)과 카드/주사위 중심의 게임플레이를 고려한 UI 패턴 제안입니다.

### 1. 캐릭터 배치 및 애니메이션 패턴
*   **풀바디/상반신 스탠딩 (Side-by-side):** 화면 좌우에 캐릭터를 배치. *Library of Ruina, Limbus Company*는 중앙 전투 영역을 두고 양옆에 배치.
*   **아이콘/초상화 (HP바 통합):** 상단 정보창에 작은 원형/사각형 아이콘 사용. *Slay the Spire*는 플레이어 캐릭터를 화면에 직접 그리지 않고 하단에 정보만 표시.
*   **컷인 (Cut-in):** 특정 스킬 사용 시 화면 중앙에 일러스트가 튀어나옴. *Limbus Company, FGO* 등 모바일 RPG에서 흔히 사용.
*   **히트 플래시/반응:** 캐릭터가 직접 움직이지 않고, 피격 시 화면 전체나 해당 영역이 붉게 점멸하거나 흔들림. *Darkest Dungeon*은 캐릭터가 제자리에서 살짝 튀어 오르는(Jump) 애니메이션 사용.
*   **주사위/카드 연동:** *Dicey Dungeons*는 캐릭터가 주사위 위에 올라가 있거나 주사위를 던지는 모션을 수행.

### 2. 좁은 모바일 화면을 위한 최적화
*   **권장 패턴:** 캐릭터를 화면 중앙에 크게 배치하기보다, **상단 HP바 영역에 60x60px 정도의 '얼굴 아이콘'**을 배치하고, **피격/공격 시에만 중앙에 0.5~0.8초간 컷인**을 띄우는 방식이 가장 효율적입니다.
*   **반응 효과:**
    *   **Shake:** 화면 전체를 흔들기보다 해당 캐릭터 영역만 CSS `transform: translate`로 미세하게 흔드는 것이 가독성에 좋습니다.
    *   **Flash:** 피격 시 캐릭터 영역에 흰색/붉은색 오버레이를 0.1초간 씌우는 것만으로도 타격감이 충분합니다.
    *   **숫자:** 데미지 텍스트는 캐릭터 머리 위로 솟아오르며 사라지게 처리합니다.

### 3. 소규모 프로젝트를 위한 최소 에셋 및 주의사항
*   **최소 에셋:** 
    *   기본 스탠딩 (Idle)
    *   피격 (Hurt)
    *   공격 (Attack)
    *   *총 3장의 정지 이미지*만 있어도 CSS `transition`을 활용해 충분히 생동감을 줄 수 있습니다.
*   **구현 팁:** 프레임 애니메이션(GIF/스프라이트 시트)보다는 **CSS `transform`과 `filter`**를 활용하세요. (예: 공격 시 `scale(1.1)`, 피격 시 `filter: brightness(2)`)
*   **피해야 할 점:**
    *   **클러터:** 430px 폭에서는 캐릭터가 너무 크면 카드와 주사위 영역을 가립니다. 캐릭터는 항상 배경 레이어에 두세요.
    *   **멀미:** 화면 전체를 과도하게 흔드는 효과는 반드시 설정에서 끌 수 있게(Reduce Motion) 만드세요.
    *   **성능:** 모바일 브라우저에서 너무 많은 레이어 애니메이션은 배터리 소모와 렉을 유발합니다.

### 4. 모바일 vs 데스크탑 레이아웃 차이
*   **데스크탑:** 화면 좌우 여백이 넓으므로, 캐릭터의 **풀바디 일러스트**를 고정 배치하여 몰입감을 높입니다.
*   **모바일:** 세로형 화면에서는 캐릭터를 상단에 고정하고, 하단에 카드/주사위 영역을 배치하는 **'상하 분할'** 구조가 표준입니다.
*   **반응형 전략:** 
    *   데스크탑은 캐릭터가 화면 좌우에 고정(Fixed).
    *   모바일은 캐릭터를 상단 정보창(HP바) 옆으로 축소하거나, 전투 로그가 올라올 때 캐릭터를 반투명하게 처리하여 공간을 확보합니다. (불확실: *일부 웹 기반 RPG는 모바일에서 캐릭터를 아예 숨기기도 함*)
