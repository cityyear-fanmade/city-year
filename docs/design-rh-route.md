# 전용 루트 설계안 · R사 부화장 복제체 / H사 홍원 가주 후보

상태: 초안(승인 전). 테섭(v8-dev)에서만 구현. 두 루트 모두 **공방거리 없음** (별도 시스템).
세계관 원문은 참고만 하고, 이름·사건은 이 게임용으로 새로 쓴다.

## 공통 골격
| 단계 | 시기 | 내용 |
|---|---|---|
| 출생 | 0년 | 운명 선택(1d100 30%)의 후보 2개 중 하나. 전용 카드·무기 지급, 공방거리 대신 전용 이벤트 풀 사용 |
| 1막 초 | 1~전반 | 전용 연쇄 사건 (R사: 부화장 / H사: 가문) — 스토리 전투는 고정전(fixedFights) |
| 전환 | 1막 후반 | 도시로 편입 (R사: 탈주 / H사: 소환·이주) |
| 2막 | 중반~ | 전용 추격/계승 사건 + 전용 히든 보스 |
| 엔딩 | | 전용 엔딩 1종 (+무한모드 문구) |

## A. R사 부화장 복제체
1. **부화 (1막 초, 약 5~6사건)**: 같은 얼굴의 번호 개체들, 본체/복제체 구분 불가. 배틀로얄 **13연전**(고정전, 연전 사이 회복), 상대는 복제체(약~중). 마지막은 토끼팀 기준 강도(※ 2배 기준 확인 필요).
2. **탈출**: 다른 모든 개체를 처치. "내가 본체인가" 선택지(정신력 변화). 전용 카드 획득.
3. **도주 (1막 후반~2막 중반)**: 머리의 7일 금기, 숙청 추격대. 기존 추격(chase) 구조 재사용 — 제3무리/제4무리 대장급(까마귀팀 등)이 주기적으로 등장(회피/전투 선택, 연속 승리 시 보상).
4. **R사 히든 보스**: 추격대 종결자. 처치 시 추격 종료.
5. **엔딩**: "나는 존재한다. 그러므로 살아있다." 무한모드: (문구 미정)

## B. H사 홍원 가주 후보 (개정: 철함사·선황충·흑수)
1. **가문 (1막 초, 사건 5~6)**: 서열, 독살 시도, 방계 자객 습격. 호위·대리인과 인연.
2. **이동 이유**: 2막 진입 시 후계 결정이 임박해 가문으로 소환.
3. **가주 심사 (2막)**: 방계 찬탈자 → 가문 대리인 → 직계 후보 고정전. 승리하면 가주 심사 통과.
4. **철함사의 사태**: 심사 직후 철함사(가장 깊은 제단)에서 소요. 어르신(원로)들이 힘은 인정하되
   "진짜 가주는 선황충을 품어야 한다"며 강요. 선황충 = 타인의 감정·생명력을 먹어 불로불사와 막대한 코스트(빛)를 만드는 기생 특이점 생물.
   원로들은 플레이어를 숙주 삼아 꼭두각시 가주로 세우려 함 → **선택**: 품는다 / 거부하고 원로와 싸운다 (분기별 엔딩·보상).
5. **홍루(강화 군주)**: 기존 `hongwon`(십이지 흑수 패시브) 계열. 12흑수 중 **최대 2마리를 골라 덱(카드)으로 획득**.
6. **전용 키워드 [흑수(黑水)]**: ※ 제보 메시지가 키워드 설명 직전에서 끊겨 있음. 확정 전까지 임시안 —
   흑수 = 스택형 키워드. 공격 적중 시 대상에 흑수 누적, 라운드 종료 시 스택 비례 피해 후 절반 감소.
   12흑수 카드는 자·축·인·묘·진·사·오·미·신·유·술·해 각 1장(동물별 고유 효과), 선택한 2종만 덱에 편입.
7. **엔딩**: 가주 즉위 (선황충 품음 / 거부 두 갈래).
