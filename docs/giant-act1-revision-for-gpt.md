# 《거인 출생》 Act 1 수정 방향 정리 (GPT 전달용, 2026-11-18)

목적: 앞서 올라온 「Act 1 게임 시스템 방향 검토 요청」 원문을 어떻게 고치면 좋은지 정리한다. 상세 근거는 `docs/giant-act1-system-review.md`에 있고, 이 문서는 그 결론을 **수정 지시서**로 줄인 것이다.
표시: **[확정]** 사용자가 정한 것 / **[제안]** Claude의 제안 / **[미정]** 결정 필요. 기존 설정은 임의로 바꾸지 않는다. 원작 대사·사건 문장은 쓰지 않는다.

## 1. 사용자가 새로 정한 방향 [확정]
1. **플레이 방식은 기존 《도시의 한 해》와 완전히 다르다.** 출퇴근하는 방식으로, 로보토미(간단한 버전) 느낌이다.
2. **직접 조종이 아니라 누르면 작동하는 방식**이다. 이동·배치를 손으로 하지 않고, 버튼을 눌러 지시를 실행한다.
3. **Voice(목소리)** = 방송을 통해 전해지는, 소속들이 기다리는 무형의 무언가. 인격도 아바타도 아니다.
4. **브랜드 매니저** = 소속별로 그 소속의 목소리를 따르는 행동대장. 임명되는 직원이 아니다.
5. 원문의 나머지(3일 차 임명, 공통 권능 묶음, 수치 등)는 **메모**다.

## 2. 이 방향이 기존 설정과 맞는 이유
- 거인은 백화점 **바깥**의 존재(공무원 격)이고, 백화점의 현상을 다루는 적성이 있다. 그래서 **출근해서 백화점 안에 개입하고 퇴근하는** 구조가 설정과 그대로 맞는다.
- 퇴근 뒤에도 백화점은 계속 흐른다. 이 때문에 원문의 "플레이어 부재 중 발생한 사건 기록 → 다음 출근 때 보고"가 구조의 중심이 된다.
- Act 1이 끝나면(백화점 붕괴) Act 2부터 기존 게임 방식으로 돌아간다는 원문 방향과도 충돌하지 않는다.

## 3. 원문을 이렇게 고치자 (절별)
| 원문 절 | 고칠 점 |
|---|---|
| 1. 검토 목적 | "관리 시뮬레이션" 앞에 **출퇴근형 · 버튼으로 작동 · 직접 조종 없음**을 명시한다. |
| 3. 현재 고려하는 게임 방향 | 대응표(환상체→이상 현상 …)는 **영감 표**로만 남기고, 시스템은 아래 4절 구조로 짠다. 이상 현상은 개별 개체가 아니라 **구역에 붙는 상태**로 둔다. |
| 4. 핵심 게임 시스템 | "관측 → 업무 지시·개입 → 결과 확인"을 **출근 → 근무 → 퇴근 → 부재 중**으로 바꾼다(4절). |
| 5. Voice 방송 | Voice는 **소속들이 기다리는 무형의 무언가**로 쓴다. 거인은 그것을 방송이라는 수단으로 전하는 쪽이다. "별도 인격·아바타가 아니다"는 유지한다. |
| 6. 브랜드 매니저 | "3일 차에 임명"을 삭제한다. **소속마다 한 명, 자기 소속의 목소리를 따르는 행동대장**으로 바꾼다. 플레이어 소속의 매니저만 플레이어의 방송을 현장에서 실행한다. |
| 7. 가상 플레이 | 제4일 예시는 버튼 흐름으로 다시 쓴다(5절 예시). 수치는 설명용임을 유지한다. |
| 8. MVP | 7개 기능을 아래 6절 순서로 재배열하고, **소속은 한쪽(카키 또는 누아르)만** 먼저 만든다. |
| 9. 검토 요청 | 질문 C(모바일)를 "버튼만으로 완결되는가"로 바꾼다. 질문 D에 "다른 소속의 매니저·목소리를 어떻게 쓰는가"를 추가한다. |

## 4. 수정된 핵심 구조 [제안]
### 4-1. 출퇴근 루프
```
출근(보고 수령) → 근무(버튼 2~3개 실행) → 퇴근(정산·기록) → 부재 중(밤: 백화점이 흘러감) → 다음 출근
```
- **출근:** 소속 브랜드 매니저의 보고를 받는다. 보고는 불완전하고 편향돼 있다.
- **근무:** 하루에 쓸 수 있는 **행동 칸이 3개**다. 실시간 없이 버튼을 누르면 즉시 결과가 정산 칸에 요약된다.
- **퇴근:** 하루 정산(안정도·자원·사건 기록)을 본다.
- **부재 중:** 퇴근 뒤 미해결 구역이 한 단계 진행하고, 매니저가 일부를 처리한다. 결과는 다음 출근 보고로 돌아온다. 다음 날 위험은 **예고**로 미리 보인다(불공정 방지).

### 4-2. 버튼으로만 하는 조작 (직접 조종 없음)
화면은 **구역 카드 목록 + 구역 상세**다. 이동·배치 없이 구역 상세에 고정된 버튼만 있다.
| 버튼 | 하는 일 | 칸 |
|---|---|---|
| 관측 | 그 구역의 실제 상태와 이상 현상의 약점 하나를 안다 | 1 |
| 지시 | 그 구역 집단에게 업무를 맡긴다(복구·조사·경비 등 프리셋 3~4개) | 1 |
| 개입 | 거인 고유 권능. 상태를 바꾸지만 반동이 있다 | 1 |
| 방송 | 규칙 문장을 발표한다(5절) | 1 |
- 한 번에 한 버튼, 한 결과. 끌기·이동·미니게임이 없다.
- 소속별로 칸 배분이 다르다: 카키 계승 = 관측 중심(관측 3·개입 0), 누아르 계승 = 개입 중심(관측 1·개입 2) [제안·미정].

### 4-3. 방송 (Voice) = 버튼 세 번
1. 범위: 전체 / 한 구역 / 한 집단
2. 규칙 종류: 금지 / 요구 / 허용
3. 어조: 공지 / 명령 / 호소
- 자주 쓰는 방송은 **프리셋 버튼**으로 둔다(예: "제4구역 출입 제한 · 명령").
- 방송은 현상을 바꾸지 못하고 **순응 확률**만 바꾼다. 같은 방송도 구역 성향에 따라 해석 오차가 생긴다.
- **기다림 게이지 [제안]:** 소속마다 목소리를 기다리는 정도가 있다. 방송이 오래 없으면 불안이 오르고, 의도와 다르게 읽히면 신뢰가 깎인다. 방송을 하지 않는 것도 선택이 된다.

### 4-4. 로보토미와 다른 점 (복제 방지)
- 가져오는 것: **불완전한 정보로 판단하고, 판단이 사고로 돌아오는 긴장.**
- 가져오지 않는 것: 직원 개별 능력치·상성, 환상체별 작업 종류 퍼즐, 실시간 이동·전투, 복잡한 자원.
- 이 게임만의 재미: **규칙을 쓰는 쪽**(시지프는 규칙을 지키는 쪽이었다). 방송의 해석 오차와 다른 소속 매니저의 반응이 판단 거리다.

## 5. 수정한 가상 플레이 (제4일, 버튼 흐름)
- **출근:** 보고 — "제4구역 복도가 반복됩니다. 직원 둘이 돌아왔습니다." (매니저 편향: 위험을 낮게 말한다)
- **칸 1 · 관측(제4구역):** 복도 반복, 연결 지점 3개, 약점 하나("연결 끊기") 확인. 보고와 실제 차이 확인.
- **칸 2 · 방송(범위: 제4구역 / 금지 / 명령):** "출입 제한". 소속 순응 70%, 일부는 남은 동료를 걱정한다. 플레이어 소속의 매니저가 경비를 배치한다.
- **칸 3 · 개입(제4구역):** 약점이 맞아 연결 1개를 끊는다. 반동: 이틀간 이 구역 관측이 흐려진다.
- **퇴근 정산:** 안정도 72 → 77, 연결 3개 중 1개 복구, 출입 제한 유지, 이상 현상 잔존.
- **부재 중:** 이상 현상이 한 단계 진행(예고됨). 매니저가 출입 통제를 유지. 다음 출근 보고로 돌아온다.
- 위 수치는 설명용이다.

## 6. MVP 구현 순서 [제안]
| 순서 | 내용 | 규모 |
|---|---|---|
| 1 | 출퇴근 루프 뼈대와 행동 칸, 하루 정산 | 중 |
| 2 | 구역 카드 5곳 + 이상 현상 8종(약점·진행 단계) | 중 |
| 3 | 집단 3종(순응·숙련)과 지시 버튼 | 소 |
| 4 | 관측과 매니저 보고(편향) | 중 |
| 5 | 방송 버튼 3단계 + 프리셋 + 해석 오차 | 중 |
| 6 | 부재 중 진행·예고, 붕괴 게이지와 붕괴 사건(Act 2 연결) | 중 |
| 7 | 시지프 사건을 관리자 시점으로 뒤집은 사건 | 중 |
- 기존 시지프의 하루 상태 기계, 게이지 UI, 선택지 `h` 힌트, 정산 줄을 그대로 재사용한다.
- MVP에서 **뺄 것:** 공간 직접 조작, 직원 개별 능력치, 전투, 아바타 종류, 소속 4종 전부, 초현실 지도(카드 목록으로 대체).

## 7. GPT가 결정 또는 확인해 줄 것 [미정]
1. 계승 대상(카키·누아르)별 행동 칸 배분과 권능 차이(카키 = 관찰·방송, 누아르 = 단죄·통제를 규칙으로 어떻게 표현할지).
2. 다른 소속의 매니저·목소리를 게임에서 쓰는 방식(협조 또는 충돌).
3. 기다림 게이지를 쓸지.
4. MVP 소속(카키·누아르 중 하나).
5. 시지프 미러 사건(7번)을 누구에게 열지.
6. "개입"의 구체 예시 목록(공간 연결 끊기·분리·고정 등)과 반동의 종류.
