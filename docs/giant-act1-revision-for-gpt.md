## 1. 기존 구상(2026-11-16, `docs/giant-design.md`)과 현재 방향
| 항목 | 기존 구상 | 현재 방향 |
|---|---|---|
| 진행 방식 | 페이퍼 플리즈식: 도트 백화점에서 위험 표시를 눌러 규칙집과 대조하고 승인·거부 | **출퇴근형 관리**: 출근 보고 → 근무 → 퇴근 정산 → 부재 중 → 다음 출근 [확정] |
| 조작 | 조사, 승인, 거부, 호출, 정리 버튼 | 관측, 지시, 개입, 방송 버튼. 직접 조종 없이 누르면 작동 [확정: 버튼식, 네 행동의 역할은 미확정] |
| 영감의 출처 | 페이퍼 플리즈의 대조 퍼즐 | 로보토미 코퍼레이션의 간소화된 관리(영감만, 복제하지 않음) [확정] |
| 핵심 재미 | 안내문(규칙집)과 대상의 어긋남을 찾는 대조 | 불완전한 보고로 판단하고, 판단이 사고로 돌아오는 긴장. 규칙(방송)을 쓰는 쪽 [제안] |
| 규칙집(관리 안내문) | 거인이 읽고 대조하는 문서 | 방송으로 발표하는 규칙 문장으로 대체 [제안] |
| 침입자 전투 | 1막에서도 조사 중 전투로 돌입 | MVP에서 제외, 후순위 [제안] |
| 아바타 종류 | 소속별 4종(르누아르·르루주·르카키·르네앙) | MVP에서 제외. 플레이어 소속은 카키 또는 누아르 중 하나를 계승 [확정: 계승 대상 선택] |
| 구조 | 1막 관리, 붕괴, 2막 이후 기존 방식 | **유지**: 붕괴 후 Act 2부터 기존 게임 방식 [확정] |
| 이미지 | 도트 스프라이트와 층 배경을 사용자에게 요청 | **유지**: 카드 목록으로 시작하고 그림은 사용자에게 요청 |

## 2. 설정에서 달라진 점
| 항목 | 이전에 적었던 것 | 확정된 것 |
|---|---|---|
| 목소리 | 거인이 맡는 아바타·역할 | **인격도 아바타도 아니다.** 방송을 통해 전해지는, 소속들이 기다리는 무형의 무언가. 방송은 목소리를 전하는 수단 [확정] |
| 브랜드 매니저(행동대장) | 3일 차에 가장 광신적인 인물을 임명 | **소속별로 존재하고 그 소속의 목소리를 따르는 행동대장.** 임명 직책이 아님 [확정] |
| 소속 차이 | 카키는 관측 중심, 누아르는 개입 중심 | 확정하지 않는다. 카키는 **도시의 유지와 운영**, 누아르는 **도시의 통제와 질서**이고 선악이 아니다. 게임적 차이는 이 역할에서 도출한다 [확정: 역할, 제안: 차이] |
| 하루 행동 칸 | 3칸 | 제안일 뿐 확정 규칙이 아니다 |

## 3. 달라진 게임 시스템 요약 [제안]
- **하루:** 출근(행동대장 보고) → 근무(구역 카드와 4버튼) → 퇴근(정산) → 밤(이상 현상 진행, 행동대장 자율 행동) → 다음 출근.
- **구역과 이상 현상:** 이상 현상은 구역에 붙는 상태이고 단계 0~4로 밤마다 진행한다. 예고를 항상 보여 준다.
- **목소리의 표현:** 소속별 기다림, 공명, (잔향은 미정). 방송은 규칙 문장(범위, 종류, 어조)이다.
- **소속 차이:** 카키는 가동과 순환(마모, 정비), 누아르는 질서와 규칙(위반, 적발, 격리). 균형 막대로 한쪽만 밀 수 없게 한다.
- **행동대장:** 플레이어 소속의 행동대장은 방송 집행과 보고, 다른 소속의 행동대장은 자기 소속 목소리를 따른다. 협력과 충돌의 재료가 된다.

## 4. 기존 게임 코드에서 바뀌는 점 (설계 단계, 아직 수정하지 않음)
| 대상 | 바뀌는 점 |
|---|---|
| 상태 | 거인용 상태 객체 `ch.giant`를 추가한다. 저장은 전체 직렬화라서 자동으로 저장된다 |
| 하루 진행 | `advanceYear`에 거인 훅을 추가하고 `giantFree(G)` 상태 기계를 만든다(시지프의 `sisFree` 방식) |
| 일반 사건 차단 | 시지프 상태에 묶인 활성 조건(`sisOn`, `sisQuiet`)에 거인용 병렬 조건이 필요하다 |
| 효과 처리 | 한 줄짜리 시지프 효과 목록처럼 거인용 접두어 하나로 분기하는 조건을 추가한다 |
| 화면 | 화면 표에 거인 화면을 추가하고, 구역 목록은 이벤트 플래그 방식의 커스텀 화면으로 만든다 |
| 데이터 | 새 데이터 파일 하나를 추가한다(`birth.json` 분리) |
| 진입점 | 해금 출생과 빌드 플래그 방식으로 거인 출생을 연다 |
| 종료와 연결 | 붕괴 시 `giantEnd`와 `giantDone`을 남기고 Act 2는 기존 엔진으로 복귀한다 |
| 그대로 재사용 | 이벤트 모양, 선택 처리, 게이지 막대, 정산 줄, 목표 패널, 봇 시뮬, 파일 분리 빌드 |

## 5. 아직 결정이 필요한 것
행동 제한 방식(칸 또는 시간), 네 행동의 역할 분담과 개입의 비용, 목소리를 기다림·공명·잔향으로 표현할지, 카키와 누아르 차이 제안 수용, 전임 거인 설정, 이상 현상의 종류와 이름, Act 1 길이와 붕괴 조건, 다른 소속 행동대장의 MVP 처리, 시지프 미러 사건 여부. 자세한 목록은 `docs/giant-act1-system-review.md` 10절.
