# 전투 규칙 정리 (src/engine.js `act` 기준, 2026-10-21)

수치는 `src/config.js`, 카드 수치는 `data/cards.json`. 아래는 코드를 읽고 정리한 것이며 실제 로그로 전부 검증한 것은 아니다.

## 1. 한 라운드
1. 두 쪽 모두 `1d100 + 속도×2`(+보너스)로 순서를 정한다. 높은 쪽이 선공.
2. 빛(코스트): 기본 3, 최대 5. 선공이면 +1, 장비·효과로 증가. 손패 4장.
3. 카드를 순서대로 낸다. 코스트(빛)가 부족하면 못 낸다.

## 2. 카드 한 장 = "타수" 번의 공격
- `타수 n`은 아래 3~6단계를 n번 **따로** 반복한다. 명중도 피해 주사위도 타마다 새로 굴린다.
- 공격할 때마다(명중 여부 무관) 내 출혈 스택만큼 피해를 받고 스택이 1 줄어든다.

## 3. 명중 판정 (타마다)
- 공격측: `1d100 + 명중값`, 방어측: `1d100 + 회피값`. 공격측이 **커야** 명중. 동점은 방어 성공.
- 명중값 = `floor(공격×0.5)` + **카드의 "명중 +n"** + 선공 보너스 + 속도 차 보너스(5당 +1, 최대 +4) + 장비·키워드 보정.
- **카드의 "명중 +n"은 피해가 아니라 명중 굴림 보정이다.** (맞았을 때 추가 피해가 아님)
- 방어 자세 상대: 명중이 방어값 이하면 막힘, 피해 1만 받는다. 방어 자세를 뚫으면 피해 ×0.5(방어 무시 효과 제외).

## 4. 피해 계산 (명중한 타마다)
1. 주사위 `dice`개를 굴려 합산. 면 수는 `die`(기본 d6). `range`가 있으면 각 주사위가 `a~b` 안에서만 나온다.
2. + 카드 고정 `b` + 등급 보너스 + 무기 `dmgB`.
3. + `floor(공격 ÷ 6)` (공격력이 피해에도 반영됨).
4. 무기 전용 주사위가 있으면 그 주사위도 추가로 굴려 더한다 (예: 미미크리 2d5).
5. 키워드·패시브·상태 보정(치명, 화염, 파열, 되갚음 등)을 차례로 더하거나 곱한다.
6. 상대의 피해 감소(%, 최대 70%) → 보호막(최대 150, 방어 무시 효과면 건너뜀) → HP.
7. 한 타의 최종 피해가 0 이하여도 최소 1은 들어가는 경우와 아닌 경우가 있다 (효과별로 다름).

## 5. 카드 표기
- `(2d6+6) × 2타` : 주사위 2개 + 고정 6 = 한 타의 피해, 이걸 2번.
- `주사위 2개(각 4~6)` : 범위 주사위. 각 주사위가 4~6.
- `명중 +4` : 명중 굴림 보정.

## 6. 카드 등급 (+1~+3)
| 등급 | 연차 | 고정 | 명중 | 주사위 |
|---|---|---|---|---|
| +1 | 16~ | +2 | +5 | 0 |
| +2 | 31~ | +3 | +10 | +1 |
| +3 | 46~ | +5 | +15 | +1 |
보호막이 있는 카드는 등급이 오르면 보호막도 늘어난다.

## 7. 붉은 안개 (이번에 만든 것)
- 보스: HP 400, 공격 20, 회피 16, 속도 14, 4라운드마다 회피 +10. 덱 7장(대절단 2, 가로베기, 세로베기, 돌진 2, 방어, 대절단 가로). HP 50% 이하에서 칼리 개방(공격 +20, 회피 −5, 피해 +5, 받는 피해 −10%, 빛 +3).
- 보상: 코트(HP +50), 미미크리 (프로토타입)(공 +25), 책장 "붉은 안개". 방어구 드롭은 끔.
- 책장 패시브: 전투 시작 때 최대 HP의 10% 보호막(상한 없음) · 적을 쓰러뜨리면 HP 60 + 최대 HP의 15% 회복(상한 없음, 최대 HP까지만).
- 개방: 미미크리 (프로토타입)를 들고 적중 12번 → 다음 손패에 "대절단 가로"(5코) 1장, 빛 +2로 2라운드. 카드를 쓰면 게이지 0.
- 책장 카드: 방어 1코 / 가로베기 1코 / 세로베기 2코 2타 / 돌진 3코 2타 / 대절단 4코 1타 + (개방) 대절단 가로 5코.

## 8. 확인이 필요한 것
- 붉은 안개 카드의 "명중 +n"(가로 +6, 세로 +4, 돌진 +8, 대절단 +60, 대절단 가로 +50)은 명중 보정이라 피해를 올리지 않는다. 대절단의 +60은 거의 필중이 될 뿐이다. 피해를 올리려면 고정(`b`)이나 주사위를 올려야 한다.
- 타수 카드의 고정값이 타마다 붙는다는 점이 카드 설명에 드러나는지.
