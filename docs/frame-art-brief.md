# 테두리(프레임) 제작 지침 (전달용 · 2026-11-05 초안)

- **제작 분담:** 이미지는 사용자가 만들어서 전달하고, Claude는 크기 변환·색 입히기·화면 연결·글자 대비 검사를 맡는다(Claude가 직접 그리지 않는다).
- **쓰임:** 전투 중 내 카드(이름 줄 + HP + 상태 칩, 칩이 늘면 세로로 길어진다). 이후 일대기·결과 카드에도 쓸 수 있다.
- **참고 이미지 주의:** 스톡 사이트(워터마크가 보이는 세트)는 그대로 쓸 수 없다. 스타일 참고로만 쓰고, 새로 그린 원본이거나 게임에 넣고 재배포해도 되는 라이선스가 확인된 것만 쓴다.

## 1. 한 틀(프레임 1종)에 필요한 조각
| 파일 | 내용 | 크기 | 비고 |
|---|---|---|---|
| `frame_<id>_corner.png` | 좌상단 코너 1개 | 256×256, 투명 배경 | 나머지 세 모서리는 뒤집어서 쓴다(좌우·상하 대칭이 되게) |
| `frame_<id>_edge.png` | 가로 띠(좌우가 이어지는 타일) | 64×512, 투명 배경 | 세로 변은 회전해서 쓴다 |
| `frame_<id>_cap.png` (선택) | 위쪽 가운데 장식 | 256×128, 투명 배경 | 없어도 된다 |
| `frame_<id>_accent.png` (선택) | 포인트(보석·점)만 **흰색**으로 칠한 마스크 | corner/cap과 같은 크기·위치 | 코드가 내 특색 색으로 칠한다 |
| `frame_<id>_ring.png` (선택) | 가장자리 무늬 띠(HUD 선·아르데코 선) | 64×512 타일 | 안쪽은 비워 둔다, 불투명도 60% 이하 |

## 2. 만들 때 지킬 것
- 글자·워터마크·배경 채움 없음. 안쪽 가운데 60% 이상은 비어 있어야 한다.
- 선 두께는 256px 기준 2px 이상(작게 줄여도 보이게). 금속색(금·은·흰·청 등) + 포인트 1색.
- 틀 자체는 특색 색에 따라 바뀌지 않는 고정색, 포인트(accent 마스크)만 특색 색으로 바뀐다.
- 파일 형식은 PNG(투명)나 SVG. 전달할 때 `assets/frame/` 아래에 두는 것을 기준으로 한다.

## 3. 글자가 안 보이는 것을 막는 규칙 (코드와 검사가 맡는다)
- 배경색은 패널색에 특색 색을 **8% 이하**만 섞는다(15색 모두 본문 11.7:1, 흐린 글자 4.9:1; 12%는 4.4:1, 18%는 3.7:1이라 기준 4.5 미만).
- 무늬(ring)는 가장자리 12px 띠에만 올리고 가운데로 들어오지 않는다. 글자 아래에는 항상 어두운 안전판(불투명도 88%)을 깐다.
- 검사: 모든 틀 × 15색 × 4가지 배경 테마(기본·단테·검지 단말기·도서관 초대장)에서 글자 대비를 계산한다. 본문 7:1 미만 또는 흐린 글자 4.5:1 미만이면 실패하고, 그 조합은 무늬·배경 변화를 끄고 단색 안전판으로 대체한다.

## 4. 구현상 쓰지 않는 것 (저장 이미지가 깨진다)
시험(html2canvas 1.4.1)으로 확인: `border-image`는 저장본에 안 그려지고, `mask`는 색 덩어리가 덮이고, `mix-blend-mode`는 글씨를 가린다. 틀·무늬는 평범한 이미지(`img`/`background-image`)로만 올린다.

## 5. 해금 연결 (초안)
심볼 수집률 5% · 15% · 30% · 50% · 75% · 100%마다 틀 1종씩(총 6종) + 기본. 소속별로 틀을 따로 만들지 않는다.
