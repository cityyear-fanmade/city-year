시지프 이미지 · 무늬·장식 GPT 프롬프트 (2026-11-17)

지금까지 받은 마네킹·옷 그림체와 똑같이 맞춘다. 같은 대화에서 시트(또는 옷 한 장)를 다시 올려 "기준 그림"으로 쓴다.
게임에서는 옷 위에 무늬를 겹치고(곱하기), 장식을 옷 위에 올린다. 그래서 아래 조건이 중요하다.
- 무늬: 무채색 흑백 위주, 옷 모양 없이 무늬만, 상하좌우로 이어지는 반복 패턴, 정사각형.
- 장식: 물건 한 개, 정면, 작게 쓰이므로 단순하고 굵은 윤곽선.
※ 한 번에 한 장씩. 한 장에 여러 개를 그리라고 하지 않는다.

------------------------------------------------------------
[1] 무늬 5장 (sis_pt_stripe / band / check / dots / stitch)
공통 문장(앞에 붙인다)
```
올린 옷 그림과 같은 굵은 외곽선 느낌과 단순한 면 처리로, 아래 무늬 하나만 한 장에 그려 줘. 옷이나 마네킹 모양은 그리지 마. 정사각형 전체를 무늬가 채우고, 위아래·좌우로 이어 붙여도 이음새가 보이지 않는 반복 패턴. 색은 흰색 배경에 옅은 회색(밝기 85%)과 중간 회색(밝기 55%)만 사용. 글자·사람·그림자 없음. 1:1, 1024×1024.
```
뒤에 붙일 무늬 설명
| id | 무늬 설명 |
|---|---|
| sis_pt_stripe 줄무늬 | `세로 줄무늬. 굵은 줄과 얇은 줄이 번갈아 나옴. 줄 폭은 가로 1024 안에 8~10줄.` |
| sis_pt_band 띠 | `가로로 지나가는 띠. 굵은 띠 하나와 얇은 띠 두 개가 한 묶음이고, 묶음이 위아래로 반복(세로 1024 안에 3묶음).` |
| sis_pt_check 격자 | `체크 격자. 굵은 가로줄과 세로줄이 교차하고, 교차 칸마다 중간 회색이 한 겹 더 진해짐. 한 칸 크기 약 128px.` |
| sis_pt_dots 물방울 | `크기가 같은 동그란 물방울 무늬. 어긋나게(벽돌 배치) 반복. 점 지름 약 60px, 점 윤곽선 없이 면만.` |
| sis_pt_stitch 박음선 | `점선 박음선. 가로로 짧은 선(바늘땀)이 줄지어 있고, 줄 사이 간격 약 80px. 땀 길이와 간격이 일정.` |

------------------------------------------------------------
[2] 장식 스프라이트 4장 (sis_tr_button / tooth / eye / buckle)
공통 문장(앞에 붙인다)
```
올린 옷 그림과 같은 굵은 검은 외곽선, 은회색 두 단계 명암의 그림체로, 아래 장식 하나만 한 장에 그려 줘. 물건 하나, 정면, 정중앙, 사방 여백 25%(작게 쓰일 것이라 단순하게). 배경 단색 초록(#00FF00), 글자·사람 얼굴·그림자 없음. 1:1, 1024×1024.
```
| id | 장식 설명 |
|---|---|
| sis_tr_button 단추·브로치 | `둥근 단추 한 개 옆에 작은 십자 모양 브로치 한 개. 단추에는 구멍 두 개. 단정하고 각진 인상.` |
| sis_tr_tooth 손톱·이빨 | `손톱 두 개와 이빨 세 개가 한 줄로 가는 끈에 꿰어 있는 장식 줄. 날것 같지만 피나 잔인한 표현은 없게. 끈 묶음에만 붉은색 포인트.` |
| sis_tr_eye 눈알 구슬 | `둥글게 깎은 구슬 한 개. 눈동자 하나만 있는 모양(눈썹·얼굴 없음). 눈동자에만 노란 금색 포인트.` |
| sis_tr_buckle 부품 | `각진 사각 버클 한 개와 고리 한 개. 고리 안쪽에만 연한 금색 포인트.` |

------------------------------------------------------------
확인할 때 볼 것
- 무늬: 초록 배경이 아니라 흰 바탕에 회색으로 나왔는지, 위아래·좌우로 이어도 이음새가 없는지. 옷 모양이 그려지면 "옷 모양 없이 무늬만"으로 다시.
- 장식: 선 굵기와 명암이 옷 그림과 같은지, 글자가 없는지.
- 파일 이름은 위 id로 저장해서 보내 주면 된다. 제가 옷 위에 겹치는 위치와 크기를 맞춘다.
