# 심볼 새로 만들기 · 제미나이(앱) 프롬프트

현재 심볼(`assets/symbol/*_big.png`)은 장식이 많아 24~32px로 줄이면 뭉개진다. 완성도와 분위기는 현재 수준으로 유지하되 **작게 줄여도 읽히는 구도·명암**으로 다시 만든다. (GPT가 "5세 그림처럼" 단순하게 그려 준 결과는 폐기했다. 아이 그림·낙서 느낌은 원하지 않는다)
이미지는 사용자가 만들어서 전달하고, Claude는 투명 배경 변환·크기별 확인·색 입히기·코드 연결만 한다.

## 사용 방법
1. 제미나이에 기존 심볼 3~4장(`assets/symbol/`의 `index_big.png`, `middle_big.png`, `pinky_big.png`, `ring_big.png`)을 **모티브 이미지**로 올린다. 64px짜리(`index.png` 등)는 화질이 낮아 쓰지 않는다.
2. 아래 [공통 프롬프트]를 붙여 넣고, 마지막 `{모티프}` 줄만 `docs/symbol-art-brief.md`의 표에서 바꿔 넣는다.
3. 한 장씩 만든다. 결과는 PNG로 저장해 `id`(예: `of_lamp.png`)를 파일명으로 해서 전달한다.

## 공통 프롬프트

```
첨부한 이미지는 우리 게임에서 이미 쓰고 있는 심볼 시리즈다. 이 디자인을 모티브로 삼아, 같은 시리즈에 들어갈 새 심볼 하나를 그려 줘.
처음 보는 스타일로 새로 만들지 말고, 첨부 이미지들과 한 세트로 보이게 만든다. 세트의 공통 문법은 다음과 같다.
- 가운데에 방패·마름모·화면 같은 단단한 틀이 있고, 그 안에 상징물 하나가 들어간다.
- 위아래로 뾰족하게 뻗는 날카로운 끝장식, 틀을 감싸는 가는 사슬·고리·궤도선이 있다.
- 사방으로 뻗는 네 갈래 별빛이 포인트 장식으로 한두 개 들어간다.
- 검은 외곽선 + 은회색·크림색 금속 본체 + 한 가지 포인트색(청록·보라·하늘색 등).
- 어둡고 정교한 게임 UI 엠블럼 느낌의 고급 일러스트. 낙서·아이 그림·만화풍은 금지.
틀과 끝장식의 문법은 유지하고, 안쪽 상징물과 포인트색만 아래 [그릴 것]에 맞게 바꾼다.
게임 화면에서는 가로 24~32픽셀까지 줄여 쓰므로, 줄였을 때도 형태가 또렷하게 읽히도록 첨부 이미지보다 장식 수를 줄이고 큰 형태를 키운다.

[작게 줄였을 때 잘 보이게 하는 방법]
- 크고 뚜렷한 중심 실루엣 하나. 바깥 윤곽만 봐도 무엇인지 알 수 있어야 한다.
- 굵고 선명한 검은 외곽선(전체 폭의 4~6%). 얇은 선과 아주 작은 장식(잔 무늬, 작은 별, 스파크, 리벳, 가는 균열)은 넣지 않는다.
- 안쪽 디테일은 크고 대비가 강한 것 3개 이하. 디테일끼리 붙어 뭉개지지 않게 사이를 충분히 띄운다.
- 밝은 면과 어두운 면의 명암 대비를 크게 준다. 중간 톤이 길게 이어지는 부드러운 그라데이션은 피한다.
- 은회색 금속 본체 + 포인트색 한 곳(채도 높은 한 가지 색). 포인트색은 한 군데에만 쓰고 나머지는 회색·흰색·검정 같은 무채색으로만 칠한다.
- 가운데 정렬, 정사각형 구도, 가장자리에 여백. 엠블럼 하나만 그린다.

[금지]
- 배경은 균일한 단색 초록(#00FF00). 심볼 안에는 초록 계열을 쓰지 않는다. 배경에 그림자·그라데이션·워터마크를 넣지 않는다.
- 사람 얼굴, 글자(한글·영문·숫자), 외부 로고를 넣지 않는다.
- 크기는 512×512.

[그릴 것]
{모티프}
```

`{모티프}` 예시 (`docs/symbol-art-brief.md` 3절 표에서 그대로 가져온다)
- 가로등 기둥 하나 — 외눈 램프, 포인트색은 램프 불빛
- 어금니 실루엣 하나 + 윗면의 톱날 세 개

## 받은 뒤 확인 (Claude가 한다)
- 배경 제거 후 24 · 32 · 48 · 96px로 줄여 한 장에 늘어놓고 알아볼 수 있는지 본다.
- 4가지 테마 배경 위와 15가지 특색 색을 입힌 상태에서 포인트색만 바뀌는지 본다.
- 안 읽히는 것은 프롬프트에 "형태를 더 크고 단순하게"를 더해 다시 만들어 달라고 요청한다.
