# 심볼 새로 만들기 · 제미나이(앱) 프롬프트

현재 심볼(`assets/symbol/*_big.png`)은 장식이 많아 24~32px로 줄이면 뭉개진다. 같은 계열의 분위기는 유지하되 **작게 줄여도 읽히는 단순한 형태**로 다시 만든다.
이미지는 사용자가 만들어서 전달하고, Claude는 투명 배경 변환·크기별 확인·색 입히기·코드 연결만 한다.

## 사용 방법
1. 제미나이에 기존 심볼 1~2장(`index_big.png`, `middle_big.png` 등)을 **참고 이미지**로 올린다.
2. 아래 [공통 프롬프트]를 붙여 넣고, 마지막 `{모티프}` 줄만 `docs/symbol-art-brief.md`의 표에서 바꿔 넣는다.
3. 한 장씩 만든다. 결과는 PNG로 저장해 `id`(예: `of_lamp.png`)를 파일명으로 해서 전달한다.

## 공통 프롬프트

```
첨부한 이미지는 게임에서 쓰는 엠블럼(심볼)이다. 이 이미지들과 같은 계열의 어두운 금속 엠블럼 느낌은 유지하되,
훨씬 단순하고 굵은 형태로 새 엠블럼 하나를 그려 줘. 작게 줄여도(가로 24~32픽셀) 한눈에 알아볼 수 있어야 한다.

[그리는 방식]
- 5세 이하 아이가 크레파스로 그린 것처럼 단순하고 굵은 도형으로 그린다. 선은 굵고, 면은 크고, 작은 장식은 넣지 않는다.
- 실루엣이 한 덩어리로 읽히게 한다. 형태를 지워도 검은 실루엣만으로 무엇인지 알 수 있어야 한다.
- 세부 묘사(잔 무늬, 리벳, 균열, 글씨, 작은 별·불꽃)는 전부 뺀다. 디테일은 3개 이하.
- 검은 굵은 외곽선(전체 폭의 4~6%) + 은회색 본체(밝은 면과 어두운 면 두 톤만) + 포인트색 한 곳(채도 높은 한 가지 색).
- 포인트색은 한 군데에만 쓴다. 나머지는 회색·흰색·검정 같은 무채색으로만 칠한다. 그라데이션과 그림자 효과는 쓰지 않는다.
- 가운데 정렬, 정사각형 구도, 가장자리에 여백을 둔다. 엠블럼 하나만 그린다.
- 배경은 균일한 단색 초록(#00FF00). 심볼 안에는 초록 계열을 쓰지 않는다. 배경에 그림자·그라데이션·워터마크를 넣지 않는다.
- 사람 얼굴, 글자(한글·영문·숫자), 외부 로고를 넣지 않는다.
- 크기는 512×512.

[그릴 것]
{모티프}
```

`{모티프}` 예시 (`docs/symbol-art-brief.md` 3절 표에서 그대로 가져온다)
- 가로등 기둥 하나 — 외눈 램프, 포인트색은 램프 불빛
- 어금니 실루엣 하나 + 윗면의 톱날 세 개

## 받은 뒤 확인 (Claude가 한다)
- 배경 제거 후 24 · 32 · 48 · 96px로 줄여 한 장에 늘어놓고 알아볼 수 있는지 본다.
- 4가지 테마 배경 위와 15가지 특색 색을 입힌 상태에서 포인트색만 바뀌는지 본다.
- 안 읽히는 것은 프롬프트에 "형태를 더 크고 단순하게"를 더해 다시 만들어 달라고 요청한다.
