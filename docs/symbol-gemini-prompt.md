# 심볼 새로 만들기 · 제미나이(앱) 프롬프트

현재 심볼(`assets/symbol/*_big.png`)은 장식이 많아 24~32px로 줄이면 뭉개진다. 완성도와 분위기는 현재 수준으로 유지하되 **작게 줄여도 읽히는 구도·명암**으로 다시 만든다. (GPT가 "5세 그림처럼" 단순하게 그려 준 결과는 폐기했다. 아이 그림·낙서 느낌은 원하지 않는다)
이미지는 사용자가 만들어서 전달하고, Claude는 투명 배경 변환·크기별 확인·색 입히기·코드 연결만 한다.

## 사용 방법
1. 제미나이에 기존 심볼을 **1~2장만** 화풍 참고용으로 올린다(`assets/symbol/index_big.png`, `ring_big.png`). 많이 올리거나 `middle_big.png`를 올리면 그 틀을 베낀다. 64px짜리(`index.png` 등)는 화질이 낮아 쓰지 않는다.
2. 아래 [공통 프롬프트]를 붙여 넣고, `{틀}`과 `{모티프}`만 `docs/symbol-art-brief.md`의 표에서 바꿔 넣는다.
3. 한 장씩 만든다. 결과는 PNG로 저장해 `id`(예: `of_lamp.png`)를 파일명으로 해서 전달한다.

## 공통 프롬프트

```
첨부한 이미지들은 우리 게임의 기존 심볼이다. 이 이미지들에서는 **그림 솜씨(화풍)만** 가져온다:
검은 굵은 외곽선, 은회색 금속 질감, 어둡고 정교한 게임 UI 엠블럼의 완성도, 포인트색 한 가지만 쓰는 색 처리.
첨부 이미지의 틀(마름모·방패·화면), 사슬, 고리, 별빛 장식, 구도는 **절대 따라 하지 않는다.** 첨부 이미지와 겹쳐 보이면 실패다.
틀과 구도는 아래 [틀]과 [그릴 것]에 적힌 것만 따른다. 낙서·아이 그림·만화풍은 금지.
게임 화면에서는 가로 24~32픽셀까지 줄여 쓰므로, 줄였을 때도 형태가 또렷하게 읽히도록 장식 수를 줄이고 큰 형태를 키운다.

[틀]
{틀}

[작게 줄였을 때 잘 보이게 하는 방법]
- 크고 뚜렷한 중심 실루엣 하나. 바깥 윤곽만 봐도 무엇인지 알 수 있어야 한다.
- 굵고 선명한 검은 외곽선(전체 폭의 4~6%). 얇은 선과 아주 작은 장식(잔 무늬, 작은 별, 스파크, 리벳, 가는 균열)은 넣지 않는다.
- 안쪽 디테일은 크고 대비가 강한 것 3개 이하. 디테일끼리 붙어 뭉개지지 않게 사이를 충분히 띄운다.
- 밝은 면과 어두운 면의 명암 대비를 크게 준다. 중간 톤이 길게 이어지는 부드러운 그라데이션은 피한다.
- 은회색 금속 본체 + 포인트색 한 곳. 포인트색은 [그릴 것]에 적힌 색으로 고정하고(다른 색으로 바꾸지 않는다) 한 군데에만 쓴다. 나머지는 회색·흰색·검정 같은 무채색으로만 칠한다.
- 가운데 정렬, 정사각형 구도, 가장자리에 여백. 엠블럼 하나만 그린다.
- 판(틀) 안의 상징물은 판 지름의 70% 이상으로 크게 그린다. 상징물이 작으면 24px에서 점으로만 보인다.
- 판 표면의 긁힌 자국·얼룩 같은 질감은 최소로 하고, 상징물과 포인트색 부분을 가장 밝고 선명하게 한다.

[금지]
- 배경은 균일한 단색 초록(#00FF00). 심볼 안에는 초록 계열을 쓰지 않는다. 배경에 그림자·그라데이션·워터마크를 넣지 않는다.
- 사람 얼굴, 글자(한글·영문·숫자), 외부 로고를 넣지 않는다.
- 크기는 512×512.

[그릴 것]
{모티프}
```

`{틀}`은 그룹별로 아래 문장을 넣는다 (`docs/symbol-art-brief.md` 2절 표와 같다)
- 사무소 일반: 간판 같은 단단한 방패 또는 원형 판 하나. 각진 직선 위주, 장식은 적게. 사슬·고리·별빛 없음
- 사무소 상위: 일반보다 장식이 늘고 모티프가 판 밖으로 뻗는 새 실루엣
- 날개: 깃털 + 방패형 윤곽. 안쪽 문양으로 구분
- 협회: 숫자·선·점으로 구분하는 원형 인장
- 산하: 소속 손가락 심볼의 실루엣 일부를 변형한 형태
- 출생·직업: 완전히 새 실루엣, 상징물 하나 (마름모 틀 금지)

`{모티프}` 예시 (`docs/symbol-art-brief.md` 3절 표에서 그대로 가져온다)
- 가로등 기둥 하나 — 외눈 램프, 포인트색은 램프 불빛
- 어금니 실루엣 하나 + 윗면의 톱날 세 개

## 받은 뒤 확인 (Claude가 한다)
- 배경 제거 후 24 · 32 · 48 · 96px로 줄여 한 장에 늘어놓고 알아볼 수 있는지 본다.
- 4가지 테마 배경 위에서 포인트색(고정색)이 24px에서도 보이는지 본다. 사무소 등 소속 심볼은 캐릭터 색으로 바뀌지 않는다.
- 안 읽히는 것은 프롬프트에 "형태를 더 크고 단순하게"를 더해 다시 만들어 달라고 요청한다.

## 결과를 받은 뒤 지울 것
- 제미나이 이미지 오른쪽 아래의 작은 ✦ 표시(워터마크)는 우리가 지운다. 프롬프트로 막을 수 없다.
