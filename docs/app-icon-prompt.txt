도시의 한 해 · 홈 화면 아이콘 프롬프트 (2026-11-17)

용도: 폰 홈 화면에 설치하는 앱 아이콘. 작게 보여도 알아볼 수 있어야 한다.
게임 색: 배경 짙은 남흑색(#0c0e13), 포인트 금색(#c8a35a), 글자색 아이보리(#e7e2d7).

규칙
- 한 번에 한 장. 정사각형 1:1, 1024×1024.
- 아이콘 안에 글자(한글·영문·숫자)를 넣지 않는다. 사람 얼굴도 넣지 않는다.
- 원작(프로젝트 문) 로고·캐릭터를 그대로 따라 그리지 않는다. 이 게임만의 상징으로.
- 가장자리는 둥글게 자르지 않고 정사각형 전체를 칠한다(폰이 알아서 둥글게 잘라 준다).
- 중요한 그림은 가운데 70% 안에만 둔다(가장자리가 잘려도 보이게).

[프롬프트 1] 도시 + 한 해
```
모바일 앱 아이콘. 정사각형 1024×1024, 배경은 짙은 남흑색(#0c0e13) 단색에 아주 약한 안개 그라데이션. 가운데에 금색(#c8a35a) 선으로 그린 단순한 상징 하나: 둥근 시계 모양 원 안에 도시 건물 실루엣(높낮이가 다른 직사각형 5~6개)이 들어 있고, 원 가장자리의 한 곳이 열려 있어 한 해의 시작과 끝처럼 보인다. 선은 굵고 단순하게, 면은 평평하게. 글자·얼굴·그림자·사실적 질감 없음. 가운데 70% 안에 모든 그림이 들어가게.
```

[프롬프트 2] 열쇠 구멍 + 도시
```
모바일 앱 아이콘. 정사각형 1024×1024, 짙은 남흑색(#0c0e13) 배경. 가운데에 금색(#c8a35a)의 큼직한 열쇠 구멍 모양 하나, 구멍 안쪽에 도시 건물 실루엣(아이보리 #e7e2d7)이 보인다. 굵고 단순한 도형, 평평한 면, 한 단계 그림자만. 글자·얼굴·원작 로고 없음. 그림은 가운데 70% 안에.
```

[프롬프트 3] 주사위 + 도시
```
모바일 앱 아이콘. 정사각형 1024×1024, 짙은 남흑색(#0c0e13) 배경. 가운데에 금색(#c8a35a) 외곽선의 20면체 주사위 하나, 주사위 한가운데 면에 도시 건물 실루엣이 작게 들어 있다. 면은 평평하고 선은 굵게, 한 단계 그림자만. 글자·숫자·얼굴·원작 로고 없음. 그림은 가운데 70% 안에.
```

받은 뒤
- 파일 이름: app-icon.png 로 주면 된다(원본 그대로).
- 제가 192·512 크기와 아이폰용 180 크기를 만들고, 설치 정보 파일과 오프라인 저장(네트워크 우선)을 붙인다.
- 세 장 중 마음에 드는 하나를 고르면 된다. 마음에 안 들면 "더 단순하게", "금색을 더 밝게" 같은 한 줄로 다시 요청한다.
