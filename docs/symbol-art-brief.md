# 심볼 이미지 제작 지침 (전달용)

도시의 한 해 · 심볼 46종(기존 손가락 5·특색 3은 완료). 이 문서만 보고 작업할 수 있게 정리했다. 점수·해금 규칙은 `docs/symbols.md`.

## 1. 공통 규칙 (전부 지킬 것)
- **한 장에 심볼 하나.** 가운데 정렬, 실루엣이 한 덩어리로 읽혀야 한다. 둘레에 잔 장식(스파크·먼지)을 흩뿌리지 않는다.
- **배경은 단색 초록(#00FF00 계열 크로마키).** 심볼 안에 초록 계열을 쓰지 않는다. 배경에 그림자·그라데이션·워터마크가 남지 않게 한다.
- **검은 굵은 외곽선 + 은회색 본체 + 금색 또는 포인트색 한 곳.** 기존 손가락 5종(`assets/symbol/*_big.png`)과 같은 톤: 어두운 금속 느낌, 뾰족한 장식, 은색 하이라이트, 금색 포인트.
- **색은 포인트 한 곳에만, 색은 심볼마다 미리 정한다.** 사무소·날개·협회·출생직업 심볼은 캐릭터 색으로 바뀌지 않는다(색이 바뀌는 것은 특색 3종뿐). 그래서 각 심볼의 포인트색은 아래 표에 적힌 고정색이고, 나머지(판·본체)는 회색·흰색·검은색 무채색으로 둔다. 심볼 전체를 한 색으로 물들이지 않는다.
- **작게 줄여도 읽혀야 한다(32px).** 디테일은 3개 이하. 실루엣만으로 서로 구분돼야 한다.
- **사람 얼굴·AI 인물 금지.** 글자(한글·영문)도 넣지 않는다(예외: 윤 사무소의 "윤"은 글자를 도형화한 것).
- **원작 로고를 그대로 따라 그리지 않는다.** 이름과 상징 개념(모티프)은 따르되 도안은 새로 그린다.
- **납품 형식:** PNG, 512×512, 파일명은 아래 표의 `id`. 투명 배경 처리는 우리가 한다(초록 배경 그대로 납품).

## 2. 그룹별 틀
같은 그룹은 외곽 두께와 장식 톤을 맞추고 안쪽 모티프만 바꾼다. 그룹 사이는 틀 자체가 달라야 한다.

| 그룹 | 틀(분위기) |
|---|---|
| 사무소 일반 9 | 간판 같은 단단한 방패·원형 판 위에 모티프 하나. 소박하고 각진 직선 위주. 손가락보다 장식이 적다 |
| 사무소 상위 3 | 일반보다 장식이 늘고 모티프가 판 밖으로 뻗는다 (투귀·러스크·찰스는 각자 새 실루엣) |
| 날개 6 | 깃털 + 방패형 윤곽. 안쪽 문양으로 회사를 구분한다 |
| 협회 8 | 숫자·선·점으로 구분하는 원형 인장. 통일감 있게, 개수·배치로 구분 |
| 산하 3 | 소속 손가락 심볼의 실루엣 일부를 변형한 형태(산하임이 드러나게) |
| 출생·직업 17 | 완전히 새 실루엣, 상징물 하나 (손가락·특색과 겹치지 않게) |

## 4. 작업 순서 (중간 확인 지점)
1. 사무소 일반 9 → 방향 확인(우리 톤과 맞는지)
2. 날개 6 + 협회 8 (각자의 문양 정보를 먼저 받을 것)
3. 사무소 상위 3 + 산하 3
4. 히든·해금 출생 13 + 중간 진입 직업 4

## 5. 납품 후 우리가 하는 일
- 초록 배경 제거, 가장자리 정리, 512 → 256 / 64 / 32px 변환
- `assets/symbol/` 에 넣고 시험판에서 32px로 읽히는지 확인(안 읽히면 단순화를 요청)
- 색 변환(특색 색 적용)이 포인트색 한 곳에만 걸리는지 확인

## 6. 확인이 필요한 항목 (제작 전에 정할 것)
- 러스크 사무소와 날개 6곳의 고유 문양(원작 상징을 아는 사람이 알려 줄 것)
- 협회를 8장으로 할지 1장으로 할지
- 출생 심볼을 위 목록 그대로 가져갈지(혈귀·라만차랜드 줄기는 보류라 제외)
