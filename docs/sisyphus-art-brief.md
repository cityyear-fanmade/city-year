# 시지프 백화점 이미지 제작 지침 (전달용 · 2026-11-14)

재단대(옷 제작) 화면과 구역 선택 화면에 쓸 이미지 22장. **이미지가 없어도 게임은 글자 칩으로 동작하고, 이미지를 주시면 그 자리에 들어간다.** 규격과 톤은 `docs/symbol-art-brief.md` 1절과 같다.

## 방향 (2026-11-14 갱신)
- **그림체는 림버스 컴퍼니의 2D 캐릭터 정도의 단순한 게임 그림체로 한다.** 고급스럽거나 반짝이는 일러스트(AI 특유의 과한 광택·질감·장식)는 피하고, 면과 선이 단순한 느낌이면 충분하다.
- **재단대는 동숲식**이다. 형태·무늬·색은 게임 안에서 SVG로 그려서 마네킹에 입히므로 옷 이미지는 꼭 필요하지 않다. 아래 이미지는 **선택**이고, 재료·장식·구역·작업대 이미지가 우선이다.

## 공통 규칙
- 한 장에 하나. 가운데 정렬, 실루엣이 한 덩어리로 읽힐 것.
- 배경은 **단색 초록(#00FF00 계열 크로마키)**. 그림자·그라데이션 없음. 그림 안에 초록 계열 사용 금지.
- 검은 굵은 외곽선 + 은회색 본체 + 포인트색 한 곳. **글자·사람 얼굴 금지.** 원작 로고·도안을 따라 그리지 않는다(이름과 개념만 참고).
- 납품: PNG **512×512**, 파일명은 아래 id. (게임에서는 96~128px로 줄여 쓴다. 용량 때문에 이미지 총량을 작게 유지한다.)
- 염료와 옷은 색을 **은회색(무채색)으로 그려 주세요.** 검정·붉은색·무채색 같은 색은 게임에서 입힌다.
