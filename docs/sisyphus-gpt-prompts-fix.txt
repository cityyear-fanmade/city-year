방금 받은 시트(마네킹 1 + 옷 6)가 좋아서 이 그림체를 그대로 쓴다. 고칠 것은 세 가지다.
(1) 한 장에 모여 있으니 한 장씩 따로, (2) 옷이 마네킹보다 크니 마네킹에 맞는 크기로, (3) 황금가죽 의복 소매를 짧게.

순서
① 같은 대화에서 시트 이미지를 다시 올린다(기준 그림).
② 아래 [A]를 먼저 보낸다.
③ 마네킹이 나오면 마음에 드는 것을 고르고, [B]를 옷마다 한 장씩 보낸다.
④ 황금가죽 의복은 [C]로 보낸다.
※ 한 번에 한 장씩. 한 장에 여러 개를 그려 달라고 하지 않는다.

[A] 마네킹 한 장 (시트 맨 왼쪽 위 그림 그대로, 따로 한 장)
```
올린 시트의 맨 왼쪽 위 상체 마네킹과 똑같은 그림체·형태로, 마네킹 한 개만 한 장에 따로 그려 줘. 정면, 좌우 대칭, 정중앙, 사방 여백 10%. 같은 선 굵기, 같은 은회색 두 단계 명암, 배경은 단색 초록(#00FF00). 글자·얼굴·그림자 없음. 1:1, 1024×1024.
```

[B] 옷 한 장 (옷마다 "형태 설명"만 바꿔서 보낸다)
```
올린 시트의 {옷 이름}과 같은 형태·그림체로, 옷 한 벌만 한 장에 따로 그려 줘.
크기 규칙: 방금 만든 마네킹에 입혔을 때 어깨선이 마네킹 어깨와 같은 폭이 되도록, 어깨 폭을 마네킹 어깨 폭의 약 1.1배로 그려 줘. 옷 전체는 마네킹 상체(목 아래~허리 조금 아래) 길이에 맞춰 줘.
마네킹 없이 옷만, 정면, 좌우 대칭, 팔은 내리고 소매는 어깨 아래로 짧게. 무늬 없는 은회색 무채색. 같은 선 굵기, 같은 명암 두 단계. 배경 단색 초록(#00FF00), 글자·얼굴 없음. 1:1, 1024×1024, 정중앙, 사방 여백 10%.
```
{옷 이름}에 넣을 말

※ 정장·외투의 어깨 패드는 그대로 두되 마네킹 어깨 폭의 1.1배 안에 들어오게.

[C] 황금가죽 의복만 다시 (sis_cl_gold)
```
올린 시트의 황금가죽 의복(가운데 아래)과 같은 디자인으로 다시 그려 줘. 바꿀 점: 소매를 나팔 모양이 아니라 다른 옷들처럼 어깨 아래로 짧게. 어깨 폭은 마네킹 어깨 폭의 약 1.1배. 목선과 가운데 세로 이음선에만 금색 포인트(다른 곳은 은회색). 한 장에 옷 한 벌만, 마네킹 없이, 정면 좌우 대칭. 배경 단색 초록(#00FF00), 글자·얼굴 없음. 1:1, 1024×1024.
```
