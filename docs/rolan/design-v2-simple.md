# 검은 가면 해금 — 간소화 안 (2026-11-11, 확인 필요)

배경: 사용자 정리 "롤랑 모티브 해금 캐릭터는 간단하게". 이전 설계(`design.md`, `review-1.md`)의 긴 연표를 줄이고, **검은 침묵의 장갑 → 책장 변환**을 중심에 둔다. 아래는 내가 이해한 내용이며, 틀리면 고친다.

## 핵심 아이디어
1. **같은 이름의 무기, 다른 효과**: 검은 가면 출생이 얻는 "검은 침묵의 장갑"은 일반 출생의 것(공격 카드마다 1d9로 무기가 바뀜)과 효과가 다르다.
2. **무기 주사위 → 카드 효과**: 장갑의 무기 9종(도끼, 장검, 뒤랑달, 쌍검, 단검, 샷건, 랜스, 대검, 해머)이 1d9로 무작위로 바뀌던 것을 **"검은 침묵의 책장" 카드 9장**으로 바꾼다. 플레이어가 고르는 카드가 되고, 무기 자체의 성능은 달라진다(예: 회피 +7만 남기고 무작위 변신 제거).
3. **검은 침묵을 거의 확정으로 만남**: 이 출생은 **인연을 피아니스트에게 잃었을 때** 검은 침묵을 만나고(거의 확정), 이기면 장갑과 책장을 얻는다.
4. **피아니스트는 이 출생 전용으로 강하게**: 지금의 일반 피아니스트(HP 64)와 다른 전용 상대로 만든다.
5. **음악 컨셉 카드 추가**: 리듬, 선율 같은 음악 컨셉의 카드를 이 출생용으로 새로 만든다.

## 간소화한 흐름 (제안)
| 단계 | 내용 |
|---|---|
| 시작 | 17세. 인식 저해 가면(장신구)을 쓰고 시작 |
| 12~14년차 | 첫 인연 강제 만남(고급 해결사 2번). 거절하면 3년 뒤 두 번째 인연 |
| 중반 | 피아니스트 사건(전용 피아니스트) |
| 상실 시 | 검은 침묵 전투(거의 확정) → 검은 침묵의 장갑 + 검은 침묵의 책장 획득 |
| 그 뒤 | 일반 게임 |
- 연기전쟁 3연전, 사무소 입단, 엘레나 전은 이 간소화 안에서는 **뺀다**(필요하면 나중에 추가).
- 인연을 잃지 않았을 때(피아니스트에게 이겨 생존)의 처리는 정해야 한다.

## 장갑 → 책장 변환 (초안, 원래 수치 그대로 옮긴 것)
원래 무기(명중 보정 · 피해 주사위) → 카드:
| 무기 | 원래 | 카드(안) |
|---|---|---|
| 느티나무 공방 도끼 | +6 · 1d3 | 도끼 카드: 명중 +6, 피해 1d3 |
| 묵 공방 장검 | +8 · 2d5 | 장검 카드: 명중 +8, 피해 2d5 |
| 뒤랑달 | +8 · 1d5 | 뒤랑달 카드: 명중 +8, 피해 1d5 |
| 크리스탈 아틀리에 쌍검 | +24 · 1d4 | 쌍검 카드: 명중 +24, 피해 1d4 |
| 랑아 공방 단검 | +16 · 2d2 | 단검 카드: 명중 +16, 피해 2d2 |
| 로직 아틀리에 샷건 | +0 · 1d10 · 확정 명중 | 샷건 카드: 확정 명중, 피해 1d10 |
| 알라스 공방 랜스 | +24 · 1d20 | 랜스 카드: 명중 +24, 피해 1d20 |
| 휠스 인더스트리 대검 | +4 · 8~24 | 대검 카드: 명중 +4, 피해 8~24 |
| 올드보이 공방 해머 | +2 · 2d2 | 해머 카드: 명중 +2, 피해 2d2 |
- 원래 효과의 **Furioso 규칙**(서로 다른 무기 3종이 나오면 다음 손패에 Furioso 1장, 전투당 최대 5회)은 **"서로 다른 책장 카드 3종을 내면"**으로 옮긴다.
- 위 수치는 원래 값이고, 카드로 바뀌면서 코스트·균형을 시뮬로 다시 맞춘다. 장갑의 회피 +7과 "무작위 변신 없음"이 다른 점이다.

## 음악 컨셉 카드 (방향만, 아직 설계 안 함)
- 이 출생 전용 키워드 후보: **박자**(카드를 연속으로 낼 때마다 쌓이고, 3 · 6 · 9에서 효과가 붙는다. 헤르메스의 3-6-9타와 비슷한 구조), **선율**(같은 종류 카드를 이어 낼 때 보너스).
- 카드 이름은 리듬, 선율 같은 말을 따라간다. 수와 효과는 방향을 정한 뒤 만든다.

## 필요한 신규 요소

- 신규 카드: 검은 침묵의 책장 9장 + Furioso 1장(이미 있으면 재사용), 음악 카드 몇 장
- 출생 칸, 해금 조건(검은 침묵 처치), 시작 가면, 인연 흐름, 검은 침묵 확정 만남 이벤트
- 엔진: 시작 장비 2개 확장이 필요하면 최소로(가면만 시작이면 불필요), 거절 뒤 두 번째 인연 예약

# 확정 정리 (2026-11-11, 사용자 정리 반영)

## 시작 상태 (해금 "검은 가면")
- **뒤랑달**(전용 무기), **검은 가면**(장신구), **전용 책장**, **뒤랑달을 활용한 검술**(전용 책장의 시작 카드)을 가지고 시작한다.
- 검은 침묵의 책장과 장갑은 시작 때는 없다.

## 검은 침묵 만남과 보상
- **검은 침묵을 거의 확정으로 만난다.** 인연을 피아니스트에게 잃은 경우가 기본 흐름이다.
- **인연을 잃지 않은 경우에도 만나는 이유를 만든다(추천안)**: 인식 저해 가면이 검은 침묵의 가면과 같은 계통이라, 가면을 쓰고 활동한 이름이 소문으로 퍼져 검은 침묵이 가면 착용자를 확인하러 온다. 상실과 무관하게 성립하는 이유라서 두 경우에 같은 전투와 같은 보상을 줄 수 있다. (다른 후보: 피아니스트의 잔재를 같은 상대로 쫓다 마주친다 / 인연을 지킨 뒤 그 인연이 위험에 놓여 경고하러 온다.)
- 이기면 **검은 침묵의 장갑**과 **검은 침묵의 책장**을 얻는다.

## 장갑 (변경)
- 일반 출생의 장갑은 "회피 +7, 무기 1d9 무작위 변신"이다.
- 검은 가면의 장갑은 **무기 변신 기믹을 카드로 옮겼으므로 장갑 자체에 히든급 능력치(공격, 명중, 피해 등)를 준다.** 수치는 시뮬로 정한다.

## 검은 침묵의 책장 (카드 9종 + Furioso)
- 원래 무기에 있던 9종의 공격(도끼, 장검, 뒤랑달, 쌍검, 단검, 샷건, 랜스, 대검, 해머)을 **카드 9장**으로 바꾼다. 명중 보정과 피해 주사위는 원래 값을 시작점으로 쓰고 코스트는 시뮬로 맞춘다.
- **Furioso 규칙(변경)**: 책장의 **서로 다른 카드를 총 3번 사용하면 바로 다음 손패에 Furioso가 코스트 0으로 들어온다.** 그 턴에 써야 한다(안 쓰면 사라진다). 얻는 횟수에는 제한이 없다(원래는 전투당 최대 5회).

## 이펙트
- 기존 이펙트를 그대로 재사용한다(코드 확인 완료).
  - 뒤랑달 전용 이펙트: 장갑이 무기 3번(뒤랑달)을 고를 때 쓰는 이펙트 `n_bs3`.
  - 책장 카드 9장: 무기 종류별 이펙트 `n_bs1`~`n_bs9`에 각 카드를 연결.
  - Furioso: `n_bsF`.
- 연결 방식: 지금은 장갑이 1d9로 무기를 고를 때 남기는 기록("장갑 1d9 N")으로 이펙트를 고른다. 카드로 바뀌면 카드 아이디로 이펙트를 고르도록 연결을 한 줄 추가한다.
- 시작 무기 뒤랑달(전용 무기)에도 `n_bs3`를 연결한다.

## 남은 결정
1. 시작 전용 책장("뒤랑달을 활용한 검술")의 카드 수와 구성
2. 장갑의 히든급 능력치 방향(공격, 명중, 피해 중 무엇을 중심으로)
3. 상실하지 않은 경우의 검은 침묵 만남 이유(위 추천안으로 갈지)
4. 전용 피아니스트의 설계(체력, 카드, 패시브, 음악 컨셉)
5. 음악 컨셉 카드(박자, 선율)의 방향

## 검은 침묵을 만나는 분위기 (2026-11-11, 사용자 정리)
- 검은 침묵은 "다른 세계의 나"라고 **말하지 않는다.** 정체를 설명하는 문장 없이, **인식 저해 가면을 뚫고 나를 바라보는 느낌**, "나를 알고 있다"는 느낌으로 만난다.
- 상실한 경우와 상실하지 않은 경우 모두 이 분위기로 같은 만남을 쓰고, 상실한 경우만 첫 문장의 분위기를 조금 다르게 한다.
- 이 만남이 상실 여부와 무관하게 성립하는 이유가 곧 "가면(인식 저해)이 통하지 않는 사람이 있다"는 것이다. 별도의 사연은 필요 없다.

### 만남 이벤트 초안 (상실하지 않은 경우, 새로 쓴 문장)
- **제목**: 가면을 뚫는 시선
- **본문**: 사람들이 아무도 얼굴을 기억하지 못하고 스쳐 가는 골목에서 한 사람이 걸음을 멈췄다. 가면은 늘 그랬듯 얼굴을 지우고 있는데, 그 사람의 시선은 지워진 자리를 정확히 짚고 있다. 검은 장갑을 고쳐 끼는 손이 이상하게 낯익다. 모르는 사람이 아는 사람처럼 서 있다.
- **선택지 A 「가면을 벗지 않고 마주 선다」**: 검은 침묵 전투 / 결과 문구(승리 뒤): 장갑이 가볍게 떨어졌다. 상대는 마지막까지 내 얼굴이 아니라 가면 안쪽을 보고 있었다.
- **선택지 B 「시선을 피해 돌아선다」**: 이번에는 넘어가지만 2년 뒤 같은 자리에서 다시 만난다(이때는 피할 수 없다) / 결과 문구: 몇 걸음 만에 시선이 등에 닿는 것이 느껴졌다. 가면은 돌아서도 소용이 없었다.

### 상실한 경우 (첫 문장만 다르게)
- 본문 첫 문장: 모든 것이 비어 버린 뒤의 골목에서, 한 사람이 걸음을 멈췄다. (이후 문장은 위와 같다.)

### 전투 전후
- 전투 전 대사/설명은 최소로 둔다. 상대는 먼저 말하지 않고, 이쪽도 이유를 묻지 않는다.
- 승리 보상: 검은 침묵의 장갑 + 검은 침묵의 책장(히든급 능력치 장갑 · Furioso 규칙 책장).
