# GPT에게 할 말 (짧게, 한 번에 하나) — 2026-11-10

문제: GPT가 과거사와 줄거리를 한꺼번에 쓰려 해서 작업이 안 된다.
원인과 처방: GPT에게 배경을 많이 줄수록 이야기를 키운다. 그래서 **배경(롤랑·과거사·원작)을 아예 빼고**, 길이 상한과 "이것만 하고 멈춰"를 박은 짧은 메시지를 한 번에 하나씩 보낸다.

## 0. 첫 메시지 (딱 한 번, 짧게)
```
한국어 텍스트 게임의 짧은 글을 같이 쓸 거야. 규칙은 이것뿐이야.
1) 내가 시킨 한 가지만 쓰고 멈춘다. 다음 일을 미리 쓰지 않는다.
2) 배경 이야기, 과거사, 인물 설정을 새로 만들지 않는다. 모르면 질문 하나만 한다.
3) 담담한 문어체(~했다, ~이다). 미사여구 없이.
4) 길이 상한을 넘기지 않는다. 내가 말한 개수와 글자 수를 지킨다.
5) 원작 소설·게임의 문장을 쓰거나 비슷하게 바꿔 쓰지 않는다. 사람 이름도 새로 짓지 말고 "그 사람", "{n}"을 쓴다.
이해했으면 "준비됨" 한 단어만 답해.
```

## 1. 해금 설명 문구
```
작업 1: 게임 출생(시작 직업) 설명 문구를 쓴다.
출생 이름: 검은 가면
조건: 가면을 쓴 사무소의 행동대장. 본심을 숨기는 사람.
형식: 3안, 안마다 2문장, 안마다 80자 이내.
이것만 쓰고 멈춰.
```

## 2. 1년차 가면 장면
```
작업 2: 게임 사건 1개를 쓴다. 장면: 주인공이 가면을 쓰고 본심을 숨기기 시작한다.
형식(안 A, 안 B 두 가지):
제목: 한 줄
본문: 3문장 이하, 120자 이내
선택지 2개: 각 20자 이내, 결과 한 문장씩(40자 이내)
과거사, 노인, 가족 같은 배경은 쓰지 않는다.
이것만 쓰고 멈춰.
```

## 3. 사무소 입단
```
작업 3: 사건 1개. 장면: 주인공이 사무소에 처음 들어간다.
형식은 작업 2와 같다(안 A, 안 B). 사무소 이름·사람 이름을 만들지 않는다.
이것만 쓰고 멈춰.
```

## 4. 연기전쟁 전투 글 (전투는 게임이 처리)
```
작업 4: 연속 전투 3번의 앞뒤 글만 쓴다. 전투 내용은 쓰지 않는다.
- 첫 전투 전: 2문장
- 전투 사이: 1문장씩 2개
- 마지막 전투 후: 2문장
분위기: 연기가 자욱한 전장. 이것만 쓰고 멈춰.
```

## 5. 인연 첫 만남 (두 사람)
```
작업 5: 인연과의 첫 만남 장면 2개. 이름은 쓰지 않고 {n}만 쓴다.
A) 백발 장발, 연파란 눈, 검은 터틀넥과 검은 가죽장갑, 소리를 싫어하는 해결사.
B) 청색이 도는 검은 긴 코트, 창백한 얼굴, 호박색 펜던트, 책을 좋아하는 무뚝뚝한 사람.
각 장면: 제목 한 줄 + 본문 3문장 이하(120자 이내) + 선택지 2개(수락·거절, 각 20자 이내).
과거나 사연은 쓰지 않는다. 이것만 쓰고 멈춰.
```

## 6. (선택) 엘레나 전 앞뒤
```
작업 6: 보스 전투 앞뒤 글. 전투 전 2문장, 전투 후 2문장. 상대 이름은 "그 사람"으로만 쓴다.
이것만 쓰고 멈춰.
```

## 7. GPT가 길게 쓰거나 이야기를 만들 때 보내는 말
```
너무 길다. 다시 한다. 내가 말한 개수와 글자 수만 지키고, 배경·과거사·인물 설정은 지운다. 이것만 쓰고 멈춰.
```
```
설정을 새로 만들었다. 그건 지우고, 내가 준 조건만으로 다시 쓴다.
```
```
다음 일은 내가 시킬 때까지 쓰지 않는다. 지금 한 가지만 쓴다.
```

## 쓰는 요령
- 한 메시지에 작업 하나만 보낸다. 결과를 보고 마음에 드는 안(A/B)만 골라 Claude에게 가져온다.
- GPT에게 롤랑, 과거사, 아내, 도서관 이야기는 말하지 않는다. 그 이야기는 이번 범위가 아니다(우리 쪽 설계에만 있다).
- 길이를 못 지키면 7번을 보내고, 두 번 연속 못 지키면 새 대화에서 0번부터 다시 시작한다.
