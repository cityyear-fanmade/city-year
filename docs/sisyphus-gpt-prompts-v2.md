`docs/sisyphus-gpt-prompts.md`(v1)를 대체한다. 바뀐 점: **상체 마네킹(동숲식 흉상)**, 옷은 **층 쌓기**(몸체·무늬·장식), 재료는 확정된 **13종**. 한 번에 다 시키지 말고 **1단계 → 확인 → 2단계** 순서로 간다.

## 0. 대화 맨 처음에 한 번 붙이는 공통 지시
```
앞으로 요청할 이미지는 모두 아래 규칙을 지켜 줘.
- 그림체: 모바일 게임의 2D 아이템 일러스트 정도의 단순한 그림체. 면은 평평하게 칠하고 그림자는 한 단계만(셀 셰이딩). 반짝이는 광택, 사실적인 질감, 과하게 화려한 효과, 흩뿌린 장식은 쓰지 마.
- 선: 검정에 가까운 굵은 외곽선. 선 굵기는 모든 그림에서 같게.
- 색: 은회색 무채색 본체. 포인트 색은 요청에서 지정할 때만 한 곳에 써.
- 배경: 단색 초록(#00FF00). 그림자·그라데이션·바닥선·워터마크 없음. 그림 안에는 초록 계열을 쓰지 마.
- 구도: 한 장에 물건 하나, 정중앙, 정면, 좌우 대칭, 사방 여백 10%.
- 금지: 글자(한글·영문·숫자), 사람 얼굴, 로고, 서명.
- 크기: 정사각형 1:1, 1024×1024.
- 같은 세트의 그림은 선 굵기·명암 단계·채도가 같아야 해.
이해했으면 "알겠어"라고만 답해.
```

## 1단계 (먼저 시킬 것 · 7장): 마네킹과 옷 몸체
**순서가 중요하다.** ① 마네킹을 먼저 만들고, 마음에 드는 것을 골라 ② 이후 요청마다 그 그림을 올리며 "이 마네킹의 어깨 폭과 위치에 정확히 맞는 옷"이라고 붙인다(층을 쌓을 때 어긋나지 않게).

**sis_mannequin · 상체 마네킹**
```
옷가게 진열용 상체 마네킹(흉상) 하나. 목 아래부터 어깨, 가슴, 허리까지만 있고 머리와 팔은 없음. 목은 짧은 기둥으로 끝나고, 허리 아래는 가는 금속 봉과 둥근 받침대. 표면은 매끈한 은회색. 포인트 색 없음.
```

## 3단계 (나중에 · 선택)
무늬 5장(줄무늬·띠·격자·물방울·박음선의 반복 패턴), 장식 스프라이트 4장, 구역 6장, 재단대 1장. 없어도 게임은 기존 그림(SVG·글자 칩)으로 동작한다. 1·2단계 결과를 보고 필요하면 프롬프트를 따로 드린다.

## 받은 뒤
- 파일 이름을 위 id로 저장해서(`sis_cl_daily.png` 등) 초록 배경 그대로 주면 된다. 투명 처리·크기 줄이기·게임 연결은 제가 한다.
- 글자나 얼굴이 들어가거나 선이 얇으면 같은 대화에서 "글자 없이, 외곽선을 더 굵게"로 다시 요청한다.
- 옷이 마네킹과 어긋나 보이면 마네킹 그림을 다시 올리고 "어깨선을 이 마네킹에 맞춰"로 요청한다. 조금 어긋나는 것은 제가 위치를 맞출 수 있다.
