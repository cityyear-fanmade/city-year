# 심볼 시스템 설계 메모 (테섭 · 확정 전)

대화에서 정한 규칙을 모은 문서다. 구현 전 기준 문서이고, 값은 임시다.

## 심볼 종류와 이미지
| 종류 | 대상 | 이미지 상태 |
|---|---|---|
| 조직 | 엄지·검지·중지·약지·소지 (소지는 정식 소지 소속만, 서브 직업 형태 제외) | 5개 완료(assets/symbol) |
| 조직 | 흑운회·검계 전용, 밤의 송곳 미정 | 미제작 |
| 날개 | 최고 임원 날개를 세웠을 때 특정 단계에서 날개 모양 심볼 | 미제작 |
| 협회 | 원본 심볼 8개 또는 하나로 통일(미정) | 미제작 |
| 특색 | 전용 3종 중 선택, 특색 색에 따라 색만 변함, 능력치는 모든 색 동일 | 파일 대기(보라 별·크림 별·금색 고리) |
| 사무소 | 공통 3종 + 사무소 색, 등급에 따라 단계, 1급 전용 심볼 | 미제작(간판·열쇠·깃발 제안) |

## 얻는 규칙
- 심볼은 조직 상징이다. 말단은 없음(또는 낮은 심볼), 중간 직위부터 더 좋은 심볼, 최종 단계에 풀강화 심볼.
- 진행 중에는 개인 심볼(조직·날개·협회·특색)을 **한 번에 하나만** 든다. 능력치를 받기 때문이다.
- 사무소 심볼은 개인이 아니라 **사무소 기준**이고, 개인 심볼과 별개로 같이 해금된다. 특색은 별개 줄기다.
- 1급 사무소 전용 심볼은 직원이 등급이 높아져야 받는다. 개인 특색이 있어도 사무소 급수가 자동으로 오르지 않는다(원작 사례).
- 2급·1급 해결사 사무소(투귀·러스크·찰스)에 소속된 적이 있으면 개인 사무소를 차릴 수 없다 (구현됨).

## 해금 규칙
- 게임의 엔딩은 모두 **2막 종료 기준**이다. 해금 시점은 **엔딩(2막 종료) 시점의 소속 기준**이다. 이직으로 심볼을 한 판에 모으지 못하게 한다.
- 개인 심볼은 엔딩 때 들고 있던 심볼이, 사무소 심볼은 엔딩 때 소속 사무소가 해금된다.
- 하드 완주 조건 여부는 미정(앞서는 하드 한정으로 말했다).

## 능력치
- **진행 중 능력치**(그 판에서 들고 있는 단계에 따라)와 **해금 능력치**(다음 캐릭터 시작 보정)는 별개로 지급한다.
- 어려운 단계일수록 많이 준다. 사기 조합이 나와도 의도로 받아들인다. 제안 배율: 1단계 ×1, 2단계 ×2, 3단계 ×4.
- 심볼마다 능력치 한 가지: 사무소=최대 HP, 중지=최대 HP, 엄지=공격, 검지=사건 판정, (약지=회피, 소지=속도 제안), 특색은 모든 색 같은 값.
- 해금된 능력치 중 최대 3개를 새 캐릭터 시작에 더한다. 같은 심볼 중복은 불가(제안).
- 오늘의 시드·공유 시드에서는 해금 능력치를 끈다(제안, 미확인).

## 외형
- 이름 앞 모양 슬롯 1개(꾸미기). 기본 모양은 처음부터 열리고, 테두리는 기록으로 해금(테섭은 전부 열림).
- 전투 카드에서 심볼은 32px, 선택 버튼 안은 24px.
