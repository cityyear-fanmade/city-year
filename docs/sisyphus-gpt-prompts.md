# 시지프 백화점 이미지 · GPT용 프롬프트 (2026-11-14)

용도: 재단대(옷 제작)와 구역 선택 화면에 쓸 이미지. 규격과 목록은 `docs/sisyphus-art-brief.md`. 옷 자체(형태·무늬·색)는 게임이 SVG로 그리므로 **필수가 아닌 것**은 맨 끝에 따로 적었다.

## 0. 먼저 한 번만 붙이는 공통 지시 (대화 맨 처음에 붙여 넣기)

```
앞으로 요청할 이미지는 모두 아래 규칙을 지켜 줘.
- 그림체: 모바일 게임의 2D 캐릭터·아이템 일러스트 정도의 단순한 그림체. 면은 평평하게 칠하고, 그림자는 한 단계만(셀 셰이딩). 반짝이는 광택, 사실적인 질감, 과하게 고급스럽거나 화려한 효과, 렌즈 플레어, 먼지·불꽃 같은 흩뿌린 장식은 쓰지 마.
- 선: 어두운 검정에 가까운 굵은 외곽선. 선 굵기는 어느 그림에서나 같게.
- 색: 어두운 금속·가죽 느낌의 차분한 톤. 은회색 본체 + 포인트 색 한 곳만. 포인트 색은 요청마다 지정해 줄게.
- 배경: 단색 초록(#00FF00). 그림자, 그라데이션, 바닥선, 워터마크 없음. 그림 안에는 초록 계열을 쓰지 마.
- 구도: 한 장에 물건 하나, 정중앙, 정면에서 본 모습, 여백은 사방 10%.
- 금지: 글자(한글·영문·숫자), 사람 얼굴, 로고, 서명.
- 크기: 정사각형 1:1, 1024×1024로 만들어 줘.
- 같은 세트의 그림은 선 굵기, 명암 단계, 채도가 같아야 해.
이해했으면 "알겠어"라고만 답해.
```

## 5. 선택(필수 아님): 옷 5

게임이 옷을 SVG로 그리므로 없어도 된다. 구역과 재료가 먼저고, 시간이 남으면 의복 아이콘으로 쓴다. 옷은 색을 **은회색(무채색)** 으로 그려 달라고 해야 게임에서 색을 입힐 수 있다.

- `sis_cl_daily · 셔츠`: `단순한 셔츠 하나, 장식 최소. 무채색.`
- `sis_cl_suit · 정장 재킷`: `각진 어깨의 재킷, 단추 두 개. 무채색.`
- `sis_cl_coat · 외투`: `긴 외투, 큰 깃, 가죽 이음새, 옷깃에 날카로운 장식. 무채색.`
- `sis_cl_gala · 드레스`: `폭이 넓은 드레스, 주름이 많음. 무채색.`
- `sis_cl_gold · 황금가죽 의복`: `긴 수의 같은 천옷. 금색 포인트를 눈에 띄게.`

## 6. 받은 뒤 처리
- 파일 이름은 위 id로 저장(`sis_m_thread.png` 등). 초록 배경 그대로 전달하면 투명 배경으로 바꿔서 96~128px로 줄여 넣는다.
- GPT가 글자나 얼굴을 넣거나 선이 얇게 나오면 같은 대화에서 "글자 없이, 외곽선을 더 굵게"라고 다시 요청한다.
- 세트의 선 굵기와 톤이 서로 다르면 첫 그림을 기준 이미지로 올려 "이 그림과 같은 톤으로"라고 요청한다.
