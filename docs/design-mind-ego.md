# 정신력 · 뒤틀림 · E.G.O 개화 설계 (초안, 미적용)

2026-10-12 사용자 요청 기준. ★ 표시는 사용자가 정한 값, ☆ 표시는 Claude 추천안(확인 필요).

## 1. 정신력
| 항목 | 값 |
|---|---|
| 기본 정신력 | ★ 45 (최대치도 45) |
| 0이 되면 | ★ 사망 (사망 원인: 정신 붕괴) |
| 정신력이 떨어지는 선택지 | ★ 2d3 감소 |
| 환상체와 마주침 (환상체 전투 시작) | ★ 감소. ☆ 2d3 |
| 회피 실패 (적 공격에 맞음) | ★ 감소. ☆ 1 (2d3이면 전투 한 번에 바닥남) |
| 회복 | ☆ 해마다 +3, 휴식·치료 사건 선택지로 +2d3 |
| 표시 | ☆ HP 바 아래 정신력 바 (10 이하 빨간색) |

## 2. 들리는 목소리 (10 이하)
- ★ 정신력이 10 이하가 되면 "들리는 목소리" 선택지가 나온다.
- ★ 1d50을 3번 굴려 3번 모두 25 이상이면 E.G.O 개화. (확률 약 14%)
- ☆ 실패하면 **뒤틀림**: 그 판은 뒤틀림 엔딩으로 끝난다 (사망 엔딩과 다른 전용 문구·카드 이미지).
- ☆ 선택지는 두 개: "목소리에 답한다"(굴림) / "귀를 막는다"(굴리지 않음, 정신력 그대로. 다음에 또 떨어지면 다시 묻는다).
- ☆ 판정 보정(판정 능력치)은 이 굴림에 더하지 않는다. 운에 맡기는 순간으로 둔다.

## 3. E.G.O 개화
- ★ 공격용 / 방어용 중 고른다. ★ 이름은 1~5글자 직접 입력.
- 개화하면 패시브로 붙는다 (장비 칸 차지 없음, 인벤토리 유물 탭에 표시).

| 종류 | 효과 |
|---|---|
| 공격용 | ★ 공격 판정(명중) +10, ★ 정신력이 20 미만으로 떨어지지 않음 |
| 방어용 | ★ 최대 체력 +30, ★ 정신력이 11 미만으로 떨어지지 않음 |

- ☆ 개화는 한 판에 한 번. 개화 뒤에는 "들리는 목소리"가 다시 나오지 않는다.
- ☆ 개화하는 순간 정신력은 하한값까지 회복 (공격용 20, 방어용 11).

## 4. 환상체 보스 2종 (전투 후 E.G.O 장비)
- ★ 로보토미·라오루 환상체 중 중반급·후반급 1마리씩.
- 이름만 원작에서 가져오고, 소개 문구·카드·기믹은 새로 쓴다. 원작 대사·설명문은 옮기지 않는다.
- ☆ 후보 (사용자가 고름. 한국어 공식 명칭은 확인 필요)
  - 중반급: 마탄의 사수 / 징벌새 / 지혜를 찾는 허수아비
  - 후반급: 큰 새 / 아무것도 없다(Nothing There) / 침묵의 오케스트라
- ☆ 등장: 조우 표에 낮은 확률(피아니스트처럼 once), 마주치면 정신력 2d3 감소.

### E.G.O 장비 (패시브 아이템, ★ 개화 효과의 절반)
| 종류 | 효과 |
|---|---|
| 공격형 장비 | 명중 +5, ☆ 정신력 하한 10 |
| 방어형 장비 | 최대 체력 +15, ☆ 정신력 하한 5 |
- ☆ 중반급 보스 → 공격형, 후반급 보스 → 방어형 (또는 처치 시 선택).
- ☆ 개화와 장비가 겹치면 효과는 더하고, 하한은 높은 쪽을 쓴다.

## 5. 밸런스 확인 계획 (적용할 때)
- 시뮬에 정신력을 넣고 55년 완주율이 지금(약 78%)에서 크게 떨어지지 않는지 본다.
- 정신 붕괴 사망, 뒤틀림 엔딩, 개화 비율을 따로 센다.
