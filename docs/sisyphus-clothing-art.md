# 시지프 옷 외형·재료 다양성 정리 (2026-11-17, 확인 대기)

옷 외형 이미지는 GPT로 만든다(사용자). 이 문서는 **(1) 재료를 다양하게 늘리는 안**과 **(2) GPT에게 시킬 옷 외형 제작 체계**를 정리한다. 이미지 규격과 공통 지시는 `docs/sisyphus-art-brief.md`·`docs/sisyphus-gpt-prompts.md`를 기준으로 하고, 여기서는 **바뀌거나 늘어난 것**만 적는다.

## 1. 재료 다양성 (제안)
지금 재료는 가죽·실·원단·황금가죽·염료·장식 부품·정육 소다·황금송진 8종뿐이라, 옷을 만들 때 고를 것이 적다. **분류는 그대로 두고 분류 안에 단계(등급)를 둬서** 늘린다. 형태(셔츠·정장…)는 "원단 계열이면 아무 원단이나 가능"으로 두고, **고른 재료의 단계가 값과 손질 확률에 영향**을 준다.

| 분류 | 재료(단계 낮음 → 높음) | 얻는 곳 | 효과 |
|---|---|---|---|
| 원단 | 무명 → 모직 → 비단 | 마네킹(1층·지하 1층 = 무명, 지하 3층 = 모직), 4층 이후 비단 | 값 ×1 / ×1.4 / ×2 |
| 가죽 | 가죽 조각 → 무두질 가죽 → 황금가죽 | 장갑·지갑(조각), 지하 3층(무두질), 5층(황금가죽) | 손질 보너스 14 / 16 / 20 |
| 실 | 무명실 → 은실 → 황금실 | 방적장 이후 | 손질 보너스 8 / 10 / 12 |
| 장식 | 단추·브로치 / 손톱·이빨 / 눈알 구슬 / 부품 | 매장·푸드코트·손님·4층 | 장식마다 다른 성향 값(지금 구현) |
| 염료 | 8색(회색~금색) | 지하 2층, 거래 | 색이 열리는 등급은 지금과 같음 |
| 특수 | 황금송진, 정육 소다 | 벽 뜯기, 푸드코트 | 수의형 의복 재료 / 체력 회복 |

- 재료 종류는 **15종 전후**(원단 3 + 가죽 3 + 실 3 + 장식 4 + 특수 2 + 염료 병 1)이다. 아이콘도 이 수만큼 필요하다.
- 효과는 가볍게 두고, "무엇을 들고 나갈지"를 고르는 재미를 늘리는 것이 목적이다. 높은 단계 재료일수록 구하기 어렵고(구역 해금, 낮은 드랍 확률) 옷값과 등급 점수가 오른다.
- 구현은 지금의 `ch.sis.mat`(분류별 수량)에 단계 이름을 키로 더하는 방식(`cloth_wool`처럼)이고, 형태가 요구하는 분류를 "같은 분류의 아무 단계"로 확장한다.

## 2. 옷 외형: GPT 제작 체계
### 2-1. 결론: 조합 방식으로 만든다
형태 5종 × 무늬 6종 × 색 8종 × 장식 4종을 전부 그릴 수 없으므로, **층(레이어)을 쌓는다.** 이미 있는 SVG 방식(`sisSvg`)을 이미지 레이어로 바꾸는 것이다.

| 층 | 만드는 이미지 | 게임이 하는 일 |
|---|---|---|
| ① 몸체 실루엣 | 형태마다 **무채색 한 장**(6장) | 선택한 색으로 칠한다(곱하기 + 밝기 보정) |
| ② 무늬 | 줄무늬·띠·격자·물방울·박음선의 **반복되는 무늬 5장**(민무늬는 없음) | 몸체 모양 안에 겹친다 |
| ③ 장식 | 단추·손톱·이빨·눈알·부품 **작은 스프라이트 4장** | 정해진 위치(옷깃·가슴·소매·밑단 중 하나)에 올린다 |
| ④ 마네킹 | **상체 마네킹 한 장**(동숲식 흉상, 머리·팔 없음) | 아래 층으로 깐다. 옷 몸체도 상체 기준으로 그린다(소매는 어깨 아래까지만) |

### 2-2. 이미지 목록 (새로 필요한 것 / 바뀐 것)
| 우선순위 | id | 내용 | 규격 |
|---|---|---|---|
| P0 | `sis_cl_daily` `suit` `coat` `gala` `gold` | 5종 몸체(기존 목록과 같음, **옷만 무채색, 마네킹 없이**) | 512×512, 은회색, 초록 배경 |
| P0 | `sis_cl_shroud` | 수의형 의복(붉은 신에게 입히는 옷) 몸체 | 같음 |
| P0 | `sis_mannequin` | **상체 마네킹**(동물의 숲 가게의 마네킹처럼 목 아래부터 어깨·가슴·허리까지만 있는 흉상, 머리·팔 없음, 가는 받침대 위) — 옷은 이 상체에 입힌다(2026-11-17 사용자) | 같음 |
| P1 | `sis_pt_stripe` `band` `check` `dots` `stitch` | 무늬 **반복 이미지**(위아래·좌우로 이어짐), 무채색 | 256×256 |
| P1 | `sis_tr_button` `tooth` `eye` `buckle` | 장식 스프라이트 | 128×128 |
| P2 | `sis_m_*` 재료 아이콘 15종 | 1절 목록 | 256×256 |
| P3 | `sis_z_*` 구역 6장, `sis_bench` | 기존 목록 | 기존 |
- 합계: P0 7장 + P1 9장 + P2 15장 + P3 7장 = **38장**. P0만 있어도 옷 모양은 완성되고, 무늬·장식은 글자 칩이나 SVG로 대신 동작한다.

### 2-3. GPT에게 시키는 방법 (일관성)
1. 대화 맨 처음에 `docs/sisyphus-gpt-prompts.md`의 공통 지시 블록을 한 번 붙인다.
2. **첫 이미지(`sis_cl_daily`)가 나오면 마음에 드는 것을 "기준 그림"으로 올리고**, 이후 모든 요청에 "이 그림과 같은 선 굵기·명암·채도로"를 붙인다. 같은 대화에서 이어서 시킨다(대화가 길어지면 기준 그림을 다시 올린다).
3. 옷은 **정면, 팔을 내린 자세, 마네킹 없이 옷만**, 대칭으로 요청한다(층 쌓기가 쉬워진다).
4. 무늬는 "무늬가 상하좌우로 이어지는 반복 패턴, 옷 모양 없음, 무채색"으로 요청한다.
5. 장식은 "한 개 물건, 정면, 작게"로 요청한다.
6. 결과가 초록 배경에 섞이면 같은 대화에서 "배경은 단색 초록, 초록 계열을 그림에 쓰지 마"를 다시 요청한다.
- 프롬프트 초안(옷 몸체 템플릿): `{형태 설명}을 정면에서 본 무채색 옷 한 벌. 팔은 내리고 마네킹 없이 옷만. 어깨선이 좌우 대칭. 굵고 일정한 검은 외곽선, 면은 은회색 두 단계 명암(셀 셰이딩). 배경 단색 초록(#00FF00). 글자·얼굴 금지.`

### 2-4. 받은 뒤 처리 (제가 하는 일)
- 초록 배경을 투명으로 바꾸고(크로마키), 크기를 줄이고(몸체 160px, 무늬 128px, 장식 64px), 파일 용량을 줄여(PNG 양자화) `assets/sis/`에 둔다. 단일 파일 빌드에는 data URI로 넣는다.
- 게임에서는 몸체를 색으로 칠하고 무늬를 겹치고 장식을 올린다. 이미지가 하나라도 없으면 그 층은 기존 SVG로 그린다.
- 총량이 크므로 용량 점검이 필요하다(38장 × 평균 15KB 안팎 = 약 0.6MB 목표).

## 3. 확인이 필요한 것
1. 재료 다양성: 위 분류(원단·가죽·실 3단계 + 장식 4 + 특수 2)와 **15종 전후**가 적당한지. 더 늘릴지 줄일지.
2. 재료 단계가 옷값에만 영향을 줄지, 등급 점수에도 영향을 줄지.
3. 옷 외형을 **층 쌓기 방식**(몸체 + 무늬 + 장식)으로 만들어도 되는지. 아니면 형태마다 완성 그림 몇 장을 만드는 방식을 원하는지.
4. 제작 순서: P0(몸체 7장)을 먼저 시키고 모양을 본 뒤 P1·P2로 가도 되는지.

## 4. 재료 수급처·등급 밸런스 (2026-11-17, 제안 · GPT 작업 전에 확정)
GPT에게 재료 아이콘을 시키기 전에 **무엇을 어디서 얼마나 얻는지**를 먼저 정한다. 아이콘 수와 구역별 보상이 이 표로 정해진다.

### 4-1. 원칙
- 사냥 1번(하루)에 **재료 1개**(가끔 2개)와 안을 얻는다. 옷 한 벌에 필요한 재료는 형태마다 1~2개이므로, 하루 사냥 → 하루 제작/판매의 이틀 사이클에서 **한 벌씩 지을 만큼** 나오게 맞춘다.
- 낮은 구역에서는 기본 재료(무명·가죽 조각)가 안정적으로 나오고, 높은 구역은 **새 재료가 나오되 확률이 낮다**(수집 목표). 높은 단계 재료는 옷값을 올리지만 필수는 아니다.
- 구역 해금은 지금처럼 고객 등급이 정한다(토파즈 0 · 에메랄드 10 · 금 28 · 루비 55 · 다이아몬드 90점).

### 4-2. 수급표
| 구역 | 해금 | 적 → 재료(드랍 비율) |
|---|---|---|
| 1층 매장 | 토파즈 | 가죽 장갑·지갑 → 가죽 조각 100% · 마네킹 → 무명 70% / 가죽 조각 30% · 단추·브로치 15%(추가) |
| 지하 1층 푸드코트 | 토파즈 | 수셰프 → 정육 소다 50% / 가죽 조각 50% · 마네킹 → 무명 70% / 가죽 조각 30% · 손톱·이빨 15%(추가) |
| 지하 2층 방적장·염색실 | 에메랄드 | 바늘이 → 무명실 60% / 염료 40% · 바느질의 왕(보스) → 은실 60% / 모직 40% |
| 지하 3층 가죽실·수선실 | 금 | 마네킹 → 모직 60% / 가죽 조각 40% · 통제자 → 무두질 가죽 60% / 눈알 구슬 15%(추가) / 모직 25% |
| 4층 가구관·신발관 | 루비 | 가구들 → 비단 40% / 장식 부품 40% / 은실 20% · 원레그·도로테아 → 장식 부품 60% / 비단 40% |
| 5~6층 | 다이아몬드 | 고객들·추락한 마네킹 → 비단 40% / 황금실 30% / 눈알 구슬 30% · 간수(보스) → 황금가죽 70% / 황금실 30% |
| 벽 뜯기(첫 재고 정리 후) | — | 황금송진 100% |

- 각 사냥에서 위 비율로 1개를 고르고, 15%로 "추가" 재료를 하나 더 얻는다.
- 장식 부품은 지금처럼 장식 한 칸에 하나씩 든다.

### 4-3. 단계 효과 (옷값·손질)
| 분류 | 낮음 | 중간 | 높음 |
|---|---|---|---|
| 원단 | 무명 ×1 | 모직 ×1.4 | 비단 ×2 |
| 가죽 | 가죽 조각 (손질 +14) | 무두질 가죽 (손질 +16) | 황금가죽 (손질 +20) |
| 실 | 무명실 (손질 +8) | 은실 (+10) | 황금실 (+12) |
- 옷 가격은 쓴 원단·가죽 단계의 곱을 따른다(예: 비단 정장은 정장 값 × 2). 고객 점수는 옷의 품질 단계가 정하고 재료 단계는 값만 바꾼다(점수 상승 속도는 지금과 같다).
- 형태가 요구하는 재료 수: 셔츠 원단 1, 정장 원단 2, 외투 가죽 2, 드레스 원단 2 + 실 1, 황금가죽 의복 황금가죽 3 + 황금실 1, 수의형 황금송진 2 + 황금가죽 1.

### 4-4. 검증 계획
- 자동 시뮬로 소속 3종 각 50판을 돌려 **등급 도달 시기(턴)**, **재료별 획득 횟수**, **재료가 남거나 부족한 구간**을 표로 뽑는다. 다이아몬드(5층)에 턴 35~45 사이에 닿는 것이 목표이고, 4층 이후 새 재료를 한 번도 못 얻는 판이 20%를 넘지 않게 맞춘다.
- 확정되면 이 표 그대로 데이터에 넣고, 아이콘 목록(15종)을 확정해 GPT 프롬프트를 만든다.

### 4-5. 확인이 필요한 것
1. 구역별 재료 배치와 비율이 괜찮은지(특히 비단·황금실을 4층 이후로 묶는 것).
2. 옷 값의 재료 단계 배수(×1 / ×1.4 / ×2)가 적당한지.
3. 15%로 추가 재료(장식)를 주는 것.
4. 상체 마네킹 방향(위 표) 확인.

## 5. 구현 결과 (2026-11-17, 권장안 그대로 반영)
- 재료: 원단(무명·모직·비단), 가죽(가죽 조각·무두질 가죽·황금가죽), 실(무명실·은실·황금실), 장식 부품, 염료, 정육 소다, 황금송진. 높은 단계부터 먼저 쓰고, 옷값은 쓴 원단의 평균 배수(×1 / ×1.4 / ×2)를 따른다.
- 형태 필요량: 셔츠 원단 1, 정장 원단 2, 외투 가죽 2, 드레스 원단 2 + 실 1, 황금가죽 의복 황금가죽 3 + 황금실 1.
- 수급: 적마다 드랍 표를 가진다(위 4-2). 마네킹은 1층·지하 1층에서 흔하게 나오도록 구역 적 목록에 여러 번 넣었다.
- 등급 기준 점수를 8 / 24 / 48 / 80으로 낮췄다(전 10 / 28 / 55 / 90).
- 시뮬(소속 3종 × 12판, 자동 플레이): 다이아몬드 도달 턴 36~44 (목표 35~45), 36판 모두 도달.
