# 도시의 한 해 · 규칙과 밸런스 설명서

> 자동 생성 문서 (`npm run guide`). 수치는 `src/config.js`와 `data/*.json` 기준이고, 승률은 시뮬 3000회(시드 1)와 무작위 진행 6,000판 결과다. 모든 수치는 임시값이다.

## 1. 한 판의 흐름

1. **출생**: 이름을 정하고, 출신·재능·결점·무기·색을 각각 1d100으로 굴린다. 태어날 때마다 새 시드가 뽑힌다.
2. **성장기**: 5세·9세·13세·16세에 성장기 표를 1d100으로 굴려 능력치가 하나씩 오른다.
3. **17~71세 (55년)**: 해마다 사건 하나. 3·6·7년차는 고정 전투. 4년차에는 소속을 정하는 갈림길.
4. 전투에서 이기면 회복·보상 카드·경험치·현상금을 받고, 레벨이 오르면 성장표를 1d100으로 세 번 굴려 하나를 고른다.
5. 55년을 버티면 완주. 전투에서 HP가 0이 되면 끝.

## 2. 능력치

| 능력치 | 기본값 | 쓰이는 곳 |
|---|---|---|
| HP | 60 | 0이 되면 끝. 해마다 +9, 전투 승리 후 +11 회복 |
| 공격 | 0 | 명중 굴림에 더한다 |
| 회피 | 0 | 상대의 명중 굴림을 막는 굴림에 더한다 |
| 속도 | 0 | 라운드 순서 굴림에 더한다 |
| 사건 판정 | 0 | 모든 사건 판정에 더한다 |
| 시작 출혈 / 시작 호흡 | 0 | 전투 시작 때 자신에게 붙는 스택 |
| 피해 최소값 | 1 | 피해 d6가 이 값보다 작게 나오면 이 값으로 (무기·장비) |
| 방어 카드 보너스 | 0 | 방어 카드의 회피 보너스에 더한다 |
| 2회 굴림 | 0 | 라운드 첫 공격의 명중을 1d100 두 번 굴려 높은 값 |
| 적 HP 보정 | 0 | 모든 적의 HP에 더한다 (결점 "추적자") |

## 3. 주사위 규칙

| 판정 | 식 | 비고 |
|---|---|---|
| 사건 판정 | 1d100 + 능력치 + 사건 판정 보정 (+ 출신 진로 보정) ≥ 난이도 | 능력치가 없는 "운 판정"은 보정만 더한다 |
| 라운드 순서 | 1d100 + 속도 (+10 추격 보정) | 높은 쪽이 선공·빛 +1. 30 이상 앞서면 선제: 첫 공격 명중 +10. 진 쪽은 다음 라운드 추격 +10. 동점이면 둘 다 보너스 없음 |
| 명중 | 1d100 + 공격 + 카드 명중 보정 > 상대 1d100 + 회피 (+ 방어 카드) | 동점은 방어 쪽 승리 |
| 피해 | 카드의 d6 개수만큼 굴려 합 + 카드 고정값 | 코스트가 높을수록 주사위가 많다 |
| 치명 | 호흡 스택 × 5% 확률로 피해 ×1.5 (소수점 버림) | 명중할 때마다 호흡 1 소모 |
| 방어 자세 | 카드를 하나도 내지 않은 라운드: 회피 대신 방어로 같은 굴림 | 출혈 스택 ×0.5(내림, 플레이어만). 막으면 피해 1, 못 막으면 피해 ×0.5(소수점 버림). 다음 라운드 명중 +5, 다음 라운드 빛 +2 |

**빛(코스트)**: 라운드마다 3, 선공이면 +1, 최대 5. 남은 빛은 사라진다. 손패는 덱에서 4장. 고른 순서대로 발동한다.

**발동 순서**: 방어 카드가 먼저(순서대로) 적용되고, 그다음 공격·버프 카드를 선공부터 한 장씩 번갈아 낸다. 적은 라운드 시작 때 낼 카드를 정하고 화면에 공개한다.

**예시**: 공격 +2인 내가 찌르기(명중 +10)로 회피 +3인 적을 친다. 내 1d100이 40이면 40+2+10=52, 적 1d100이 45면 45+3=48. 52 > 48이라 명중, 1d6이 4면 피해 4. 적에게 파열 2가 있으면 피해 +2로 6, 파열은 1로 줄어든다.

**알려진 점**
- 방어 자세: 지금 설정(전투 동안 빛 +0)이면 첫 라운드에 방어 자세를 하는 운영이 보스 승률을 약 12%p 올린다. 상황 선택지로 만들려면 `CFG.guard`를 `lightUp: 0, lightNext: 2`(다음 라운드만 빛 +2)로 바꾸면 안 넘길 때와 비슷해진다.

- 날개 소속은 아직 승진이 없다.
