시지프 백화점 배경 이미지 프롬프트 (2026-11-18)

목적: 지금 CSS 테마가 "색만 바뀐" 느낌이라, 장소 느낌이 나는 그림을 넣는다.
옷 그림과 같은 그림체로 간다(굵은 검정 외곽선, 평평한 면, 한 단계 그림자). 단, 배경이라 글자가 올라가므로 **어둡고 대비가 낮게** 그린다.
먼저 옷 그림 한 장(예: sis_w_suit.png)을 대화에 올려 그림체 기준으로 삼는다. 한 번에 한 장씩.

[공통 지시] 맨 처음 한 번만 붙인다
```
올린 옷 그림과 같은 그림체로 그릴 거야(굵은 검정 외곽선, 평평한 면, 한 단계 그림자). 배경 일러스트라서 전체를 어둡게 하고 대비는 낮게, 채도도 낮게 해 줘. 사람 얼굴·글자(한글·영문·숫자)·로고·서명 없음. 그림 안에 밝은 광원은 작은 조명 몇 개만. 알겠으면 "알겠어"만.
```

A. 상단 간판 3종 (파일: sis_bg_sign_rouge / noir / kaki)
- 크기 1536×384, 가로로 긴 띠.
```
어두운 백화점 매장 입구 위의 간판 띠. 가운데가 비어 있고(글자가 들어갈 자리, 글자는 그리지 마), 양옆에 진열창 조명과 작은 마네킹 실루엣이 대칭으로 있다. 전체 색은 {소속 색}을 중심으로 한 어두운 단색 계열.
```
- {소속 색}: rouge = 짙은 붉은 적갈색 / noir = 검은색과 은회색 / kaki = 어두운 금색과 갈색

B. 배경 타일 3종 (파일: sis_bg_tile_rouge / noir / kaki)
- 크기 512×512, **이어 붙여도 이음새가 보이지 않게**(상하좌우 반복).
```
백화점 매장 바닥과 진열대가 위에서 내려다보이는 듯한 반복 무늬. 진열대와 옷걸이 줄, 바닥 타일 선이 흐리게 보인다. 전체 어둡고 대비가 매우 낮다. 주 색은 {소속 색}. 가운데에 시선을 끄는 물체는 두지 마.
```

C. 구역 일러스트 6종 (선택, 파일: sis_zone_f1 / b1 / b2 / b3 / f4 / hall)
- 크기 1536×512. 구역을 고르는 화면의 머리 그림.
```
{구역 설명}을 옆에서 본 모습. 안쪽으로 깊어지는 통로, 작은 조명, 어두운 분위기. 사람은 그리지 마.
```
- 구역 설명: f1 = 1층 매장(옷걸이와 진열대) / b1 = 지하 1층 푸드코트(철제 조리대와 줄지은 의자) / b2 = 지하 2층 방적장과 염색실(천이 걸린 줄, 염색통) / b3 = 지하 3층 가죽실과 수선실(마네킹들, 재봉틀) / f4 = 4층 가구관과 신발관(소파와 신발 진열대) / hall = 에스컬레이터 홀(끝없이 이어진 에스컬레이터)

받은 뒤
- 파일 이름을 위처럼 저장해서 초록 배경 없이 그대로 보내 주면 된다(배경 그림이라 투명 처리는 필요 없다).
- 제가 크기를 줄이고 소속별 테마에 연결한다. 글자(층 이름 등)는 게임이 위에 쓴다.
- 우선순위: A(간판 3장) → B(타일 3장) → C(구역 6장).

대안(그림 없이)
CSS를 더 진하게 하는 방법도 있다: 진열창 조명, 소속별 간판 띠, 마네킹 실루엣을 CSS 그림으로 넣는다. 그림 작업 없이 바로 가능하지만 GPT 그림만큼 풍부하지는 않다.
