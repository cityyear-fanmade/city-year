# 튜토리얼 v2 설계 · 안내자가 보여 주는 가상 플레이

> 상태: 설계안 (구현 전). 이전의 6장 "처음 안내"(미커밋, 보류)는 이 설계로 대체한다.
> 정체성: **안내자와 함께 보는 게임 사용 설명서.** 실제 게임을 시작하기 전에 짧은 연극처럼 한 판의 흐름을 보여 준다.

## 1. 원칙
- 실제 게임 상태를 바꾸지 않는다. 시연 선택·결과는 기록실·세이브·통계에 저장하지 않는다.
- 가상 화면은 실제 UI(카드, 칩, 선택지 버튼)와 같은 모양을 써서 익숙하게 한다.
- 시연 숫자는 실제 규칙과 일치시킨다. 값은 `CFG`에서 읽고, 계산이 필요한 예는 식을 코드에서 풀어 화면에 쓴다.
- 안내자 디자인은 고정한다(에셋 12종). 새 표정이 필요하면 사용자에게 요청한다.
- 조작은 **이전 · 다음 · 건너뛰기**. 상세 규칙은 기존 도움말(카드 읽는 법 · 키워드 · 규칙)로 연결한다.
- 시연용 인물·사건은 전부 가상이다(실제 이름·원작 문장 없음).
- 한국어 먼저, 일본어는 한국어 확정 뒤.

## 2. 화면 구성
```
┌ 안내자가 보여 주는 가상 플레이 ──────────┐
│ ┌ 가상의 게임 화면 ───────────── [시연 중] ┐ │
│ │  (실제 UI 모양의 사건·카드·전투 화면)   │ │
│ └────────────────────────────────────┘ │
│ [안내자 스프라이트]  ┌ 말풍선(설명 1~3문장) ┐ │
│ ※ 실제 게임 데이터와 무관한 예시 화면      │
│ 시연 진행 n / 7        [이전] [다음] [건너뛰기]│
└──────────────────────────────────────┘
```
- 위쪽: **가상 화면**(시연 중 배지). 단계마다 내용이 바뀌고, 간단한 CSS 연출(선택지 강조, 주사위 굴림, 카드 나가기)을 쓴다.
- 아래쪽: 안내자 스프라이트(약 100px)와 말풍선. 스프라이트는 단계별 용도 표정으로 바뀐다.
- 건너뛰기를 눌러도 시작 화면으로 돌아가고 아무것도 저장하지 않는다(다시 보지 않는 표시 `cityYearTutSeen`만 저장).

## 4. 진행 순서 (7단계, 단계마다 슬라이드 2~7장 · 슬라이드 수는 늘어도 된다)
안내자 이름은 **앤젤라**, 시연 인물은 **아인**(출신: L사 둥지 노동자)으로 통일한다. 아인은 실제 판의 캐릭터가 아니라 시연용 가상 인물이다.

| 단계 | 제목 | 가상 화면 | 안내자 표정 | 짚는 규칙 |
|---|---|---|---|---|
| 1 | 안내자 첫인사 | 시작 화면 윤곽 + 「새로 태어난다」 버튼 | 01 기본 → 09 안내 | 주사위로 사람을 만들고 일생을 한 해씩 산다. 대부분은 글을 읽고 고르는 게임, 칼을 뽑을 때만 카드 |
| 2 | 출생과 성장 | 출생 결과 표(출신·재능·결점·무기), 성장기 표 | 03 가리키기 → 04 기쁨 | 1d100으로 정한다. 마음에 안 들면 다시 굴린다. 성장기에 능력치가 오른다 |
| 3 | 사건과 선택 | 「17세 — 첫 번째 사건」 + 선택지 ①②③, 고른 뒤 결과 문장 | 05 고민 → 01 기본 | 해마다 사건 하나. 선택에 따라 결과가 달라진다 |
| 4 | 주사위 판정 | 1d100 굴림 연출 + 식 풀이 (성공 예 / 실패 예) | 07 주사위 → 04 기쁨 / 11 걱정 | 사건 판정 = 1d100 + 능력치 ≥ 난이도 |
| 5 | 카드와 전투 | 손패 4장 → 빛 → 순서 굴림 → 명중 굴림 → 피해 → 회피·방어 → 라운드 끝 (슬라이드 7장 안팎, 기존 전투 연출 재사용) | 08 카드 → 03 가리키기 → 07 주사위 → 06 놀람 → 11 걱정 | 빛(코스트), 순서(속도×2), 명중(공격 + 카드 보정), 피해, 회피·방어 |
| 6 | 성장과 보상 | 승리 보상 카드, 레벨 업 성장표 | 04 기쁨 → 10 생각 | 이기면 회복·보상 카드·경험치. 덱 크기 제한 |
| 7 | 기록실과 마무리 | 기록실 탭 윤곽(만난 적·엔딩·해금) + 「태어난다」 | 02 독서 → 12 마무리 | 완주와 기록, 해금. 막히면 ? 버튼·난이도 쉬움 |

## 5. 단계별 시연 스크립트 초안 (말풍선 문구)
문구는 한국어 초안이고 짧게 쓴다(말풍선 3문장 이내, "~다" 체).

**1. 첫인사**
1. (01) "처음이라면 잠깐 내 화면을 같이 보자. 실제 게임은 아니고, 어떻게 흘러가는지 보여 주는 시연이다."
2. (09) "이 게임은 주사위로 사람 하나를 만들고, 그 사람의 일생을 한 해씩 넘겨 살아 보는 게임이다. 시연은 7단계, 건너뛰어도 된다."

**2. 출생과 성장**
1. (03) "태어날 때 출신, 재능, 결점, 무기를 1d100으로 굴려 정한다. 마음에 들지 않으면 다시 굴릴 수 있다."
2. (04) "다섯 살, 아홉 살처럼 몇 번의 성장기를 지나며 능력치가 조금씩 오른다."

**3. 사건과 선택** (가상 사건: "길거리에서 수상한 의뢰를 받았다" — 스크린샷 시안 그대로)
1. (05) "해마다 사건이 하나 찾아온다. 아래 선택지 중에서 하나를 고른다."
2. (01) "①을 고르면 의뢰를 받아들이는 결과가, ②를 고르면 거절하는 결과가 나온다. 이렇게 선택에 따라 이야기가 달라진다."

**4. 주사위 판정**
1. (07) "사건에서 모험을 하면 판정이 나온다. 1d100을 굴려 내 능력치를 더하고, 난이도 이상이면 성공이다."
2. 성공 예: 난이도 60, 능력치 +10, 주사위 52 → 62 ≥ 60 성공. (04)
3. 실패 예: 같은 난이도, 주사위 41 → 51 < 60 실패. (11) "실패하면 체력을 잃거나 기회를 놓칠 수 있다."

**5. 카드와 전투** (아인의 시연 전투: 아인 공격 +2 · 속도 3, 적 회피 +3 · 속도 1. 모든 굴림 값은 미리 정해 둔 것)
1. (08) 손패: "전투의 모든 행동은 카드다. 라운드마다 덱에서 4장이 손패로 나온다. 덱이 좋으면 손패가 좋다." 가상 화면에 찌르기 등 카드 4장.
2. (03) 빛: "카드 왼쪽 숫자는 코스트, 빛이다. 라운드마다 빛은 3이고, 먼저 움직이면 +1, 최대 5. 카드를 내면 코스트만큼 줄고, 남은 빛은 사라진다."
3. (09) 순서: "누가 먼저 움직일지는 1d100 + 속도×2로 정한다. 아인 62 + 3×2 = 68, 적 55 + 1×2 = 57. 아인이 먼저 움직이고 빛 +1을 받는다." 가상 화면에 주사위 굴림(기존 `wob` 연출)과 두 값 비교.
4. (07) 명중 굴림: "카드를 내면 명중 굴림이 나온다. 1d100에 내 공격 능력치와 카드의 명중 보정을 더한다. 아인이 40을 굴렸다면 40 + 공격 2 + 찌르기 보정 10 = 52."
5. (07) 상대 굴림: "상대도 1d100에 자기 회피를 더한다. 적이 45를 굴렸다면 45 + 회피 3 = 48. 내 52가 48보다 크면 명중이다."
6. (06) 동점과 방어: "동점이면 방어 쪽이 이긴다. 카드를 하나도 안 내면 방어 자세가 되어 회피 대신 방어로 같은 굴림을 한다."
7. (04) 피해: "명중하면 카드의 주사위로 피해를 굴린다. 찌르기는 1d6, 눈이 4면 피해 4. 주사위 개수가 많은 카드일수록 코스트가 높다." 가상 화면에 적 HP 감소(`hurt`·`flt` 연출).
8. (11) 라운드 끝: "라운드가 끝나면 다시 4장을 받고 시작한다. 한쪽 HP가 0이 되면 전투가 끝난다. 굴림이 번거로우면 '자동 전투로 바꾸기'를 누르면 카드를 알아서 고른다."

**6. 성장과 보상**
1. (04) "전투에서 이기면 체력을 조금 회복하고 보상 카드와 경험치를 받는다."
2. (10) "덱에는 넣을 수 있는 장수가 정해져 있다. 카드가 늘어나도 좋은 카드로 덱을 짜는 게 중요하다."

**7. 기록실과 마무리**
1. (02) "55년을 버티면 완주, 중간에 HP가 0이 되면 끝난다. 끝나면 기록실에 만난 적과 엔딩이 남는다."
2. (12) "처음에는 이기려 하지 말고 한 판을 끝까지 살아 보자. 막히면 위쪽 ? 버튼에서 규칙을 다시 볼 수 있다."

## 6. 구현 계획
- 새 파일 `src/tutorial.js`(시연 스크립트와 화면 조립)를 두고, `ui.js`는 진입점과 렌더만 연결한다. 문구는 한국어 먼저, 이후 번역 파이프라인에 포함.
- **연출은 이미 쓰는 것을 그대로 보여 준다.** 주사위 굴림(`wob`), 공격 돌진(`lungeUp`/`lungeDown`), 피격(`hurt`), 회피(`dodge`), 방어(`guard`), 떠오르는 숫자(`flt`), 카드 등장(`settle`) 등 `css/style.css`의 기존 전투 연출을 시연 화면에서 호출한다. 새 연출 에셋은 만들지 않는다.
- 가상 화면은 실제 UI 클래스를 재사용하고, 튜토리얼 전용 상태(`UI.tutStep`)만 쓴다. `G`(실제 판)나 `E`의 상태·난수는 건드리지 않는다. 시연 굴림 값은 **미리 정해 둔 값**을 쓴다(난수 사용 안 함).
- 수치는 `CFG`에서 읽는다: 시작 나이 `startAge`, 55년 `years`, 빛 `light`/`lightMax`, 손패 `hand`, 속도 배수 `spdMul`.
- 진입점: 시작 화면의 작은 버튼과 도움말(?) 첫 탭. 첫 방문자는 버튼을 강조.
- 이미지: `assets/tutorial/*.webp`(240px 안팎, 12종, 합계 약 195KB). 단일 파일 빌드에도 함께 들어가므로 용량 확인이 필요하다.
- 기존 보류 코드(6장 "처음 안내")는 폐기하고, CSS는 쓸 수 있는 부분만 재활용한다.
- 검증: Playwright로 7단계 전부 넘겨 화면·오류 확인, 시연 중 `localStorage` 기록(`cityYearRecords` 등)이 변하지 않는지 확인.

## 7. 결정 사항과 남은 것
확정(2026-11-22):
- 안내자 이름: **앤젤라**. 시연 인물: **아인**, 출신 L사 둥지 노동자.
- 슬라이드 수는 늘어도 된다(전투의 속도·공격·명중 계산을 자세히 설명하기 위해).
- 연출은 기존 게임에서 쓰는 전투 연출을 그대로 보여 준다.
- 주사위 표정(07) 이미지는 새 그림으로 교체했다(배경 제거 후 `assets/tutorial/07_dice.webp`).

남은 것:
1. "L사 둥지 노동자"는 현재 게임 데이터에 없는 표기다(실제 둥지 노동자는 N사 둥지 출신으로 고정). 시연 화면에서 이 출신 표기를 어떻게 보일지(예: 출생 화면의 "출신 · 둥지 노동자" 칸 + 태어난 곳 L사) 확인이 필요하다.
2. 2단계의 가상 출생 결과 표(재능·결점·무기 예시) 내용.
3. 에셋 가장자리에 이웃 그림의 조각이 일부 남은 그림(3·9·10번 등) 정리.
4. 명중 보정, 선제(속도 30 이상 앞서면 첫 명중 +10) 같은 세부 규칙을 몇 장에 나눠 설명할지.
