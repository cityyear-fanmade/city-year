# 도시의 한 해 · 세계관 정리 (2026-10-11 개정)

게임에 쓰는 세계관을 한곳에 모은 설계 문서다. 근거는 세 갈래다.
- **원작 설정**: 사용자가 정리해 온 Project Moon 세계관 자료집 3종(나무위키 분류 기반 재구성본)과 이전에 모은 공개 위키 정리.
- **게임 오리지널**: 원작에 없는 이름·수치. 원작 설정과 섞이지 않게 따로 표시한다.
- **미확인**: 이름만 알고 내용은 모르는 것. 짐작으로 채우지 않는다.

원칙
1. 위키·자료집 문장은 옮기지 않는다. 이름·구조·관계만 쓰고 게임 문구는 새로 쓴다.
2. 원작 고유 인물(롤랑, 앤젤라, 수감자 등)과 대사는 쓰지 않는다. 플레이어는 이름 없는 도시 주민이다.
3. WonderLab 등 사용자가 제외한 출처는 쓰지 않는다.
4. 시점은 특정 작품에 묶지 않는다. 도서관·L사 같은 사건은 "소문"이나 "흔적" 정도로만 등장시킨다.

## 1. 도시의 층위

| 층위 | 원작 설정 (요약) | 게임에서 |
|---|---|---|
| 머리 | 도시 전체의 질서와 금기를 정하는 최상위 권력. 개인의 행복보다 도시의 지속을 우선한다 | 직접 등장하지 않음. 금기 플래그가 쌓이면 집행자가 온다 |
| 눈 | 감시·정보 | 미구현 (금기 감시 연출 후보) |
| 발톱 | 강제력·직접 집행 | 숨은 보스 "발톱" (금기 1회 이상, 6년차부터) |
| 조율자 | 머리의 권한을 등에 업은 집행자. 해결사·날개 전투원과 차원이 다름 | 숨은 보스 "조율자" (금기 2회 이상, 7년차부터, 도주 불가) |
| 금기 | 생활 규칙보다 강한 상위 규칙. 위반하면 개인·조직 힘으로 감당 못 할 처벌 | 사건 "금지된 연구", "두 번째 금기"로 플래그 획득 |

| 특이점 | 상식을 넘는 핵심 기술. 결과·접근권·비용을 나눠 봐야 한다 | 장비 "특이점 응용 의수" 하나 |
| 둥지 | 날개가 관리하는 상대적으로 안전한 구역. 안전은 기업 통제에 종속된다 | 출신 "평범한 둥지 시민", "둥지 노동자" |
| 뒷골목 | 둥지 밖 생활권. 무법지대가 아니라 여러 세력의 규칙이 겹친 곳 | 출신 "뒷골목 태생", 대부분의 사건 무대 |
| 밤의 뒷골목 | 정해진 시간대에 안전 기준이 무너지는 시간. 청소부가 관련 | 사건 "뒷골목의 밤" 하나. 청소부는 미확인 |
| 외곽·폐허 | 도시 질서 밖. 미지의 생물·유적 | 출신 "외곽 생존자", 적 "외곽 들개 떼", "외곽 사냥꾼" |

## 2. 직업과 소속

### 2.1 해결사
- **원작**: 의뢰를 받는 전문직. 등급은 숫자가 낮을수록 높고 1급이 최상위. 등급은 실력·실적·평판의 지표이지 전투력 공식이 아니다.
- **게임**: 9급 등록 → 승급 포인트(전투·사건) → 승급심사 이벤트 → 1급까지. 심사 실패 시 포인트 1/4 손실, 필요량은 ×2, ×1.4, ×1.2, ×1.1… 로 증가.

### 2.2 색(특색)
- **원작**: 1급 전체를 가리키는 말이 아니다. 업적과 명성으로 특정 색 이름이 붙은 **소수의 개인**.
- **게임**: 1급이 된 뒤 한 번뿐인 특색 심사. 통과하면 "색 + 칭호어"(예: 푸른 칼날).
- **고칠 점**: 심사 문구를 "시험 합격"이 아니라 "업적이 소문으로 퍼져 색으로 불리기 시작한다"는 흐름으로 바꾼다. (미적용)

### 2.3 사무소
- **원작**: 해결사들이 실제로 의뢰를 수행하는 단위. 1인부터 대형까지. 쉽게 무너진다.
- **게임 (오리지널)**: 골목 사무소(속도), 철문 사무소(체력), 등불 사무소(호흡 카드). 원작 사무소 이름은 쓰지 않는다.
- **후보**: 사무소 해체·합병 사건, 동료 사망 사건.

### 2.4 협회
- **원작**: 해결사 업무를 분야별로 조직하는 기관. 지부와 과가 있다. 이전 정리 기준 12개, 급수 심사·공방 특허 관리 등 분야가 나뉜다.
- **게임**: 8곳(하나·츠바이·트레스·시·생크·리우·세븐·디에치). 입회 시 사건 판정 +3, 카드.
- **미확인**: 협회별 전문 분야. 자료가 오기 전까지 협회별 차이를 만들지 않는다.

### 2.5 날개 직원(깃털)
- **원작**: 날개에 고용된 사람을 "깃털"로 부른다. 뒷골목 주민이 가장 바라는 진로지만 소모품 취급을 받기도 한다.
- **게임**: 입사 시험(판정 60), 전용 사건 2개.
- **후보**: 칭호 "깃털", 직급 승진, 할당량·해고·퇴거 사건.

### 2.6 손가락
| 손가락 | 원작 성격 | 서열 (게임) | 확인 |
|---|---|---|---|
| 엄지 | 위계·예법·복종, 무례는 조직에 대한 도전 | 솔다토 → 카포 → 소토카포 → 대부 | 앞 셋 확인, "대부"는 게임 임시 이름 |
| 검지 | 지령의 수행과 해석이 행동의 중심 | 수행자 → 대행자 / 전령 | 확인 |
| 중지 | 가족적 결속·체면·복수 | 막내 → 동생 → 형님 → 큰형님 | 확인 |
| 약지 | 예술·창작·평가가 권력과 연결 | 학생 → 도슨트 → 마에스트로 | 도슨트·마에스트로 확인 |
| 소지 | 서열 없이 다른 조직에 잠입 | 접촉 사건만 | 확인 |

- **후보**: "가주 심사"(이름만 확인, 내용 미확인)를 손가락 쪽 승급심사 이름으로 쓸지 결정 필요.

### 2.7 기타 뒷골목 조직
- **원작**: 손가락 말고도 범죄 조직, 무허가 해결사, 자경단, 종교·사상 집단이 있다.
- **게임**: 적 "조직 행동대장", "손가락 수금원", 사건 "조직의 손짓".

## 3. 장비와 돈

| 항목 | 원작 | 게임 |
|---|---|---|
| 공방 | 무기·장비 제작·개조 업체. 이름난 공방은 품질의 표식. 협회가 특허를 관리 | 오리지널 3단계: 뒷골목 공방 → 협력 공방(소속 필요) → 명장 공방 |
| 장비 | 현실 무기 + 특이점·공방 기술 | 무기·방어구·의수 9종 |
| 화폐 | 작품마다 표기만 나오고 환율은 없다 | 게임 단위로만 사용, 현실 화폐로 환산하지 않는다 |

## 5. 전투 키워드 (게임 규칙)

원작 이름을 빌렸지만 수치와 규칙은 게임 자체 설계다.
- **출혈**: 걸린 쪽이 공격할 때마다(빗나가도) 스택만큼 피해 후 1 감소. 플레이어가 방어 자세를 취하면 절반으로 지혈.
- **파열**: 맞을 때마다 스택만큼 추가 피해 후 1 감소.
- **호흡**: 스택당 치명 확률, 명중마다 1 소모.

## 6. 빈칸 (자료가 오면 채울 것)

1. 날개 목록과 각 날개의 특이점 → 날개별 효과 차별화
2. 협회별 전문 분야 → 협회별 효과·사건
3. 청소부, 혈귀 → 밤 사건·적
4. 가주 심사, 연기 전쟁 → 사건 배경
5. 엄지 최상위 서열 이름
