# 도시의 한 해

> **Project Moon 팬메이드 게임 · 비공식 · 비영리**
> Project Moon(로보토미 코퍼레이션 · 라이브러리 오브 루이나 · 림버스 컴퍼니)의 세계관을 바탕으로 만든 2차 창작물입니다.
> 원작의 권리는 Project Moon에 있으며, 이 게임은 Project Moon과 관련이 없습니다.

플레이: https://cityyear-fanmade.github.io/city-year/

프로젝트문 세계관(로보토미·라오루·림버스) 기반 팬게임. 1인 TRPG 텍스트 어드벤처 + 코스트 카드 전투. 모바일 우선.
**1인용만 만든다.** 멀티는 하지 않는다. 다만 전투 엔진은 화면과 완전히 분리되어 있어 나중에 다시 필요하면 재사용할 수 있다.

## 실행

```bash
npm run dev                 # http://localhost:5173 (개발용: data/*.json을 바로 읽는다)
npm run pages               # 루트 index.html (GitHub Pages 배포용)
npm run build               # dist/city-year.html 한 파일 (서버 없이 휴대폰에서 열기)
npm run sim -- --n 2000     # 밸런스 측정 (--seed 7 로 재현, --json 으로 JSON 출력)
npm run check               # 데이터 참조 검사 + 무작위 진행 4,000판
npm run guide               # 규칙·밸런스 설명서 docs/guide.md 다시 만들기
npm run build -- --expires 2026-10-11T11:30:00Z   # 플레이테스트용 dist/city-year-playtest.html (종료 시각 뒤 새 판 시작 불가)
node tools/play.cjs 5       # 브라우저 자동 플레이 (Playwright 필요, --shots 로 테마 캡처)
```

`dev.html`을 파일로 바로 열면(file://) 브라우저가 JSON 읽기를 막는다. `npm run dev`로 열거나 빌드 파일을 연다.

## 구조

| 경로 | 역할 |
|---|---|
| `data/cards.json` | 키워드 이름, 카드, 보상 카드 목록 |
| `data/enemies.json` | 적, 고정 전투(연차 → 적 id 또는 `table:<조우 표>`), 히든 보스 조건 |
| `data/encounters.json` | 1d100 조우 표. `<표>@<소속 종류>` 표가 있으면 그 소속일 때 그 표를 쓴다 |
| `data/events.json` | 사건, 4년차 갈림길(소속 선택) |
| `data/birth.json` | 출신·재능·결점·무기·색·칭호 단어·레벨 업 성장표·성장기 |
| `data/text.json` | 화면에 나오는 세계관 용어(해결사, 급, 사무소, 날개 등) |
| `src/config.js` | `CFG` 수치 전부. 밸런스는 여기만 바꾼다 |
| `src/engine.js` | 규칙·판정·전투·진행·시뮬. DOM 없음, 난수 주입 가능 |
| `src/ui.js` | 렌더와 연출(굴림/빠르게/끔)만 맡는다 |
| `src/main.js` | 브라우저 진입점(JSON을 불러와 엔진과 화면 연결) |
| `tools/` | sim, check, dev 서버, build, 브라우저 자동 플레이 |
| `v0.3.html` | 처음 받은 원본 (참고용) |

규칙 코드는 일반 용어(빛, 카드, 특색, 자격, 소속)만 쓰고, 세계관 고유명사는 `data/`의 문자열에만 있다.

## 데이터 추가 방법 (코드 수정 없이)

- **카드**: `cards.json`의 `cards`에 추가. `t`는 `atk`/`def`/`buff`. 공격 카드 필드: `c`(코스트), `hits`, `dice`(d6 개수), `b`(고정 피해), `hit`(명중 보정), 선택 `kw: [[키워드, 스택, "t"상대|"s"자신]]`, `adv`(명중 2회 굴림), `rr`(낮은 피해 주사위 재굴림), `min`(피해 주사위 최소값). 보상으로 나오게 하려면 `rewards`에도 넣는다.
- **적**: `enemies.json`의 `enemies`에 추가하고 `encounters.json`의 조우 표에 넣는다(마지막 `max`는 100). 고정 전투(`fixedFights`)와 사건 `fx.combat`은 적 id 또는 `table:<표 이름>`을 받는다.
- **사건**: `events.json`의 `events`에 추가. 선택지에 `check: {s: 능력치|null, dc}`가 있으면 1d100 판정, 없으면 결과 확정. `fail`은 판정이 있을 때 필수.
  - 조건 `req`(사건 또는 선택지): `licensed`, `unlicensed`, `aff`, `noaff`, `aff:<종류>`, `affname:<이름>`, `rank<=N`, `flag:<이름>`, `flag:<이름>>=n`. 배열은 모두 만족, `{"any": [...]}`는 하나라도
  - 효과 `fx.flag`: 보이지 않는 기록을 1 올린다(금기, 초대 등)
  - `first: true`면 조건이 맞을 때 다른 사건보다 먼저 나온다(소속 전용 사건)
  - 효과 `fx`: `hp`, `maxHp`, `atk`, `eva`, `spd`, `check`, `startBreath`, `card`, `reward`, `license`, `join: {type, name}`, `combat`
- 추가한 뒤 `npm run check`: 없는 카드·적·키워드를 가리키면 알려 주고, 무작위로 2,000판을 끝까지 돌려 막히는 곳이 없는지와 한 번도 안 나온 사건을 보여 준다.

## 진행

1. **출생**: 이름 입력(없으면 "당신"). 태어날 때마다 새 시드를 뽑아 화면에 보여 주고, 시드 번호를 넣으면 같은 출생·굴림을 다시 할 수 있다(같은 시드 + 같은 선택 = 같은 결과). 출신(8종)·재능·결점·무기·색을 1d100으로 정한다(색은 직접 바꿀 수 있음).
   - 진로 보정이 있는 출신: 조직 출신(손가락 +20), 날개 직원 집안(날개 +20 · 협회 +15), 외곽 생존자(해결사 +20)
   - 평범한 출신: 평범한 둥지 시민, 뒷골목 태생, 둥지 노동자, 몰락한 가문, 도서관의 손님
   - 진로 보정은 그 진로에 들어가는 판정에 더해지고, 그 진로의 권유 사건이 (보정 × 2)% 확률로 먼저 나온다.
2. **성장기**: 5·9·13·16세에 1d100으로 능력치가 하나씩 오른다.
3. **17~23세 (7년)**: 해마다 사건 하나. 3년차는 초반 조우 표, 6년차는 중반 조우 표를 1d100으로 굴리고, 7년차는 보스(열두 번째 손님). 사건 판정 실패 전투도 조우 표를 굴린다. 손가락·날개 소속이면 전용 표를 쓴다.
4. **소속**: 권유 사건(조직의 손짓, 날개 채용 공고, 해결사 자격 시험, 협회 추천서)으로 일찍 들어가거나 4년차 갈림길에서 고른다.
   - 사무소(골목·철문·등불), 협회(하나·츠바이·트레스·시·생크·리우·세븐·디에치), 날개(K·R·W·N·J·G사), 손가락(엄지·검지·중지·약지·소지). 이름은 들어갈 때 무작위로 정해진다.
   - 소속마다 전용 사건이 있고, 소속이 생기면 먼저 나온다.
5. **해결사**: 자격 시험·계약·견습으로 9급 등록. 소속이 없거나 사무소 소속이면 전투 승리 뒤 소문 판정(1d100 + 해결사 보정 ≥ 60)으로도 등록. 고정 전투에서 이길 때마다 2급씩 승급.
6. **특색**: 1급에 오른 해결사 중 특출 판정(1d100 + 판정 보정 ≥ 80)을 넘은 사람만. 지금 7년 진행으로는 최고 3급까지라 나오지 않는다.
7. 레벨이 오르면 성장표를 1d100으로 세 번 굴려 하나를 고른다.
8. **히든 보스** (`enemies.json`의 `hiddenBosses`, 위에서부터 첫 번째로 조건이 맞는 보스가 고정 전투를 대신한다)
   | 보스 | 조건 | 시점 |
   |---|---|---|
   | 조율자 | 금기 2회 | 7년차 |
   | 발톱 | 금기 1회 | 6·7년차 |
   | 도서관의 사서 | 초대장 두 번 수락 (도서관의 손님 출신은 1회 수락 상태로 시작) | 7년차 |
   | 검지 대행자 | 검지 소속 또는 윗선의 지시 거역 | 7년차 |
   | 검은 침묵 | 해결사 3급 이상, 1d100 ≤ 12 | 7년차 |
   | 푸른 잔향 | 해결사 3급 이상, 1d100 ≤ 20 | 7년차 |
   | 홍원 군주 | 소지 표식 보유, 70% | 40년차부터 (십이지 흑수가 한 마리씩 차례로 덤벼들고 물러난다 · 승리하면 특수환(능력치 하나 +10)과 붉은 붕대(HP+20)) |
   - 조건이 맞으면 먼저 **불길한 예감** 화면이 나온다. "이 길로 간다"면 히든 보스, "돌아선다"면 평소 조우(조건이 맞으면 다음에 또 나온다). 조율자만 피할 수 없다(`noEscape`). 문구는 `hiddenBosses[].omen`.
   - 해결사 전용 급수 심사 사건(급수 심사, 승급 추천)으로도 승급할 수 있다. 일찍 등록해 심사를 통과한 판만 7년차 전에 3급이 된다.
   - 특색 보스는 `penalty`가 있다: 1급 미만(지금 7년 진행에서는 3급)이면 급수 부족 보정으로 내 명중·회피 −15. 성장한 3급 기준 승률 3~5%, 1급이면 약 28%.
   - 금기 사건: 뒷골목의 밤(창밖을 기록한다), 금지된 연구, 두 번째 금기. 선택지에 "금기"라고 표시된다.
   - 자동 진행 30,000판 기준 만났을 때 승률: 발톱 10% · 조율자 13% · 도서관 13% · 검지 대행자 20% · 푸른 잔향 18% (카드를 무작위로 내는 값이라 직접 하면 더 높다).
9. **히든 직업**: 발톱을 이기면 머리의 발톱, 조율자를 이기면 머리의 조율자가 해금된다. 해금 기록은 그 브라우저에만 남는다. 직업 이야기 줄기는 다음 단계.

10. **돈과 공방** (`data/workshops.json`)
   - 화폐 단위 안. 출신별 시작 자산(외곽 생존자 80 ~ 몰락한 가문 700), 해마다 소속 봉급(무소속 60 · 사무소 160 · 협회 260 · 날개 300 · 손가락 220) + 해결사 급수 수당(9급에서 오른 급수당 25), 전투 현상금(초반 90 · 중반 200 · 보스 400 · 히든 700), 일부 사건.
   - 공방 3등급: 뒷골목(누구나) · 협력(사무소·날개·손가락·협회 소속, 또는 해결사 5급 이상) · 명장(협회 소속, 또는 다른 소속이면서 해결사 5급 이상).
   - 장비 칸 무기·방어구·의수. 사면 그 칸 장비와 교체. 출생 무기는 무기 칸의 첫 장비.
   - 사건·전투 전 화면의 "공방에 들른다"로 들어간다.
   - `npm run check`의 자동 진행은 해마다 지금 장비보다 비싼 것 중 살 수 있는 가장 비싼 것을 산다. 20,000판 기준 끝날 때 접근 등급 뒷골목 36% · 협력 46% · 명장 17%.

11. **손가락 서열과 소지** (`data/fingers.json`)
   - 엄지 솔다토 → 카포 → 소토카포 → 대부 · 검지 수행자 → 대행자/전령(1d100 갈래) · 중지 막내 → 동생 → 형님 → 큰형님 · 약지 학생 → 도슨트 → 마에스트로
   - 손가락에 들어가면 첫 서열부터 시작. 고정 전투 승리와 승급 사건(윗선의 시험 등 `fx.promote`)으로 한 단계씩 오르고 서열마다 보정을 더한다. 서열 3단계 이상이면 공방 +1등급, 서열마다 봉급 +40.
   - 소지는 어느 소속에도 겹쳐 붙는 표식(`fx.pinky`): 판정 +5 · 회피 +2 · 해마다 +100안. "소지의 접촉" 사건으로 얻는다.

`npm run check`는 출신별로 해결사 등록률과 최종 소속 비율을 보여 준다(사건 선택은 무작위). 4,000판 기준: 외곽 생존자 해결사 85%(다른 출신 49~66%), 날개 직원 집안 날개 33%(다른 출신 10~13%), 조직 출신 손가락 34%(다른 출신 7~12%).

## 전투 화면

- 라운드 시작 때 적이 낼 카드를 정해 공개한다(의도). "이번 라운드 행동 순서"에 방어 카드 → 공격·버프 교대 순서로 누가 누구에게 무엇을 내는지 나열하고, 손패를 고르면 바로 끼워진다.
- 재생 중에는 지금 행동을 순서표에서 강조하고, 공격하는 쪽은 금색, 맞는 쪽은 붉은 테두리. 주사위에 주인 이름("당신 · 명중" / "적 · 회피")과 판정 결과("명중 · 피해 7" / "빗나감")를 띄운다.

## 연출 설정

수동(행동마다 "주사위를 굴린다"를 눌러 직접 굴림, 라운드 끝에 "라운드 마치기", 사건 판정도 탭) · 천천히(자동, 1.4배) · 빠르게(자동, 0.45배) · 끔(결과만). 어느 모드든 "연출 건너뛰기"로 남은 행동을 한 번에 끝낸다. 설정은 그 브라우저에 기억된다.

## 밸런스 (`npm run sim -- --n 5000 --seed 1`, 카드는 무작위로 냄)

| | 분리 전 v0.4 (1인) | 분리 후 | 성장기 추가 후 (현재) |
|---|---|---|---|
| 웃는 가로등 | 97.7% | 97.5% | 98.5% |
| 녹슨 자장가 | 69.7% | 69.1% | 75.9% |
| 열두 번째 손님 | 44.6% | 44.6% | 49.8% |
| 꺼진 메아리 | 90.1% | 89.4% | 92.8% |
| 연속 3전 | 10.7% | 10.5% | 15.7% |
| 연속 3전 · 성장 반영 | 16.1% | 16.8% | 21.3% |

- 분리 전후 차이는 통계 오차 범위(5,000회 기준 ±1%p 안팎)라 동작과 수치는 그대로다.
- 성장기 능력치 상승 4회가 붙어서 전체가 조금 쉬워졌다. 체력·피해 비율을 정할 때 `CFG` 또는 성장기 표로 맞춘다.
- `npm run check` 무작위 진행(사건도 무작위 선택): 완주 약 30%, 소속 분포 사무소 약 58% · 날개 약 9% · 없음 약 33%.

## 확인한 것

- 단일 파일 빌드: 브라우저 자동 플레이 6판(연출 빠르게 1판 + 끔 5판) 결말까지, JS 오류·경고 0건.
- 개발 서버(JSON fetch): 3판 결말까지, 오류 0건.
- 직접 해 볼 것: 실제 휴대폰에서 빌드 파일을 열어 글자 크기와 테마 프레임이 잘리지 않는지.
